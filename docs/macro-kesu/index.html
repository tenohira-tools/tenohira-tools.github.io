社外に渡す前に、Excel・Word・PowerPointのマクロ（VBA）を削除してxlsx/docx/pptxに変換

マクロ(VBA)入りのファイル（.xlsm/.docm/.pptm）を社外に送る前に、マクロだけを取り除いた通常形式（.xlsx/.docx/.pptx）に変換します。アプリで1本ずつ「名前を付けて保存」し直す手間や、オンライン変換サイトへファイルをアップロードする必要もありません。見つかったマクロの概要（容量・デジタル署名の有無）を確認してから削除し、複数ファイルを一括処理できます。ファイルはサーバーに送らず、すべてこのブラウザの中だけで処理します。元のファイルは変更しません。

ここにExcel・Word・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

マクロ入りの.xlsm / .docm / .pptm に対応。複数ファイルを同時に追加できます（.xlsx/.docx/.pptxを入れた場合はマクロが無い旨を表示します）。ファイルは選択した端末の中だけで処理されます。

読み込んだファイル

使い方とよくある質問

  1. 上の枠にExcel/Word/PowerPointファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. マクロ（VBAプロジェクト）が見つかると、容量とデジタル署名の有無が表示されます。「マクロを削除する」にチェックが入った状態（既定）で「削除して書き出す」を押すと、マクロを取り除いた.xlsx/.docx/.pptxがダウンロードされます。元のファイルはそのまま残ります。

Q. 「名前を付けて保存」でマクロなし形式にするのと何が違いますか？

A. Excel・Word・PowerPointで1本ずつファイルを開き、形式を選んで保存し直す操作と同じ結果が得られますが、このツールは複数ファイルを一度にまとめて処理できます。また、オンラインのファイル形式変換サイトのようにファイルをサーバーへアップロードする必要がなく、常にこのブラウザの中だけで処理されるため、社外秘のファイルでも安心して使えます。

Q. マクロを削除すると、見た目や内容は変わりますか？

A. 表・文章・スライドの内容、書式、画像などは変更しません。削除されるのはマクロ（VBAプロジェクトとそのデジタル署名）だけです。ただし、マクロで動いていたボタンや自動処理は、マクロ本体が無くなるため動作しなくなります。マクロに結び付けられたボタン図形自体は残りますが、押しても何も起こらなくなります。

Q. 「ActiveXコントロール」も削除されますか？

A. いいえ。フォームのボタンやテキストボックスなどのActiveXコントロールは、図形としての配置情報と結び付いているため、このツールでは削除せずそのまま残します（見つかった場合は件数だけ表示します）。コントロールに割り当てられたマクロの実行だけが無効になります。

Q. マクロの中身（コード）を確認することはできますか？

A. このツールではコードの内容までは表示しません。マクロ（VBAプロジェクト）が存在するかどうかと、その概要（データ容量、デジタル署名の有無）だけを確認できます。中身を見るには、Excel/Word/PowerPointの「Visual Basic Editor」（Alt+F11）を使ってください。

Q. 対応しているファイル形式は？

A. マクロ有効の形式としてExcel(.xlsm)、Word(.docm)、PowerPoint(.pptm)に対応し、それぞれ.xlsx/.docx/.pptxに変換します。マクロ有効のテンプレート形式（.xltm/.dotm/.potm）やスライドショー形式（.ppsm）、古い.xls/.doc/.ppt形式、パスワードで保護されたファイルは対応していません。すでにマクロの無い.xlsx/.docx/.pptxを読み込んだ場合は、マクロが見つからない旨を表示します。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は拡張子の異なる新しいファイルとしてダウンロードされます（ファイル名の末尾に「_マクロ削除済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・個人を特定しない形で数えるGoatCounterの通信のみ発生します。入力内容は端末の外に送られません）。

How to use & FAQ

  1. Drag and drop Excel/Word/PowerPoint files into the box above, or click it to choose (multiple files are fine).
  2. If a macro (VBA project) is found, its size and whether it's digitally signed are shown. With "Remove the macro" checked (the default), click "Remove and build" to download a clean .xlsx/.docx/.pptx. Your original file is untouched.

Q. How is this different from "Save As" a macro-free format in the app?

A. The result is the same as opening each file in Excel/Word/PowerPoint and saving it again as the non-macro format, but this tool can process several files at once. It also never uploads your file to a server the way an online file-conversion site would — everything always happens inside this browser, so it's safe to use on confidential files too.

Q. Does removing the macro change the content or appearance?

A. No — the tables, text, slides, formatting and images are left untouched. Only the macro (the VBA project and its digital signature) is removed. Buttons or automated steps that relied on the macro will stop working once the macro code itself is gone; a button shape linked to a macro stays in place but does nothing when clicked.

Q. Are ActiveX controls removed too?

A. No. Form controls such as ActiveX buttons or text boxes are tied to their shape placement, so this tool leaves them in place (it only reports how many were found). Only the ability to run a macro from them is lost.

Q. Can I see the macro's actual code?

A. This tool doesn't show the code itself — only whether a macro (VBA project) exists and its summary (data size, whether it's digitally signed). To read the code, use the Visual Basic Editor (Alt+F11) in Excel/Word/PowerPoint.

Q. Which file formats are supported?

A. Macro-enabled Excel (.xlsm), Word (.docm) and PowerPoint (.pptm), converted to .xlsx/.docx/.pptx respectively. Macro-enabled templates (.xltm/.dotm/.potm), the slideshow format (.ppsm), the older .xls/.doc/.ppt formats, and password-protected files are not supported. A file that's already macro-free (.xlsx/.docx/.pptx) will simply be reported as having no macro.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file with a different extension (with "_macro_removed" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter — nothing you type or upload ever leaves your device).
