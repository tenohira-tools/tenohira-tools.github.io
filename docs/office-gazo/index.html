Excel・Word・PowerPointの画像をまとめて取り出す

拡張子をzipに変えて中身を覗く手間なく、ファイルに埋め込まれた画像を一覧表示。1枚ずつ、またはZIPでまとめて保存できます。ファイルはどこにも送信されません。

ここにExcel・Word・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.xlsx / .xlsm / .docx / .docm / .pptx / .pptm に対応。複数ファイルを一度に追加できます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）、Word（.docx/.docm）、PowerPoint（.pptx/.pptm）のファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. ファイルに埋め込まれた画像が一覧（サムネイル）で表示されます。見つかった画像の枚数と合計サイズも表示されます。
  3. 1枚だけ必要な場合は、その画像の下の「保存」ボタンを押します。
  4. すべて必要な場合は、カード上部の「ZIPでまとめて保存」を押すと、そのファイルの画像だけを集めたZIPファイルがダウンロードされます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・抽出されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 「拡張子を.zipに変える」方法との違いは？

A. よく紹介される方法は、ファイルの拡張子を手動で.zipに書き換えて展開し、xl/media・word/media・ppt/mediaフォルダから画像を探す、というものです。このツールは同じ仕組み（Office形式の実体がZIPであること）を使いながら、拡張子の変更やフォルダを探す手間なく、ブラウザの中で一覧表示とZIP保存まで行います。

Q. どの画像まで検出できますか？

A. ファイル内の画像格納フォルダ（xl/media・word/media・ppt/media）にある、写真やアイコンなどの画像ファイルそのものを検出します。Excel・PowerPoint上で図形やSmartArt、グラフとして直接描かれたもの（画像ファイルとして保存されていないもの）は対象外です。

Q. プレビューが出ず「プレビュー非対応」と表示される画像があります。

A. EMF・WMF（Windowsの図面形式）やTIFFなど、ブラウザが標準で表示できない形式です。保存自体は他の画像と同じようにできます。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm、Word の.docx・.docm、PowerPointの.pptx・.pptmに対応しています（いずれもZIP形式を実体に持つOffice Open XML形式）。古い.xls/.doc/.ppt形式や、パスワードで保護されたファイルは読み込めません。

Q. 画像が1枚も見つかりませんでした。

A. 画像を含まないファイル、または画像がすべて図形・SmartArt・グラフとして描かれている場合は「画像が見つかりませんでした」と表示されます。ファイル自体が壊れている可能性もあります。

Q. 保存した画像のファイル名は元のファイルと同じですか？

A. Office内部で画像に付けられた名前（image1.png・image2.jpeg など）のままです。わかりやすい名前に変えたい場合は、保存後にお使いの端末で名前を変更してください。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm), Word (.docx/.docm) or PowerPoint (.pptx/.pptm) file into the box above, or click it to choose one (several files at once are fine too).
  2. Every picture embedded in the file is shown as a thumbnail grid, along with how many were found and their total size.
  3. Need just one? Click "Save" under that thumbnail.
  4. Need them all? Click "Save all as ZIP" at the top of that file's card to download a ZIP containing only that file's pictures.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and extracted inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. How is this different from renaming the file to .zip?

A. The common trick is to manually rename the file to .zip, extract it, and dig through the xl/media, word/media or ppt/media folder for the pictures. This tool uses the same underlying fact (Office files are really ZIP archives) but skips the renaming and folder-hunting — it lists and re-packages the pictures right in your browser.

Q. Which pictures can it find?

A. Picture files stored in the file's media folder (xl/media, word/media or ppt/media) — photos, icons, and similar. Shapes, SmartArt and charts drawn directly in Excel/PowerPoint (not stored as picture files) are not included.

Q. Some thumbnails say "preview not supported".

A. Those are formats browsers don't display natively, such as EMF/WMF (Windows drawing formats) or TIFF. You can still save them just like any other picture.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx/.xlsm, Word .docx/.docm, and PowerPoint .pptx/.pptm — all Office Open XML formats, which are ZIP archives underneath. The older .xls/.doc/.ppt formats and password-protected files are not supported.

Q. No pictures were found.

A. This happens when the file has no embedded picture files, or everything is a shape/SmartArt/chart instead. The file could also be corrupted.

Q. Do the saved files keep their original names?

A. They keep the internal name Office gave them (image1.png, image2.jpeg, etc.). Rename them on your device afterward if you want something more descriptive.
