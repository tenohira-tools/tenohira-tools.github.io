「名前は既に存在します」対策：名前定義の点検・削除ツール

Excel(.xlsx/.xlsm)に登録された名前定義（defined names）を全件一覧表示し、非表示・エラー(#REF!)・外部ファイル参照・組み込み名を自動で見分けます。シートのコピー時に「名前'○○'は既に存在します」のダイアログが繰り返し出る原因になりやすい名前を選んで削除し、新しいファイルとして書き出せます。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。ファイルは選択した端末の中だけで処理されます。

名前定義の集計

「組み込み」は印刷範囲・フィルター範囲などExcelが自動管理する名前です。削除は可能ですが、該当する機能の設定が失われます。

名前の一覧

選んだ名前は、グラフ・条件付き書式・入力規則・他の数式からまだ参照されている場合があります。削除後にExcelで開き、#NAME?エラーが出ないか確認してください。元のファイルは変更されず、新しいファイルとして書き出されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 名前の一覧で、各名前の対象（ブック全体／シート名）・数式・非表示／エラー／外部参照／組み込みの印を確認します。
  3. 削除したい名前にチェックを入れます（「エラーを選択」「非表示を選択」で一括選択も可能）。
  4. 「選んだ名前を削除したファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 「名前'○○'は既に存在します」というダイアログが何度も出るのはなぜですか？

A. よくある原因は、コピー元のシートに紐づいた非表示の名前定義（特に参照先が壊れて#REF!になっているもの）が、コピー先のブックに既にある名前と衝突することです。Microsoft公式のFAQでも対処法としてVBAでの名前の表示・削除が案内されていますが、このツールはVBAを使わず、該当しそうな名前（非表示・エラー）を一覧から選んで削除したファイルをその場で作れます。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。.xlsmファイルのマクロ部分はそのまま保持されますが、マクロが削除した名前を参照している場合はマクロ側の修正が必要です。

Q. 「組み込み」と表示される名前は何ですか？削除しても大丈夫ですか？

A. 名前が「_xlnm.」で始まるものは、印刷範囲（Print_Area）・印刷タイトル（Print_Titles）・オートフィルターの範囲（_FilterDatabase）など、Excelが機能のために自動で管理する名前です。削除自体はできますが、該当する設定（例：印刷範囲の指定）がリセットされます。多くの場合、他の名前との衝突の原因にはなりにくいため、まずはそれ以外の名前から確認することをおすすめします。

Q. 「非表示」「エラー」「外部参照の可能性」はどうやって判定していますか？

A. 「非表示」は名前定義に保存されているhidden属性、「エラー」は参照先の文字列に#REF!が含まれているか、「外部参照の可能性」は「[1]」のような他のブックを指す書き方が含まれているかを、文字列として機械的に判定しています。断定ではないため、重要なファイルでは削除後にExcelの「名前の管理」で最終確認してください。

Q. 名前を削除すると、その名前を使っている数式はどうなりますか？

A. このツールは選んだ名前定義そのものを削除するだけで、ファイル内の他の数式・グラフ・条件付き書式・入力規則は書き換えません。もしそれらが削除した名前をまだ参照していた場合、Excelで開くと#NAME?エラーになります。非表示でエラー(#REF!)になっている名前は通常どこからも正しく参照されていないため比較的安全ですが、重要なファイルは削除後に必ずExcelで開いて確認してください。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_名前整理済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. シートの構成やセルの値、書式は変わりますか？

A. 変わりません。シート・セルの値・数式・書式・グラフ・画像など、名前定義以外のすべての部分はそのままコピーされます。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Check each defined name's scope (workbook or sheet), formula, and whether it's hidden, broken (#REF!), a possible external reference, or an Excel built-in.
  3. Tick the names you want to remove (the quick-select buttons select all errored or all hidden names at once).
  4. Click "Build a file with the selected names removed" to download the cleaned copy — your original file is untouched.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Why does Excel keep showing "A name already exists" when I copy a sheet?

A. The usual cause is a hidden defined name on the sheet being copied — often one whose reference is already broken (#REF!) — colliding with a name already present in the destination workbook. Microsoft's own guidance suggests fixing this with a VBA macro that reveals and deletes the name; this tool does the same job without VBA, letting you pick the hidden/broken names from a list and build a cleaned copy.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported. For .xlsm, the macro code itself is preserved untouched, but if a macro references a name you removed, the macro will need its own fix.

Q. What does "built-in" mean, and is it safe to delete those?

A. A name starting with "_xlnm." is one Excel manages automatically for a feature — Print_Area, Print_Titles, the AutoFilter range (_FilterDatabase), and similar. You can delete it, but the matching feature (e.g. the print area) is reset. These rarely cause name collisions, so it's usually best to review the other names first.

Q. How are "hidden", "error", and "possible external reference" detected?

A. "Hidden" reads the name's stored hidden attribute. "Error" checks whether the reference text contains #REF!. "Possible external reference" looks for a pattern like "[1]" that points at another workbook. These are text-pattern checks, not certainties — double-check in Excel's Name Manager after removing anything from an important file.

Q. What happens to formulas that use a name I delete?

A. This tool only removes the selected name definitions — it does not rewrite any other formula, chart, conditional format, or data validation rule in the file. If one of those still references a name you removed, Excel will show a #NAME? error when it's opened. Hidden names whose reference is already broken (#REF!) are usually not referenced correctly from anywhere, so they're relatively safe to remove, but always re-open an important file in Excel afterward to check.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_cleaned" appended to the name). Your original file is never overwritten.

Q. Does this change the sheets, cell values, or formatting?

A. No. Everything except the defined names — sheets, cell values, formulas, formatting, charts, images — is carried over unchanged.
