使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル・複数シートも自動でまとめて読み込みます）。
  2. 集計欄で、コメント・メモの総数と内訳（メモ／コメント／返信／解決済み）を確認します。
  3. 絞り込みで、特定のファイル・シート・種類に絞って一覧を確認します。
  4. 必要な一覧を「CSVでダウンロード」で保存するか、「この一覧を印刷」でそのまま印刷します（絞り込んだ内容がそのまま反映されます）。

Q. 「メモ」と「コメント」は何が違いますか？

A. どちらもセルに付けられる注記ですが、仕組みが異なります。「メモ」は昔からあるコメント機能（Excelの新しいバージョンではこの名前に変わりました）で、1件の注記を1人の投稿者名とともに保存します。「コメント」は比較的新しい「スレッド形式」の機能で、同じセルに複数人がやり取りを重ねられ、返信や「解決済み」の状態も保存できます。このツールはどちらも区別して一覧化します。

Q. 返信（スレッドのやり取り）はどう表示されますか？

A. 元のコメントの直後に、先頭に「↳」を付けてインデントして表示し、種類欄に返信のバッジを付けます。日時が記録されている場合は古い順に並びます。

Q. 「解決済み」はどうやって分かりますか？

A. スレッド形式のコメントには、Excelで「スレッドを解決」した際の状態がファイルに保存されています。元のコメント（返信ではないもの）がその状態の場合、種類欄に解決済みのバッジを付けます。

Q. 投稿者名や日時が空欄になることがあります

A. 投稿者情報が本来あるはずの場所（スレッド形式コメントの場合は社内のユーザー情報）に見つからない場合や、ファイルの保存元のアプリによって日時が記録されていない場合に空欄になります。本文はそのまま表示されます。

Q. コメント・メモを削除したい場合は？

A. このツールは一覧表示とCSV出力・印刷専用で、ファイルの書き換えは行いません。社外にファイルを渡す前に投稿者名だけを消したい場合は、作成者・最終更新者・コメント投稿者名を消すツールをお使いください（コメント本文自体は残ります）。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

Q. 図形コメント（セルに紐付かないコメント）やセルの背景色・罫線などの書式は読み取れますか？

A. いいえ。このツールはセルに紐付いたコメント・メモの位置・投稿者・本文・日時・解決状態だけを読み取ります。マクロ・グラフ・画像・セルの色や罫線は扱いません。

Q. 大きなファイルや多数のファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、コメント・メモの合計が数千〜1万件程度までを想定しています。一覧の表示は先頭の一定件数のみに制限されることがありますが、ダウンロードするCSVには絞り込み後の全件が含まれます。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more (every sheet in every file is scanned automatically).
  2. Check the summary panel for the total count and the breakdown (notes / comments / replies / resolved).
  3. Use the filters to narrow the list down to one file, one sheet, or one type.
  4. Click "Download as CSV" to save the list, or "Print this list" to print it directly — both reflect the current filters.

Q. What's the difference between a "note" and a "comment"?

A. Both are annotations on a cell, but the underlying mechanism differs. A "note" is the older comment feature (renamed "Note" in newer Excel versions) — a single piece of text with one author. A "comment" is the newer threaded-comment feature, which lets multiple people reply to each other on the same cell and tracks a "resolved" state. This tool lists both, clearly labeled.

Q. How are thread replies shown?

A. Each reply appears right after its parent comment, indented with a leading "↳" and labeled with a reply badge. When timestamps are present, replies are sorted oldest first.

Q. How is "resolved" determined?

A. Threaded comments store Excel's own "resolve thread" state in the file. When a root comment (not a reply) is in that state, it gets a resolved badge.

Q. Why are some author names or dates blank?

A. This happens when the author information that should be stored for a threaded comment isn't found, or when the application that saved the file didn't record a timestamp. The comment text itself is still shown.

Q. I want to delete comments or notes — can this tool do that?

A. No — this tool only lists, exports and prints; it never rewrites your file. To strip just the author names before sending a file outside your company, see the creator/author name remover (the comment text itself stays).

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.

Q. Are shape-based comments, cell colors or borders read?

A. No — only the position, author, text, date and resolved state of cell-attached comments/notes are read. Macros, charts, images, colors and borders are ignored.

Q. Can it handle large or many files?

A. Everything runs in browser memory, built for up to a few thousand to around ten thousand comments in total. The on-screen list may be capped for performance, but the downloaded CSV always contains every row matching the current filters.
