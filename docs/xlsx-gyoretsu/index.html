非表示の行・列が全シートに散らばっている：まとめて「再表示」または内容だけ削除

非表示にした行・列は、1枚のシートなら左上の全選択→右クリック→「再表示」でまとめて戻せますが、シートが何枚もあると1枚ずつ繰り返すしかなく、どのシートに何行・何列隠れているかも分かりません。値を入れたまま非表示にした行・列には、ファイルを社外やAIに渡す前に消しておきたい情報が残っている可能性もあります。このツールはExcel(.xlsx/.xlsm)の全シートを解析し、非表示の行・列の数と、そこに実際に値が入っているセルの数を一覧表示します。シートを選んで「再表示」（非表示を解除するだけで値はそのまま残ります）、または「内容だけ削除」（非表示の状態は変えずに、その行・列のセルの値・数式だけを消します）のどちらか、または両方を行った新しいファイルを書き出せます。行・列そのものを詰めて削除する操作は、数式参照や結合セルが崩れる恐れがあるため行いません。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。全シートの非表示行・非表示列を解析します。ファイルは選択した端末の中だけで処理されます。

シートごとの非表示行・列

非表示の行・列が見つかりました。シートごとに「再表示」「内容だけ削除」を選んで、下のボタンで新しいファイルを書き出せます。

非表示の行・列は、どのシートにも見つかりませんでした。

注意：「内容だけ削除」を行うと、その値を参照している他のセルの数式結果が変わることがあります。行・列そのものの削除（位置を詰める操作）は行いません。

シート別の内訳

「値のあるセル」は、非表示の行または列の中で、実際に値・数式が入っているセルの件数です（内容は表示せず件数だけを数えます）。チェックが無い項目のチェックボックスは操作できません。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 自動で解析され、シートごとに非表示の行数・列数と、そこに値が入っているセル数が表示されます。
  3. シートごとに「再表示」「内容だけ削除」を選び（上のボタンでまとめて選択も可能）、「選んだ内容で新しいファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. 「再表示」と「内容だけ削除」はどう違いますか？

A. 「再表示」は非表示フラグを外すだけの操作で、値はそのまま残ります（シート見出しを右クリックして「再表示」を選ぶのと同じ結果を、全シートまとめて行います）。「内容だけ削除」は非表示の状態を変えずに、その行・列にあるセルの値・数式だけを空にします。ファイルを社外に渡す前に「隠したつもりの情報」を確実に消したい場合は内容だけ削除を、単に見えなくなっている行・列を元に戻して確認したい場合は再表示を選んでください。両方選ぶと、内容を消したうえで表示にも戻します。

Q. 行や列そのものを削除（詰める）できますか？

A. いいえ。行・列を物理的に削除すると、他のセルの位置がずれたり、その行・列を参照している数式や結合セルの範囲が壊れる恐れがあります。このツールは安全のため、行・列の「非表示」状態と「セルの値」だけを扱い、行・列の構造自体（位置や総数）は変更しません。行・列を本当に削除したい場合は、再表示したうえでExcelの通常の削除操作（行番号を右クリックして「削除」）を行ってください。

Q. 「内容だけ削除」をすると、他のセルの計算結果が変わることはありますか？

A. あります。削除した値を他のセルの数式が参照していた場合、その数式の計算結果が変わります（空欄として計算されます）。非表示の行・列に集計用の値や作業用のデータを置いているファイルでは、削除前に一度「再表示」したファイルを開いて内容を確認することをおすすめします。

Q. 列の幅や行の高さは変わりますか？

A. 「再表示」をすると、非表示にする前に設定していた高さ・幅の情報が残っていない場合、Excelの初期設定の値で表示されることがあります。これはExcel本体の「再表示」コマンドと同じ挙動です。「内容だけ削除」では列の幅・行の高さ・非表示の状態そのものは変更しません。

Q. 完全非表示（veryHidden）のシート自体はどうなりますか？

A. このツールが扱うのは1枚のシートの中にある非表示の行・列です。シートそのものの非表示・完全非表示は対象外です。シートの表示状態を確認・変更したい場合はシート再表示ツールをご利用ください。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. It's analyzed automatically: for each sheet, the number of hidden rows/columns and how many cells inside them still hold a value or formula.
  3. Pick "Unhide" and/or "Clear contents only" per sheet (or use the buttons above to select them in bulk), then click "Build a file with what's selected" to download it. Your original file is untouched.

Q. What's the difference between "Unhide" and "Clear contents only"?

A. "Unhide" just clears the hidden flag — the values stay exactly as they were (the same result as right-clicking a row/column header and choosing Unhide, applied across every sheet at once). "Clear contents only" leaves the hidden state untouched and instead empties the value/formula of every cell inside that hidden row or column. If you need to make sure information you thought was hidden is actually gone before sending a file outside your company, use "Clear contents only"; if you just want to bring back rows/columns that went invisible, use "Unhide". Selecting both clears the contents and makes the sheet visible again.

Q. Can this actually delete the rows/columns (so positions shift)?

A. No. Physically deleting a row or column can shift other cells' positions and break formulas or merged-cell ranges that reference it. For safety, this tool only ever touches a row/column's hidden state and its cells' values — never the row/column structure itself (position or count). If you really need to delete rows/columns, unhide them first and use Excel's own Delete command (right-click the row/column header).

Q. Can clearing contents change the result of other formulas?

A. Yes. If another cell's formula referenced a value you cleared, that formula's result will change (it will now compute as blank). If a workbook keeps working totals or helper data in hidden rows/columns, open the "Unhide" version first to check what's there before clearing.

Q. Does this change column widths or row heights?

A. "Unhide" can reveal Excel's default height/width if the pre-hidden size wasn't preserved in the file — the same behavior as Excel's own Unhide command. "Clear contents only" never touches column widths, row heights, or the hidden state itself.

Q. What about a sheet that's itself hidden or "very hidden"?

A. This tool only deals with hidden rows/columns inside a sheet. A sheet's own visibility is out of scope — use the sheet-visibility tool for that.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file. Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
