Excelのシートを1枚ずつ別ファイルに分けて保存

大きなブックから必要なシートだけ取り出して誰かに渡したい、シートごとに別のファイルとして保存し直したいときに。コピーを作って他のシートを1つずつ削除する作業を繰り返す代わりに、選んだシートをそれぞれ独立したExcel(.xlsx/.xlsm)ファイルに分割し、1つにまとめてZIPでダウンロードします。他のシートを参照する数式は、既定で今の計算結果の値に変換してから保存するため、参照先のシートが無くなって#REF!エラーになるのを防ぎます。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。全シートの名前・表示状態・数式を解析します。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 全シートの名前・表示状態・他のシートを参照する数式の有無が一覧表示されます（既定では全シートが選択済みです）。
  3. 分割したくないシートはチェックを外します。「全て選択」「全て解除」でまとめて切り替えられます。
  4. 必要なら「他のシートを参照する数式を値に変換してから保存する」のチェックを調整します（既定はオン）。
  5. 「選択したシートを分割してダウンロード」で書き出します。2つ以上選んだ場合は1つのZIPに、1つだけの場合はそのシートのExcelファイルを直接ダウンロードします。

Q. 他のシートを参照する数式はどうなりますか？

A. 既定（推奨）では、選んだシート以外を参照する数式を、現在Excel上で表示されている計算結果の値に変換してから保存します。元の数式は消えますが、値はそのまま残ります（計算結果が保存されていない数式は変換できず、数式のまま残ります）。オプションを外すと数式はそのまま残りますが、参照先のシートが無いファイルを開いて再計算すると#REF!エラーになることがあります。

Q. 名前定義（名前付き範囲）はどうなりますか？

A. 選んだシートだけに限定された名前定義で、参照先も選んだシートの中に収まっているものはそのまま残します（シート番号は自動で調整します）。全シート共通の名前定義、または他のシートを参照している名前定義は、分割後のファイルには含まれません。その名前を数式で使っていた場合、#NAME?エラーになることがあります。

Q. ピボットテーブルやグラフが別シートの元データを参照している場合は？

A. 元データのシートを含めずに分割すると、ピボットテーブルやグラフの部品自体は残りますが、参照先のデータが無いため正しく更新・表示されない場合があります。元データのシートも一緒に選んで分割するか、分割後に手動で確認してください。

Q. 非表示・完全非表示のシートを選んだ場合はどうなりますか？

A. 分割後のファイルではそのシートが唯一のシートになるため、Excelの仕様（最低1枚は表示シートが必要）に従い、自動的に「表示」状態に変わります。

Q. 複数シートを選んだときのダウンロード形式は？

A. 選んだシートの数だけExcelファイルを作り、1つのZIPファイルにまとめてダウンロードします（ファイル名はシート名から自動生成、同名が重複する場合は末尾に(2)などを付けます）。1つだけ選んだ場合は、ZIPを経由せずそのシートのExcelファイルを直接ダウンロードします。

Q. 元のファイルは変更されますか？

A. 変更されません。元のファイルはそのまま残り、分割後のファイルは別名で新しく書き出されます。

Q. マクロ（.xlsmファイル）でも使えますか？

A. 読み込み自体は可能で、マクロ（VBAプロジェクト）はそのまま各分割後のファイルに含まれます。ただしマクロが削除されたシートを参照する処理を含んでいる場合、分割後は正しく動作しない可能性があります。マクロを使っているファイルは、分割後に動作を確認してください。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Every sheet's name, visibility and whether it has formulas referencing other sheets are listed (all sheets are selected by default).
  3. Uncheck any sheet you don't want split out. "Select all" / "Select none" toggle them in bulk.
  4. Adjust the "convert cross-sheet formulas to values" option if needed (on by default).
  5. Click "Split selected sheets and download". Two or more sheets download as one ZIP; a single sheet downloads directly as its own Excel file.

Q. What happens to formulas that reference other sheets?

A. By default (recommended), any formula that references a sheet other than the one you kept is converted to its current calculated value before saving — the formula itself is dropped, but the value stays (a formula with no cached result can't be converted this way and is left as a formula). Turning the option off leaves the formula as-is, which can show #REF! once Excel recalculates it, since the referenced sheet is gone.

Q. What happens to named ranges?

A. A named range scoped to just the sheet you kept, whose reference also stays within that sheet, is kept (its internal sheet index is adjusted automatically). A workbook-wide named range, or one that points at another sheet, is dropped from the split file — formulas using that name may then show #NAME?.

Q. What if a PivotTable or chart's source data is on a different sheet?

A. If you split without including the source-data sheet, the PivotTable or chart itself remains, but it may not refresh or display correctly since its source is gone. Either include the source sheet too, or check manually afterward.

Q. What happens if I split a hidden or very-hidden sheet?

A. Since it becomes the only sheet in the new file, it's automatically switched to visible — Excel requires every workbook to have at least one visible sheet.

Q. What format do I get when splitting several sheets?

A. One Excel file per sheet, all bundled into a single ZIP (filenames are generated from the sheet names, with (2), (3)... appended for duplicates). If you select only one sheet, it downloads directly as its own Excel file with no ZIP step.

Q. Does this change my original file?

A. No. Your original file is left untouched; the split files are written out under new names.

Q. Does this work on macro-enabled (.xlsm) files?

A. Yes, it can read them, and the VBA project is carried into each split file unchanged. But if a macro refers to a sheet that got removed, it may no longer work correctly — test macros after splitting.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
