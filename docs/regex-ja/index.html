    使い方とよくある質問

    1. 「正規表現パターン」に調べたいパターンを入力します。必要なら i・m・s・u のフラグにチェックを入れます。
    2. 「テスト文字列」に照合したい文章を貼り付けます。「解析する」を押す（または内容を変更する）と自動で結果が更新されます。
    3. 「日本語での解説」に、パターンの意味を文章で自動生成した説明が表示されます。「マッチ箇所のハイライト」でテスト文字列中の一致箇所を確認できます。
    4. 「マッチの一覧」で各マッチの位置・キャプチャグループの中身を確認し、コピーやダウンロードができます。
    5. 「置換プレビュー」に置換後の文字列（$1 などでグループを参照可）を入れると、置換結果をその場で確認できます。

    Q. 入力した正規表現やテスト文字列はサーバーに送信されますか？

    A. いいえ。すべてこのページを開いているブラウザの中だけで処理され、通信は発生しません。

    Q. 日本語の解説はどこまで正確ですか？

    A. 文字クラス・量指定子（*, +, ?, {n,m}）・グループ・先読み/後読み・アンカーなど、よく使う構文には対応していますが、簡易的な文章生成のため、複雑なUnicodeプロパティ指定などの一部構文は省略・簡略化されることがあります。最終的な動作は必ずハイライトやマッチ一覧で確認してください。

    Q. どの正規表現の方言（フレーバー）に対応していますか？

    A. このツールはブラウザのJavaScriptの正規表現エンジンをそのまま使っています。PythonやPHP（PCRE）など他言語の正規表現とは、細かい構文が一部異なる場合があります。

    Q. マッチが0件のときはどうすればよいですか？

    A. パターンとテスト文字列の両方を確認してください。フラグ（特に大文字・小文字を区別するかどうかの i）や、日本語の全角・半角の違いが原因であることもよくあります。

    Q. グループの中身が一覧に出ないのですが？

    A. パターンに () によるキャプチャグループが含まれていない場合、グループの中身は表示されません。(?:...) は中身を取り出さない非キャプチャグループです。

    How to use & FAQ

    1. Type the pattern you want to test into "Regex pattern". Check the i / m / s / u flags if needed.
    2. Paste the text you want to match against into "Test string". Results update automatically as you type, or click "Run".
    3. "Explanation" shows an auto-generated Japanese sentence describing what the pattern means. "Match highlighting" shows where it matches inside your test string.
    4. "Match list" shows each match's position and captured groups, with copy/download options.
    5. "Replacement preview" lets you type a replacement string (using $1 etc. to reference groups) and see the result live.

    Q. Is my pattern or test string sent to a server?

    A. No. Everything runs inside your browser on this page — no network requests are made.

    Q. Why is the explanation written in Japanese?

    A. The natural-language explanation is generated in Japanese by design — it's the main feature that sets this tool apart. The rest of the interface can be switched to English.

    Q. How accurate is the explanation?

    A. It covers common syntax (character classes, quantifiers, groups, lookaround, anchors), but as a simple generator it may simplify or skip some advanced constructs (like Unicode property escapes). Always double-check with the highlighting and match list.

    Q. Which regex flavor does this use?

    A. Your browser's native JavaScript regex engine. Details can differ slightly from other languages such as Python or PHP (PCRE).
