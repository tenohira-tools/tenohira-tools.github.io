社外に送る前に確認：Excelの「隠れた情報」一括チェック

Excel(.xlsx/.xlsm)ファイルを社外に送る前に、Windows版Excelの「ドキュメント検査」は結果を一覧でまとめて見せてくれません。非表示・完全非表示シート、非表示の行や列に残った値、コメント・メモ、作成者・最終更新者・会社名、外部ファイルへのリンク、名前定義、白文字など背景と同化した書式のセルを1画面で一覧化し、該当があれば専用ツールへ案内します。読み取り専用で、ファイルは書き換えません。サーバーには送信されません。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. 7つの項目（非表示・完全非表示シート／非表示の行・列にある値／コメント・メモ／作成者・最終更新者・会社名／外部リンク／名前定義／白文字など背景と同化した書式のセル）ごとに、見つかった件数と内訳が表示されます。

Q. このツールはファイルを書き換えたり、まとめて削除したりできますか？

A. いいえ。このツールは読み取り専用の一覧化・診断だけを行い、ファイルは一切書き換えません。見つかった項目を実際に変更したい場合は、各項目に表示されるリンク先の専用ツール（非表示シートの変更はシート再表示ツール、コメントの一覧はコメント一覧化ツール、作成者名などの削除は作成者名削除ツール、外部リンクの調査は外部リンク調査ツール、名前定義の削除は名前定義点検ツール）をご利用ください。

Q. 「非表示の行・列にある値」とは何ですか？

A. 行や列を右クリックして「非表示」にした場合、Excelの画面上では消えて見えますが、セルの値自体は残ったままファイル内に保存されています。社外に送ったファイルで非表示の行・列を「再表示」されると、隠したはずの数値や文字列がそのまま見えてしまいます。このツールは非表示の行・列の範囲と、その中に実際に値が入っているセルの数を数えて知らせます（内容は一覧に出さず、件数とシート名だけを表示します）。

Q. 「白文字など背景と同化した書式のセル」はどうやって判定していますか？

A. セルの文字の色と背景（塗りつぶし）の色が、どちらも具体的な色として明示的に同じ値に設定されている場合だけを検出します（例：文字色を白、塗りつぶしも白、または文字色と塗りつぶしを同じ色に指定）。Excelのテーマの配色や「自動」設定の色までは解決していないため、見た目には同化していてもこのツールでは検出できないケースがあります。断定はせず、確認の目安としてご利用ください。

Q. Excel自体の「ドキュメント検査」（ファイル→情報→問題のチェック）と何が違いますか？

A. Excelの「ドキュメント検査」はWindows版のみの機能で、検査結果は項目ごとに別々のダイアログで表示され、削除も検査の流れの中でしかできません。このツールはブラウザだけで完結し（Mac・Windows・Chromebookを問わず使えます）、7項目を1画面で一覧表示し、該当があれば実際に変更できる専用ツールへ直接進めます。削除自体はこのツールでは行わず、各専用ツールに任せる設計です。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込みが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one (several files at once are fine too).
  2. Seven checks are run (hidden/very-hidden sheets, hidden rows/columns with values, comments/notes, creator/last-modified-by/company, external links, defined names, invisible-looking text), each showing a count and a breakdown.
  3. Any check with a hit shows a link to the dedicated tool that can inspect or remove it.
  4. Click "Export result as CSV" to save just the summary.

Q. Can this tool rewrite or bulk-remove anything?

A. No. This is a read-only inspection tool — it never rewrites your file. To actually change something it finds, follow the link to the matching dedicated tool: hidden-sheet tool for sheet visibility, comment listing tool for comments, author-name scrubber for creator/company metadata, external-link finder for external references, and defined-name tool for defined names.

Q. What does "hidden rows/columns with values" mean?

A. Right-click-hiding a row or column only hides it on screen — the cell values stay saved inside the file. If someone unhides those rows/columns after you send the file, whatever you thought was hidden is visible again. This tool counts how many hidden rows/columns actually contain a value and which sheets they're in (it does not list the actual cell contents, only counts and sheet names).

Q. How does it detect "invisible-looking text"?

A. Only cells where the font color and the cell's background (fill) color are both explicitly set to the same specific color (e.g. white text on a white fill, or any matching pair) are flagged. Excel's theme colors and "Automatic" color are not resolved, so some visually-hidden cases won't be caught. This is a conservative check, meant as a starting point, not a guarantee.

Q. How is this different from Excel's own "Document Inspector"?

A. Excel's Document Inspector is Windows-only, shows each category in its own separate dialog, and only lets you remove things from inside that same flow. This tool works in any browser (Mac, Windows, Chromebook), lists all seven checks on one screen, and links straight to a dedicated tool when you want to actually change something — it does not remove anything itself.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported — if a file fails to load, an error is shown next to it.
