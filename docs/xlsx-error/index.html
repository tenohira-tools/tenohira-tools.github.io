#REF!・#N/A・#DIV/0!が残っているセルを全部一覧に

Q. Ctrl+Hの「ブック全体」検索と何が違いますか？

A. Ctrl+Hで「#REF!」などを検索すれば1件ずつは見つかりますが、1つのファイルしか調べられず、エラーの種類ごとの内訳も出ず、一覧をそのままCSVに保存することもできません。このツールは複数ファイル・複数シートをまとめて横断し、種類別の件数とシート・セル・数式の一覧を一度に出します。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

Q. エラーはどうやって判定していますか？再計算されますか？

A. 再計算はしません。セルに保存されている値そのものが#REF!・#VALUE!・#DIV/0!などのエラー値である場合にだけ検出します。直近にExcel等で保存されたときのキャッシュ値を見ているため、ファイルを開いて保存し直すと結果が変わることがあります。数式の内容が間違っていそうでも、保存時のエラー値が残っていなければ検出できません。

Q. 「原因」欄はどこまで信用できますか？

A. エラーの種類ごとに一般的によくある原因を参考として表示しているだけで、実際の数式やデータを見て判定しているわけではありません。断定はできないため、最終的には数式バーで元の数式を確認してください。

Q. 「共有数式」の数式が出ないことがあります

A. 同じ数式を下や右にコピー（フィルハンドルでの入力）すると、Excelは内部的に基準セルの数式だけを保存し、残りのセルには「基準セルの数式を使う」という印だけを付けます（共有数式）。このツールは基準セルの数式から、相対参照（$の付いていない部分）をセルの位置のずれ分だけ自動的にずらして復元して表示します。復元した数式には推定の印を付けます。名前付き範囲が絡む数式や非常に複雑な数式では、復元結果が実際と異なる場合があるため、重要な判断には元のExcelファイルで数式バーを直接確認してください。

Q. 数式が無いのにエラーと判定されるセルがあります

A. 通常はほぼ起きませんが、他のツールで書き出されたファイルなどでは、数式を持たないセルにエラー値だけが保存されている場合があります。その場合は一覧の数式欄が空になります。

Q. マクロやグラフ、セルの色・罫線などの書式は読み取れますか？

A. いいえ。このツールはエラー値を持つセルの位置・数式・計算結果の文字列だけを読み取ります。マクロ・グラフ・画像・セルの色や罫線は扱いません。

Q. 大きなファイルや多数のファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、エラー値セルの合計が数万件程度までを想定しています。一覧の表示は先頭の一定件数のみに制限されることがありますが、ダウンロードするCSVには絞り込み後の全件が含まれます。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more (every sheet in every file is scanned automatically).
  2. Check the summary panel for the total number of error cells and the breakdown by error type.
  3. Use the filters to narrow the list down to one file, one sheet, or one error type.
  4. Click "Download as CSV" to save the list — exactly what the filters currently show.

Q. How is this different from Find & Replace across the whole workbook?

A. Ctrl+H can find "#REF!" one match at a time, but only in one file, with no breakdown by error type and no way to export the list as CSV. This tool scans multiple files and sheets at once and gives you a per-type count plus a full sheet/cell/formula list in one pass.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.

Q. How is an error detected? Is anything recalculated?

A. Nothing is recalculated. A cell is flagged only when its own stored value is itself an error value such as #REF!, #VALUE! or #DIV/0! — the cached result Excel last saved. Re-saving the file in Excel can change the result. A formula that looks wrong but whose cached result isn't an error value won't be flagged.

Q. How reliable is the "likely cause" column?

A. It shows a generic, commonly-cited cause for each error type, not an analysis of your actual formula or data. Treat it as a starting point and check the formula bar for anything important.

Q. Why does the formula column sometimes stay blank for a "shared formula"?

A. When a formula is copied down or across (e.g. with the fill handle), Excel internally stores the full formula only on one anchor cell and marks the rest as "use the anchor's formula". This tool reconstructs the formula for those other cells by shifting the anchor's relative references by the row/column offset, marking reconstructed formulas with a derived badge. Complex or name-range-based formulas may be reconstructed incorrectly.

Q. I see an error cell with no formula at all

A. Rare, but files written by other tools can sometimes store an error value in a cell with no formula attached — the formula column is left blank for those rows.

Q. Are macros, charts, or cell formatting read?

A. No — only the position, formula text and cached result of error-valued cells are read. Macros, charts, images, colors and borders are ignored.

Q. Can it handle large or many files?

A. Everything runs in browser memory, built for up to roughly tens of thousands of error cells in total. The on-screen list may be capped for performance, but the downloaded CSV always contains every row matching the current filters.
