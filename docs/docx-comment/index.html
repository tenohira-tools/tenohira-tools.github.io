文書のあちこちに散らばったWordのコメントを全部一覧に

Word(.docx)ファイルのコメントが本文のあちこちにあって、校閲の対応表として一覧にしたい・CSVでExcelに貼りたいときに。コメントが付いた箇所の文章・投稿者・日時・本文を一覧表示し、返信（スレッド）と「解決済み」の状態も含めて一括でCSV書き出しできます。ファイルはサーバーに送信されません。

使い方とよくある質問

  1. 上の枠にWord（.docx）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. 集計欄で、コメントの総数と内訳（返信／解決済み）を確認します。
  3. 絞り込みで、特定のファイル・種類に絞って一覧を確認します。
  4. 必要な一覧を「CSVでダウンロード」で保存するか、「この一覧を印刷」でそのまま印刷します（絞り込んだ内容がそのまま反映されます）。CSVはExcelでそのまま開けます。

Q. 「対象の文章」とは何ですか？空欄のことがあるのはなぜですか？

A. コメントが実際に選択していた本文の文章です。文章を選ばずにコメントを付けた場合（カーソルだけの位置に付けた場合）や、表の構造にまたがる選択など一部の特殊な範囲は、空欄「（選択範囲なし）」として表示されます。

Q. 返信（スレッドのやり取り）はどう表示されますか？

A. 元のコメントの直後に、種類欄に返信のバッジを付けて表示します。日時が記録されている場合は古い順に並びます。

Q. 「解決済み」はどうやって分かりますか？

A. Wordで「スレッドを解決」した状態がファイルに保存されている場合、元のコメント（返信ではないもの）の種類欄に解決済みのバッジを付けます。古い形式で保存されたファイルや、一部のアプリで保存されたファイルはこの情報自体を持たないため、その場合は全件「未解決」として表示されます（実際に解決済みでないという意味ではありません）。

Q. コメントを削除したい場合は？

A. このツールは一覧表示とCSV出力・印刷専用で、ファイルの書き換えは行いません。コメントをまとめて削除したい場合は複数のWordファイルの変更履歴を一括で確定するツール（コメント削除はオプション）をお使いください。投稿者名だけを消したい場合は作成者・コメント投稿者名を消すツールをお使いください（コメント本文自体は残ります）。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Word 2007以降の.docx形式に対応しています。古い.doc形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

Q. 本文・ヘッダー・フッター・脚注・文末脚注のどこに付いたコメントも対象ですか？

A. はい。本文だけでなく、ヘッダー・フッター・脚注・文末脚注に付いたコメントも一覧に含めます。

Q. 大量のコメントがあるファイルも扱えますか？

A. ブラウザのメモリ上で処理するため、1ファイルあたり数千件程度までを想定しています。一覧の表示は先頭の一定件数のみに制限されることがありますが、ダウンロードするCSVには絞り込み後の全件が含まれます。

How to use & FAQ

  1. Drag and drop a Word (.docx) file into the box above, or click it to choose one or more at once.
  2. Check the summary panel for the total count and the breakdown (replies / resolved).
  3. Use the filters to narrow the list down to one file or one type.
  4. Click "Download as CSV" to save the list, or "Print this list" to print it directly — both reflect the current filters. The CSV opens directly in Excel.

Q. What is the "commented text" column, and why is it sometimes blank?

A. It's the actual text the comment was anchored to. When a comment was added with no text selected (just a cursor position), or in a few special cases spanning table structure, it shows "(no selected text)".

Q. How are thread replies shown?

A. Each reply appears right after its parent comment, labeled with a reply badge. When timestamps are present, replies are sorted oldest first.

Q. How is "resolved" determined?

A. When Word's "Resolve thread" state is stored in the file, a root comment (not a reply) in that state gets a resolved badge. Older file formats, or files saved by some other applications, may not store this information at all — in that case every comment shows as unresolved, which does not necessarily mean it isn't actually resolved.

Q. I want to delete comments — can this tool do that?

A. No — this tool only lists, exports and prints; it never rewrites your file. To bulk-remove comments, use the tool that accepts tracked changes across multiple files (comment removal is an option there). To strip just the author names, see the creator/author name remover (the comment text itself stays).

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Word 2007+ .docx files. The older .doc format and password-protected files are not supported; a failed file shows an error next to it.

Q. Does this cover comments in headers, footers, footnotes and endnotes too?

A. Yes — not just the body. Comments anchored in headers, footers, footnotes and endnotes are included.

Q. Can it handle a file with a lot of comments?

A. Everything runs in browser memory, built for up to a few thousand comments per file. The on-screen list may be capped for performance, but the downloaded CSV always contains every row matching the current filters.
