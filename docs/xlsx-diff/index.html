2つのExcelファイルを比較：変更されたセルだけを全シート一括で色付け表示

「変更前」と「変更後」の2つのExcelファイルのどこが変わったか分からないときに。全シートを一括で比較し、追加・削除・変更されたセルだけをシート形式の色付き表示と一覧（CSVダウンロード対応）で確認できます。ファイルはどこにも送信されません。

ファイルを選択

① 変更前（古い）ファイル ドラッグ＆ドロップ、またはクリックして選択
② 変更後（新しい）ファイル ドラッグ＆ドロップ、またはクリックして選択

2つのファイルは選択した端末の中だけで読み込み・比較されます。サーバーには送信されません。

シート単位の差分サマリー

シート状態 追加削除変更

「追加」「削除」はそのシートにだけ存在していたセル、「変更」は両方のファイルに同じセル位置があり内容が異なっていたセルの数です。シート名そのものが変わった場合は「シート削除」＋「シート追加」として扱われます。

シート表示（色付き）

使い方とよくある質問

  1. 「①変更前（古い）ファイル」「②変更後（新しい）ファイル」の両方にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップ、またはクリックして選びます。
  2. 両方読み込まれると、シート単位のサマリー（追加・削除・変更セル数）が自動的に表示されます。
  3. 「シート表示」で1枚のシートを選ぶと、実際のシートに近い形で変更箇所が色付きで確認できます。
  4. 絞り込みでシート・種類・セル番地やキーワードを指定し、一覧を「CSVでダウンロード」で保存できます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。2つのファイルはいずれもサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・比較されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. どういう基準で「変更」と判定していますか？

A. 同じセル番地（例：B3）に、両方のファイルで値があり、その文字列としての内容が異なる場合に「変更」と判定します。セルの色・フォント・枠線などの書式や、数式の文字列そのものは比較しておらず、Excelが最後に保存したときの計算結果（表示される値）だけを比較します。

Q. 行や列を挿入・削除した場合はどうなりますか？

A. セルの位置（番地）だけで比較するため、行や列を挿入・削除すると、その位置より下・右にあるセルがすべて「内容が変わった」として検出されます。これは実際の値の変化ではなく、ズレによる検出です。表の途中に行を増やしたファイルを比較する場合はご注意ください。

Q. シート名を変更した場合はどうなりますか？

A. シート名の一致で同じシートとみなすため、シート名自体を変更すると「元の名前のシートが削除され、新しい名前のシートが追加された」という扱いになり、中身が同じでも全セルが差分として出ます。

Q. 日付が入ったセルはどう表示されますか？

A. Excelは日付を内部的に数値（シリアル値）として保存しており、表示形式（書式）は別に管理されています。このツールは表示形式を再現せず、保存されている数値のまま比較・表示します。そのため日付のセルが数値で表示されることがあります。

Q. 「シート表示」に何も出ないシートがあります

A. 行数・列数が多いシート（既定では200行×40列を超える場合）は、ブラウザでの表示が重くなるため「シート表示」を省略し、下の一覧でのみ確認できるようにしています。

Q. 大きなファイルや多数の差分セルは扱えますか？

A. ブラウザのメモリ上で処理するため、差分セルが数万件程度までを想定しています。一覧の表示は先頭の一定件数のみに制限されることがありますが、ダウンロードするCSVには絞り込み後の全件が含まれます。

How to use & FAQ

  1. Drag and drop (or click to choose) an Excel (.xlsx/.xlsm) file into both "① Before" and "② After".
  2. Once both are loaded, a per-sheet summary (added / removed / changed cell counts) appears automatically.
  3. Pick one sheet under "Sheet view" to see the changes highlighted in a grid close to the real worksheet layout.
  4. Use the filters to narrow by sheet, change type or a cell/keyword search, then export the list as CSV.

Q. Is it safe to use this on my files?

A. Yes. Neither file is uploaded to a server — everything is read and compared inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. How is "changed" decided?

A. When the same cell address (e.g. B3) holds a value in both files and the text content differs, it's marked "changed". Formatting (colors, fonts, borders) and the formula text itself are not compared — only the displayed/cached result Excel last saved.

Q. What happens if a row or column is inserted or deleted?

A. Comparison is purely by cell address, so inserting or deleting a row/column shifts everything below/right of it, which this tool reports as every one of those cells having "changed" — even though their actual content didn't. Be aware of this when comparing files where rows were added in the middle of a table.

Q. What if a sheet was renamed?

A. Sheets are matched by name, so renaming a sheet is reported as the old name being removed and the new name being added — with every cell in it, even if nothing inside actually changed.

Q. How are date cells shown?

A. Excel stores dates internally as a plain number (a serial value); the date format is separate. This tool doesn't reproduce formatting, so a date cell may show up as a plain number.

Q. Why does "Sheet view" show nothing for some sheets?

A. A sheet with a very large row/column extent (over 200 rows × 40 columns by default) skips the grid view for performance — use the list below instead.

Q. Can it handle large files or many differences?

A. Everything runs in browser memory, built for up to roughly tens of thousands of differing cells. The on-screen list may be capped for performance, but the downloaded CSV always contains every row matching the current filters.
