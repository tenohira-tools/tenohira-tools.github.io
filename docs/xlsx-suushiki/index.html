引き継いだExcelの数式を一覧に

引き継いだファイルの数式がどこに入っているか分からないときに。数式が入ったセルを、ファイルを開かずシート・セルごとに一覧表示します。計算結果がエラーのまま残っているセル、他シートを参照しているセル、外部ファイルを参照している可能性があるセルを自動で見分けます。ファイルはどこにも送信されません。

すべてのシートの数式セルをまとめて抜き出します。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル・複数シートも自動でまとめて読み込みます）。
  2. 集計欄で、数式セルの総数・エラー数・他シート参照数・外部参照の可能性がある数を確認します。
  3. 絞り込みで、特定のファイル・シートや「エラーのみ」などに絞って一覧を確認します。
  4. 必要な一覧を「CSVでダウンロード」で保存します（絞り込んだ内容がそのまま書き出されます）。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

Q. 「計算結果」はどこから出てきますか？再計算されますか？

A. 再計算はしません。直近にExcel等で保存されたときに、数式の横に保存されていた計算結果（キャッシュされた値）をそのまま表示します。ファイルを開いて保存し直すと更新されます。保存されていない場合は空欄になります。

Q. 「エラー」欄はどうやって判定していますか？

A. セルに保存されている値が #REF!・#VALUE!・#DIV/0! のようなエラー値そのものである場合にチェックが付きます。数式の内容が間違っていそうでも、保存時のエラー値が残っていなければ検出できません。

Q. 「共有数式」の扱いはどうなっていますか？

A. 同じ数式を下や右にコピー（フィルハンドルでの入力）すると、Excelは内部的に基準セルの数式だけを保存し、残りのセルには「基準セルの数式を使う」という印だけを付けます（共有数式）。このツールは基準セルの数式から、相対参照（$の付いていない部分）をセルの位置のずれ分だけ自動的にずらして復元して表示します。復元した数式には推定の印を付けます。名前付き範囲が絡む数式や非常に複雑な数式では、復元結果が実際と異なる場合があるため、重要な判断には元のExcelファイルで数式バーを直接確認してください。

Q. 「他シート参照」「外部参照の可能性」はどうやって判定していますか？

A. 数式の文字列を機械的に走査し、「シート名!」のような他シートを指す書き方や、「[1]」「[ファイル名.xlsx]」のような外部ワークブックによく使われる書き方が含まれているかで判定しています。文字列の形だけを見た簡易判定のため、誤って検出したり、逆に見逃したりすることがあります。外部参照が疑われるセルは、Excel側の「データ」タブの「リンクの編集」で確認することをおすすめします。

Q. 配列数式やデータテーブルはどう表示されますか？

A. 数式の種類ごとに印を付けて区別します。配列数式（CSE数式・動的配列数式）は結果が複数セルに広がる場合がありますが、このツールは数式が保存されているセル（通常は先頭セル）だけを一覧に出します。

Q. マクロやグラフ、セルの色・罫線などの書式は読み取れますか？

A. いいえ。このツールは数式と計算結果の文字列だけを読み取ります。マクロ・グラフ・画像・セルの色や罫線は扱いません。

Q. 大きなファイルや多数のファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、数式セルの合計が数万件程度までを想定しています。非常に多い場合は読み込み・表示が遅くなることがあります。一覧の表示は先頭の一定件数のみに制限されることがありますが、ダウンロードするCSVには絞り込み後の全件が含まれます。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more (every sheet in every file is scanned automatically).
  2. Check the summary panel for the total number of formula cells, cached errors, cross-sheet references, and possible external references.
  3. Use the filters to narrow the list down to one file, one sheet, errors only, and so on.
  4. Click "Download as CSV" to save the list — exactly what the filters currently show.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.

Q. Where does the "result" value come from? Is it recalculated?

A. Nothing is recalculated. It shows the cached value Excel last saved alongside the formula. Re-saving the file in Excel updates it; if no cached value was ever saved, the cell shows blank.

Q. How is "error" detected?

A. It's checked when the cell's stored value is itself an error value such as #REF!, #VALUE!, or #DIV/0!. A formula that looks wrong but whose cached result isn't an error value won't be flagged.

Q. How are "shared formulas" handled?

A. When a formula is copied down or across (e.g. with the fill handle), Excel internally stores the full formula only on one anchor cell and marks the rest as "use the anchor's formula". This tool reconstructs the formula for those other cells by shifting the anchor's relative references ($-free parts) by the row/column offset, and marks reconstructed formulas with a derived badge. Formulas involving named ranges or unusually complex expressions may be reconstructed incorrectly, so double-check anything important directly in Excel's formula bar.

Q. How are "cross-sheet" and "possible external reference" detected?

A. By scanning the formula text for patterns like "SheetName!" (cross-sheet) or "[1]" / "[filename.xlsx]" (common external-workbook reference syntax). This is a simple text-pattern check, so it can both over- and under-detect. For anything flagged as a possible external reference, check Excel's Data → Edit Links to be sure.

Q. What about array formulas and data tables?

A. Each formula's type is labeled. Array formulas (legacy CSE or dynamic arrays) may spill results across multiple cells, but only the cell where the formula itself is stored (usually the top-left one) is listed.

Q. Are macros, charts, or cell formatting read?

A. No — only formula text and cached result text are read. Macros, charts, images, colors and borders are ignored.

Q. Can it handle large or many files?

A. Everything runs in browser memory, built for up to roughly tens of thousands of formula cells in total. The on-screen list may be capped to the first batch of rows for performance, but the downloaded CSV always contains every row matching the current filters.
