CSVのコード→名称 一括変換ツール

データCSVと、コード・名称などの対応表（マスタ）CSVを読み込むと、データ側のコード列を対応表で突き合わせて、名称などの列を一括で追加します。一致しなかった行は空欄のまま一覧表示されるので、見落としや誤った推測が起きません。ファイルはどこにも送信されません。

ダウンロード設定

使い方とよくある質問

  1. ①に変換したいデータのCSV、②にコードと名称などの対応表（マスタ）CSVを、それぞれドラッグ＆ドロップまたはクリックして選びます。
  2. ③で、データ側・対応表側それぞれの「キー（コード）となる列」を選び、対応表から追加したい列（名称など、複数可）にチェックを入れます。
  3. ④で一致・不一致の件数を確認します。一致しなかったキーがある場合は一覧に表示されるので、入力ミスや対応表の漏れに気づけます。
  4. ⑤でプレビューを確認し、「変換してCSVをダウンロード」を押します。

Q. どんな場面で使えますか？

A. 例えば、売上データの「店舗コード」列に対し、店舗コード→店舗名の対応表を使って「店舗名」列を追加する、担当者コード→氏名、部門コード→部門名のような変換に使えます。表計算ソフトのVLOOKUP関数で行うような突き合わせを、Excelを開かずブラウザだけで行えます。

Q. 一致しなかった行はどうなりますか？

A. 推測で埋めることはせず、追加した列を空欄のままにします。一致しなかったキーの値（最大50種類）を一覧表示するので、データ側の入力ミスや、対応表に登録が無いコードを見つけられます。

Q. キーの表記が多少違っても一致させられますか？

A. 「照合時に全角／半角の違いと前後の空白を無視する」をONにすると、「Ａ０１」と「A01」、「A01 」と「A01」のような表記の違いがあっても同じキーとして扱います。それでも一致しない場合は、本当にキーが異なるか、対応表に無いことが多いです。ダウンロードされる値そのもの（元の表記）は変換されません。この照合はキーの比較だけに使われます。

Q. 対応表の中でキーが重複しているとどうなりますか？

A. 同じキーが対応表に複数回出てきた場合は、先に出てきた行の値を使い、何件重複していたかを件数で表示します。対応表は一つのキーにつき一行になっているものを想定しています。

Q. アップロードしても安全ですか？

A. はい。2つのファイルともサーバーに送信されず、すべてこのブラウザの中で処理されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 大きなファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、データ・対応表合わせて数十MB程度までを想定しています。対応表はキーの一覧として数千〜数万行程度までが目安です。

How to use & FAQ

  1. Drop or choose the data CSV you want to convert in ①, and the lookup-table (master) CSV with codes and names in ②.
  2. In ③, pick the key (code) column on each side, and check the master columns (e.g. names) you want to add.
  3. In ④, check how many rows matched and how many didn't. Unmatched keys are listed so you can spot typos or missing master entries.
  4. Review the preview in ⑤, then click "Convert and download CSV".

Q. What is this useful for?

A. For example, adding a "store name" column to sales data that only has a "store code", using a code→name lookup table — the same kind of join a VLOOKUP formula does, done entirely in the browser without opening Excel.

Q. What happens to rows that don't match?

A. Nothing is guessed — the added columns are left blank. Up to 50 distinct unmatched key values are listed so you can catch typos in the data or missing entries in the lookup table.

Q. Can it match keys that are formatted slightly differently?

A. With "ignore full/half-width and surrounding spaces when matching" on, keys like "Ａ０１" and "A01", or "A01 " and "A01", are treated as the same key. This only affects the comparison — the downloaded value keeps its original formatting.

Q. What if the lookup table has duplicate keys?

A. The first matching row is used, and the number of duplicate keys skipped is shown. The tool assumes the lookup table has one row per key.

Q. Is it safe to use this on my files?

A. Yes. Neither file is uploaded to a server — everything happens inside this browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Can it handle large files?

A. Everything runs in browser memory, so it's built for a combined size of up to tens of megabytes, with a lookup table of up to roughly tens of thousands of rows.
