CSVを列の値ごとに自動分割

1つのCSVファイルを、選んだ列の値ごとに自動でグループ分けして複数のCSVに分け、まとめてZIPでダウンロードします。行数や件数で機械的に割るのではなく「同じ都道府県・同じ店舗・同じ担当者の行を1つのファイルにまとめる」分割です。文字コードはファイルを自動判定します。ファイルはどこにも送信されません。

使い方とよくある質問

  1. 上の枠にCSVファイルを1つドラッグ＆ドロップするか、クリックして選びます。文字コードは自動判定されます（おかしい場合は右のプルダウンで手動選択できます）。

  3. プレビューで、どんなグループに分かれ、各グループが何件になるかを確認します。

Q. 行数や件数で均等に分割するツールと何が違いますか？

A. 世の中の「CSV分割」ツールの多くは、行数や分割数を指定して機械的に割るものです。このツールは逆に、選んだ列（例：都道府県、店舗名、担当者）の値が同じ行どうしを集めて1つのファイルにする「グループ分割」です。業務ソフトの一括帳票生成機能にある「キーフィールドごとの分割」と同じ考え方を、無料のブラウザツールとして単体で使えるようにしたものです。

Q. 複数の列を選ぶとどうなりますか？

A. 選んだすべての列の値の組み合わせが同じ行どうしをまとめます。例えば「店舗」と「担当者」の2列を選ぶと、同じ店舗でも担当者が違えば別のファイルになります。

Q. 選んだ列の値が空欄の行はどうなりますか？

A. 空欄どうしの行は「(空欄)」という1つのグループにまとめられ、他のグループと同じようにファイルになります。行が消えたり無視されたりすることはありません。

Q. ファイル名はどうなりますか？

A. 既定では「元のファイル名_グループの値.csv」になります（例：元が「売上.csv」で都道府県列が「東京都」なら「売上_東京都.csv」）。ファイル名に使えない記号（/ \ : * ? " < > |）は自動で「_」に置き換えます。置き換えた結果、同じファイル名になってしまう場合は「(2)」のように番号を付けて区別します。

Q. ZIPファイルの中身は、各ファイルとも見出し行付きですか？

A. はい。「1行目を見出しとして扱う」がONの場合、分割後の各CSVにも同じ見出し行が先頭に入ります。OFFの場合は見出しを付けず、データ行のみで分割します。

Q. 生成されるZIPファイルは特別なアプリが無いと開けませんか？

A. いいえ。Windows・Mac・スマートフォンそれぞれの標準の解凍機能で開ける、一般的なZIP形式（無圧縮・UTF-8ファイル名）で作成しています。

Q. ファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、グループ分けもZIPの作成もすべてこのブラウザの中だけで行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 大きなファイルやグループ数が多い場合は？

A. ブラウザのメモリ上で処理するため、数十MB程度・グループ数が数百程度までを想定しています。グループ数が極端に多い（1000を超えるなど）場合は、生成に時間がかかったりブラウザが重くなったりすることがあります。

How to use & FAQ

  1. Drag and drop a single CSV file into the box above, or click it to choose one. Its character encoding is auto-detected (override it with the dropdown on the right if it looks wrong).
  2. Choose whether the first row is a header, then click to select one or more columns to group by.
  3. Check the preview to see how many groups were found and how many rows are in each.
  4. Click "Download as ZIP" to get a single ZIP file containing one CSV per group.

Q. How is this different from tools that split by row count?

A. Most free "CSV split" tools cut a file mechanically by a row count or a number of pieces. This tool instead groups rows that share the same value in the column(s) you pick (e.g. prefecture, store, person in charge) into one file each — the same idea as the "split by key field" feature found in business document-generation software, as a free standalone browser tool.

Q. What happens if I select more than one column?

A. Rows are grouped by the combination of all selected columns' values. For example, selecting both "store" and "person in charge" puts rows from the same store but a different person into separate files.

Q. What happens to rows where the selected column is blank?

A. Rows with a blank value in every selected column are collected into a single "(blank)" group and still get their own file — nothing is dropped or ignored.

Q. How are output filenames generated?

A. By default: "<original filename>_<group value>.csv" (e.g. a source file "sales.csv" with prefecture "Tokyo" becomes "sales_Tokyo.csv"). Characters not allowed in filenames (/ \ : * ? " < > |) are replaced with "_"; if that causes two group names to collide, a "(2)" suffix is added to tell them apart.

Q. Does every split file include the header row?

A. Yes, when "treat the first row as a header" is on, every split file gets the same header row prepended. When off, files contain only data rows.

Q. Do I need special software to open the ZIP?

A. No. It's built using the standard ZIP format (stored, UTF-8 filenames), openable with the built-in unzip feature on Windows, Mac, and phones.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded — grouping and ZIP creation both happen entirely inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. What about very large files or a huge number of groups?

A. Everything runs in browser memory, so it's built for files up to tens of megabytes and up to a few hundred groups. An extreme number of groups (say, over 1000) may be slow or make the browser tab heavy.
