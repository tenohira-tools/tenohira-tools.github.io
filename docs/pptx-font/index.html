別のPCで文字化け・レイアウト崩れする原因を確認：使用フォント一覧

PowerPoint(.pptx)ファイルの各スライド・各スライドマスターで実際に指定されているフォントを一覧化します。「テーマのフォント」への参照（+mn-lt等）は実際のフォント名に解決し、スライド側で直接指定（上書き）されたフォントとは区別して表示します。標準の「フォントの置換」ダイアログでは分からない使用箇所（スライド番号）も確認できます。フォントの埋め込み状況も表示します。ファイルを開かず、ブラウザの中だけで診断します。

ここにPowerPoint(.pptx)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。.pptxのみ対応（.ppt・パスワード保護は読み込めません）。ファイルは選択した端末の中だけで処理されます。

全体の概要

マスターごとのテーマフォント（既定値）

フォントを個別に指定していない文字は、そのスライドが使っているマスター（テーマ）のこの既定フォントで表示されます。「（未設定）」は、開くPCの環境によって実際に使われるフォントが変わる可能性がある項目です。

フォント使用一覧（スライド・マスター別）

各スライド・マスターのXMLに実際に記録されているフォント指定を集計しています。「直接指定」はテーマと無関係にその場所だけで上書きされたフォントで、別のPCに同じフォントが入っていないと表示が変わりやすい項目です。

使い方とよくある質問

  1. 上の枠にPowerPoint（.pptx）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 「マスターごとのテーマフォント」で、そのファイルのテーマが本来使うはずのフォント（見出し用・本文用、欧文・日本語）を確認します。「（未設定）」があれば、PC環境によって表示フォントが変わりうる箇所です。
  3. 「フォント使用一覧」で、実際にスライド・マスターに記録されているフォント指定を、どのスライドで使われているか（使用箇所）付きで確認します。「直接指定」で「未埋め込み」のフォントが、別のPCで文字化け・崩れる最も可能性の高い原因です。
  4. 必要ならCSVでダウンロードして記録に残せます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込みが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。ファイルの内容を書き換えたり保存したりすることもありません。

Q. 標準の「フォントの置換」ダイアログと何が違いますか？

A. PowerPoint（ホーム→フォントの置換）は、ファイル全体で使われているフォント名を一覧で出せますが、「どのスライドで使われているか」は表示されず、テーマ経由で使われているフォントと、そのスライドだけで直接指定されたフォントの区別もできません。このツールは、使用箇所（スライド番号・マスター）と、テーマ参照か直接指定かの区別を併せて表示するため、原因になっているフォントがどこにあるのかを特定しやすくなります。

Q. 「テーマ参照」と「直接指定」の違いは何ですか？

A. PowerPointのテーマ（デザイン→バリエーション→フォント）で選んだフォントは、ファイル内部では「+mn-lt」「+mj-ea」のような記号（プレースホルダー）で記録され、実際のフォント名はテーマ側に別途記録されています。このツールはこの記号を実際のフォント名に変換（解決）して表示します。一方、「直接指定」は、文字を選んでフォントを個別に変更した場合などに、テーマと無関係にその場所だけフォント名がそのまま書き込まれているものです。他の資料からコピーした文章にありがちで、受け取った側のPCにそのフォントが入っていないと、近い別のフォントに自動で置き換えられて見た目が変わることがあります。

Q. テーマフォントが「（未設定）」になっているのはなぜですか？

A. テーマによっては、日本語（全角）用や複合文字用のフォントが設定されておらず、空欄になっていることがあります。この場合、実際にどのフォントで表示されるかはPowerPointやOSの既定フォントに委ねられるため、作成時のPCと閲覧時のPCで見た目が変わりやすくなります。デザイン→バリエーション→フォント→「フォントのカスタマイズ」から日本語用フォントを明示的に設定すると解消できます。

Q. 「埋め込み」とは何ですか？どうすれば埋め込めますか？

A. PowerPointには、使っているフォント自体をファイルの中に保存する「フォントの埋め込み」機能があります（ファイル→オプション→保存→「ファイルにフォントを埋め込む」）。埋め込まれていれば、そのフォントが入っていないPCで開いても見た目が変わりません。このツールは、ファイル内に埋め込みフォントがあるかどうかと、一覧にある各フォントが埋め込まれているかどうかを表示します。なお埋め込みはファイル容量を増やすため、既定では無効になっていることが多いです。

Q. マスター（テーマ）が複数あるのはなぜですか？

A. 別のテンプレートで作ったスライドを後から1つのファイルにまとめた場合などに、スライドマスター（テーマ）が複数残ることがあります。マスターごとにテーマフォントが異なる場合、同じファイルの中でもスライドによって既定フォントが違うことになります。

Q. 対応しているファイル形式は？ファイルサイズの上限はありますか？

A. PowerPoint 2007以降の.pptx形式に対応しています。古い.ppt形式や、パスワードで保護されたファイルは読み込めません。ファイルはブラウザのメモリ上で処理するため、非常に大きいファイル（数百MB以上）では診断に時間がかかることがあります。

Q. 結果の通りに直せば文字化けは必ず直りますか？

A. このツールは診断のみで、ファイルを書き換えることはしません。また、スライドの文字の中でフォントを個別指定も直接指定もしていない（上の一覧に出てこない）文字は、テーマの既定フォントがそのまま使われています。実際に直すには、PowerPoint側でフォントの置換や埋め込みを行う必要があります。

How to use & FAQ

  1. Drag and drop a PowerPoint (.pptx) file into the box above, or click it to choose one.
  2. Check "Theme fonts per master" to see the fonts the file's theme is actually supposed to use (heading/body, Latin/East Asian). A "(not set)" entry means the rendered font can vary by PC.
  3. Check "Font usage" to see exactly which font is recorded where (which slide), and whether it's a theme reference or a direct override. A directly-specified, non-embedded font is the most likely cause of a file looking different on another PC.
  4. Download the list as CSV if you need a record.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter). The file's contents are never modified or saved anywhere.

Q. How is this different from PowerPoint's own "Replace Fonts" dialog?

A. PowerPoint's Replace Fonts dialog (Home → Replace Fonts) lists font names used somewhere in the file, but it doesn't show which slide each one is on, and it doesn't distinguish a font reached through the theme from one directly overridden on that one slide. This tool shows both the location (slide number / master) and whether each entry is a theme reference or a direct override, making it easier to track down exactly where a problem font lives.

Q. What's the difference between "theme reference" and "direct override"?

A. A font chosen through PowerPoint's theme (Design → Variants → Fonts) is stored internally as a placeholder symbol like "+mn-lt" or "+mj-ea", with the real font name recorded separately in the theme. This tool resolves that symbol back to the real font name. A "direct override", on the other hand, is a font name written directly at that one spot — typically from selecting text and changing its font manually, or from pasted-in text that brought its own font along. If the recipient's PC doesn't have that exact font, it gets silently substituted with something else, which is a common cause of a file looking different elsewhere.

Q. Why does a theme font show as "(not set)"?

A. Some themes leave the East Asian or complex-script font blank. In that case, which font actually renders is left up to PowerPoint/the OS's own default, so the look can differ between the PC that made the file and the PC viewing it. Setting it explicitly via Design → Variants → Fonts → "Customize Fonts" fixes this.

Q. What does "embedded" mean, and how do I embed a font?

A. PowerPoint can save the actual font data inside the file itself (File → Options → Save → "Embed fonts in the file"). An embedded font displays correctly even on a PC that doesn't have it installed. This tool reports whether the file has any embedded fonts at all, and whether each font in the list is among them. Embedding increases file size, so it's usually off by default.

Q. Why would there be more than one master/theme?

A. Combining slides from different templates into one file later on commonly leaves more than one slide master (theme) behind. If their theme fonts differ, the default font can differ from slide to slide within the same file.

Q. Which formats and sizes are supported?

A. PowerPoint 2007+ .pptx files. The older .ppt format and password-protected files are not supported. Everything runs in your browser's memory, so very large files (several hundred MB) may take a while to diagnose.

Q. If I act on the results, is the garbling guaranteed to be fixed?

A. This tool only diagnoses — it never modifies your file. Also, any text that has no explicit or direct font setting (and so doesn't appear in the list above) simply uses the theme's default font as-is. Actually fixing things requires replacing fonts or embedding them in PowerPoint itself.
