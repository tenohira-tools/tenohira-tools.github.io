ダウンロード設定

使い方とよくある質問

  1. 上の枠にCSVファイルをドラッグ＆ドロップするか、クリックして選びます。文字コードが自動判定されます（違う場合は手動で選び直せます）。
  2. 1行目が見出し行かどうかを確認します（既定でON）。
  3. 列ごとに「全角英数字→半角」「半角カタカナ→全角カタカナ」「郵便番号を123-4567に統一」「ハイフン類を半角に統一」「前後の空白を削除」から変換方法を選びます。プレビューで変わったセルが赤字で表示されます。
  4. 「変換してCSVをダウンロード」を押すと、選んだ変換をすべての行に適用したCSVがダウンロードされます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで変換されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 「郵便番号を123-4567に統一」は何をしていますか？

A. セルの中の全角数字を半角に変換したうえで数字だけを取り出し、ちょうど7桁のときだけ「123-4567」の形式にハイフンを入れ直します。7桁でない場合はハイフンを入れず、全角→半角の変換のみ行います（誤った桁のデータを勝手に作らないため）。

Q. 「ハイフン類を半角に統一」は電話番号の桁を正しく揃えてくれますか？

A. いいえ。全角ハイフンや長音記号（－・ー・―など）を半角の「-」に統一するだけで、ハイフンの位置を新しく作ったり市外局番を判定したりはしません。すでに入っているハイフンの見た目をそろえる用途です。

Q. 変換した内容が正しいか確認するには？

A. ダウンロード前にプレビュー表を確認してください。変換で値が変わったセルは赤字で表示されます。列ごとに変換方法の下に「◯件変更」という件数も出ます。

Q. 大きなファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、数十MB程度までを想定しています。非常に大きなファイルでは表示が遅くなる場合があります。

How to use & FAQ

  1. Drag and drop a CSV file into the box above, or click it to choose one. The character encoding is auto-detected (you can override it manually).
  2. Check whether the first row is a header row (on by default).
  3. For each column, choose a transform: full-width → half-width alphanumerics, half-width → full-width katakana, unify postal codes to 123-4567, unify hyphen-like characters to a plain "-", or trim leading/trailing spaces. Cells that changed are shown in red in the preview.
  4. Click "Convert and download CSV" to download a file with the chosen transforms applied to every row.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is converted inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. What does "unify postal codes to 123-4567" actually do?

A. It converts full-width digits to half-width, extracts the digits, and only inserts a hyphen as "123-4567" when there are exactly 7 digits. If there aren't exactly 7 digits, it leaves the hyphen alone and only normalizes the digit width — it never invents digits to force a match.

Q. Does "unify hyphen-like characters" fix phone number formatting?

A. No. It only normalizes full-width hyphens, dashes and long vowel marks (－・ー・― etc.) to a plain half-width "-". It doesn't add new hyphens or figure out area codes — it just makes existing hyphens look consistent.

Q. How do I check the conversion is correct?

A. Check the preview table before downloading. Cells whose value changed are shown in red, and each column shows how many cells it changed.

Q. Can it handle large files?

A. Everything runs in browser memory, so it's built for files up to tens of megabytes. Very large files may make the page slower.
