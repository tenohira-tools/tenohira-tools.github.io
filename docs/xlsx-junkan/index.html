循環参照の警告が消えない・どこにあるか分からないときに

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも可）。
  2. 集計欄で、見つかった循環参照グループの数・関係するセル数・反復計算の設定（ON/OFF）を確認します。
  3. 絞り込みで、特定のファイル・シートに絞って一覧を確認します。
  4. 各グループに含まれるセルと数式を確認し、必要なら「CSVでダウンロード」で保存します。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. Excel自体の「循環参照」警告と何が違いますか？

A. Excelは数式タブのエラーチェックから循環参照のセルを確認できますが、ステータスバーの表示は基本的に1件ずつで、別シートにある循環参照は番地が出ず「循環参照」という表示だけになることがあります。また「反復計算」が設定でONになっていると、循環参照があっても警告自体が表示されません（計算が収束しているように見えてしまいます）。このツールはExcelの警告表示に頼らず、保存されている全シートの数式そのものを読み取って参照関係を解析するため、反復計算の設定に関係なく、ファイル内の循環参照をまとめて一覧化できます。

Q. 「循環参照グループ」とは何ですか？

A. 数式が互いに参照し合っていて、どこかを起点に辿ると自分自身に戻ってくるセルの集まりです。1つのセルが自分自身を参照する場合（例：A1に「=A1+1」）も、複数のセルが輪になって参照し合う場合（例：A1が「=B1+1」、B1が「=A1+1」）も、同じグループとして一覧に出します。SUMのような範囲を合計する数式が、その範囲に自分自身のセルを含んでいる場合も検出します（例：A1に「=SUM(A1:A3)」）。

Q. 反復計算（イタレーション）がONのファイルも検出できますか？

A. できます。このツールは数式の値を実際に計算するのではなく、数式の文字列から「どのセルがどのセルを参照しているか」という関係だけを読み取って判定します。反復計算がONかOFFかに関係なく、参照関係として循環しているセルはすべて検出し、集計欄にファイルの反復計算の設定（ON/OFF）も表示します。反復計算が意図的に使われている設計（収束計算など）のファイルでは、検出された循環参照が問題ではなく仕様である場合もあるため、表示された一覧をもとにご自身で判断してください。

Q. 名前定義（名前付き範囲）を使った数式も解析できますか？

A. 名前定義そのものの参照先は解決していません。数式内に名前付き範囲が使われている場合、その参照は循環の判定に含まれないため、名前付き範囲を経由した循環参照は検出できないことがあります。また逆に、大文字3文字以内＋数字という名前（例："TAX2024"のような名前）がセル番地と似た形のため、セル参照と誤って判定されることがあります。

Q. 複数シートをまとめて参照する「3D参照」（例：Sheet1:Sheet3!A1）は扱えますか？

A. 3D参照を検出した場合は件数だけ表示し、その参照自体は循環判定の対象外としています（どのシートのどのセルを指すか展開していません）。3D参照を使った数式が多いファイルでは、見つかった循環参照の一覧が実際より少なくなる可能性があります。

Q. 配列数式やデータテーブル、マクロは扱えますか？

A. 数式と、塗りつぶしコピーで作られた「共有数式」（基準セルの数式から自動的に復元）は解析対象です。配列数式は数式が保存されているセルのみを対象にします。マクロ・グラフ・画像・書式は読み取りません。

Q. 大きなファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、数式セルの合計が数万件程度までを想定しています。範囲参照（SUMなど）1件ごとに、同じシート内の数式セルと照合する処理のため、数式セルが非常に多いシートでは解析に時間がかかることがあります。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more.
  2. Check the summary panel for the number of circular-reference groups found, how many cells are involved, and whether iterative calculation is on.
  3. Use the filters to narrow the list down to one file or one sheet.
  4. Review the cells and formulas in each group, then click "Download as CSV" to save the list if needed.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. How is this different from Excel's own circular-reference warning?

A. Excel's Formulas tab can show circular-reference cells, but the status-bar message generally shows one at a time, and a circular reference on another sheet may show up only as a bare "Circular Reference" message with no cell address. Also, when iterative calculation is turned on, Excel suppresses the warning entirely even though the circular reference still exists — the sheet just looks like it calculated fine. This tool reads the saved formulas directly from every sheet and analyzes the reference relationships itself, so it lists every circular-reference group in the file regardless of the iterative-calculation setting.

Q. What counts as a "circular-reference group"?

A. A set of cells whose formulas refer to each other in a loop — starting from any one of them and following the references eventually leads back to itself. This includes a single cell referencing itself (e.g. A1 = "=A1+1") and several cells referencing each other in a ring (e.g. A1 = "=B1+1", B1 = "=A1+1"), reported as one group either way. A range-summing formula like SUM that includes its own cell in the range (e.g. A1 = "=SUM(A1:A3)") is also detected.

Q. Does it work on files with iterative calculation turned on?

A. Yes. This tool doesn't actually compute formula values — it only reads which cells each formula's text refers to, and checks whether that reference graph loops back on itself. That check doesn't depend on the iterative-calculation setting, so every structurally circular group is listed either way, and the summary panel also shows whether iterative calculation is on in the file. Some workbooks use iterative calculation intentionally (convergence-style models), in which case a detected "circular reference" may be by design rather than a mistake — use your own judgment based on the list shown.

Q. Does it handle defined names (named ranges)?

A. No — a defined name's target isn't resolved, so a circular reference that only exists through a named range may be missed. Conversely, a name that happens to look like a cell address (such as "TAX2024": up to 3 letters followed by digits) may be mistaken for one.

Q. What about 3D references across multiple sheets (e.g. Sheet1:Sheet3!A1)?

A. These are detected and counted, but not expanded into actual sheet/cell targets, so they're excluded from the cycle analysis itself. Files that rely heavily on 3D references may show fewer circular references than actually exist.

Q. Are array formulas, data tables, or macros handled?

A. Formulas and "shared formulas" created by filling/copying (reconstructed from the anchor cell) are analyzed. For array formulas, only the cell where the formula itself is stored is considered. Macros, charts, images and formatting are not read.

Q. Can it handle large files?

A. Everything runs in browser memory, built for up to roughly tens of thousands of formula cells in total. Each range reference (like a SUM range) is checked against every formula cell on that same sheet, so sheets with a very large number of formula cells may take a while to analyze.
