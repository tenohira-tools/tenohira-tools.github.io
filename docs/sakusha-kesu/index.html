社外に渡す前に、Excel・Word・PowerPointの「作成者・最終更新者・コメントの投稿者名」を消す

取引先や社外にファイルを渡す前に、Excel(.xlsx/.xlsm)・Word(.docx)・PowerPoint(.pptx)のプロパティに残っている「作成者」「最終更新者」、コメントの「投稿者名」（社内のメールアドレスが入っている場合もあります）、Wordの「変更履歴（校閲）」に残る編集者名を消したい、というときに。複数のファイル・3つの形式をまとめて一括処理できます。ファイルはサーバーに送らず、すべてこのブラウザの中だけで書き換えます。元のファイルは変更しません。

ここにExcel・Word・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.xlsx / .xlsm / .docx / .pptx に対応。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

読み込んだファイル

使い方とよくある質問

  1. 上の枠にExcel/Word/PowerPointファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. 各ファイルについて、見つかった作成者・最終更新者・会社名・コメントの投稿者名が表示されます。消したい項目にチェックを入れたまま（既定でチェック済み）「書き出す」を押すとダウンロードされます。元のファイルはそのまま残ります。

Q. 具体的にどこを消しますか？

A. ファイル内部のdocProps/core.xml（ファイルのプロパティ）にある「作成者」「最終更新者」、docProps/app.xml（詳細プロパティ）にある「会社名」「所属部門」、そしてコメント機能の投稿者一覧（Excelのコメント作成者、Wordのコメント投稿者とその表示名、PowerPointのコメント投稿者）です。これらはExcel/Wordの「ファイル」→「情報」画面やコメント欄に表示される情報で、ファイルの外から見える形で残っています。

Q. コメント本文や、数式・文章の内容は消えませんか？

A. 消えません。消すのは投稿者の「名前」だけで、コメント本文やセルの値・数式・文章・書式など、他のすべての内容はそのまま残ります。

Q. 100%完全に消えますか？

A. 「作成者」「最終更新者」「会社名」「所属部門」は確実に消せます。コメントの投稿者名も、昔からある形式（レガシー形式）は確実に消せます。ただし、最近のExcel/Wordの「スレッド形式」コメント機能では、投稿者名の保存場所がファイルによって異なることがあり、このツールは主な保存場所（Wordのpeople.xml、Excelのpersons/person.xml）も分かる範囲で追加処理しますが、100%の除去は保証できません。社外に渡す前の最終確認として、Excel/Wordの「ドキュメント検査」機能も併用することをおすすめします。また、Wordの「変更履歴の記録（校閲機能）」に残る編集者名（挿入・削除・書式変更などに記録されるw:author属性）も、本文・ヘッダー・フッター・脚注・文末脚注を対象にベストエフォートで消去します（下の「変更履歴（校閲）の編集者名も消す」のチェックで切り替え可能。100%の網羅は保証できません）。

Q. 対応しているファイル形式は？

A. Excel(.xlsx/.xlsm)、Word(.docx)、PowerPoint(.pptx)です。古い.xls/.doc/.ppt形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_匿名化済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop Excel/Word/PowerPoint files into the box above, or click it to choose (multiple files are fine).
  2. Each file shows its detected creator, last-modified-by, company and comment-author names. Keep the boxes checked (checked by default) for what you want cleared and click "Build" to download it. Your original file is untouched.

Q. Exactly what does this remove?

A. Inside the file's docProps/core.xml (file properties): the "creator" and "last modified by" fields. Inside docProps/app.xml (extended properties): "Company" and "Manager". And the comment-author list for each format: Excel's legacy comment authors, Word's comment author name, and PowerPoint's comment author name. These are exactly the fields shown in Word/Excel's "File > Info" screen and in the comment pane, and they stay attached to the file even after you think you've deleted a comment's visible text.

Q. Does it touch comment text, formulas, or document content?

A. No. Only the author's name is cleared. Comment bodies, cell values and formulas, document text, formatting — everything else is left exactly as it was.

Q. Is removal 100% guaranteed?

A. The creator, last-modified-by, Company and Manager fields are reliably cleared. Legacy-style comment authors are reliably cleared too. However, recent Excel/Word "threaded" comment features can store the author's real name in a different internal location depending on the file's history, and while this tool also makes a best-effort pass at the two most likely such locations (Word's people.xml, Excel's persons/person.xml), 100% removal cannot be guaranteed there. Before sending a file outside your organization, we recommend also running Word/Excel's own "Document Inspector" as a final check. Word's tracked-changes (Track Changes) editor names — the w:author attribute recorded on insertions, deletions and formatting changes — are also cleared on a best-effort basis, across the document body, headers, footers, footnotes and endnotes (toggle this with the "Also clear Track Changes editor names" checkbox below; full coverage is not guaranteed).

Q. Which file formats are supported?

A. Excel (.xlsx/.xlsm), Word (.docx) and PowerPoint (.pptx). The older .xls/.doc/.ppt formats and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_anonymized" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

  • 「パワーポイントが重い」原因を診断：ファイル内訳チェッカー — PowerPoint版の同種の診断。渡す前にファイルサイズの内訳や、使われていないスライドレイアウトを確認できます。

  • 「Wordファイルが重い」原因を診断：ファイル内訳チェッカー — 作成者名以外にも、画像のトリミング残存データや埋め込みフォントなど容量の内訳を確認できます。
  • Ctrl+Endで遠くへ飛ぶ・印刷で白紙ページが大量に出るときの「使用範囲」リセット — 渡す前に使用範囲を実データの範囲まで縮小。
  • CSVの先頭の0が消える・日付に化けるときのExcel(.xlsx)変換ツール — CSVとExcelの橋渡し。
  • シートのあちこちに散らばったコメント・メモを全部一覧に — 作成者名を消す前に、どこに誰のコメントが残っているか確認できます。
  • 2つのExcelファイルを比較：変更されたセルだけを全シート一括で色付け表示 — 「変更前」「変更後」の2つのファイルを全シート一括で比較し、追加・削除・変更されたセルだけをシート形式の色付き表示と一覧で確認。
  • 引き継いだExcelの数式を一覧に — 数式が入った全セルをファイルを開かず一覧化し、エラー・他シート参照・外部参照を検出。
  • Excelの「外部ソースへのリンク」発生源を探すツール — 外部参照の参照先ファイルを一覧化し、数式・名前定義・入力規則・条件付き書式・グラフのどこで使われているかを列挙。
  • 循環参照の警告が消えない・どこにあるか分からないときの一覧化ツール — 全シートの数式を解析し、循環参照になっているセルのグループを一度に全部一覧化してCSV出力。
  • #REF!・#N/A・#DIV/0!が残っているセルを全部一覧に — 全シート・複数ファイルを横断してエラー値セルだけを一覧化し、種類ごとの件数と典型的な原因を表示してCSV出力。
  • 「名前は既に存在します」対策：名前定義の点検・削除ツール — 名前定義（defined names）を全件一覧化し、非表示・エラー・組み込みの名前を見分けて削除。
  • Excelの結合セルを解除して値を埋める→CSV出力 — 結合セルを解除してできる空欄を左上の値で自動的に埋め、並び替え・フィルター・ピボットができる表にしてCSV出力。
  • Excelファイルを複数まとめて1つに — 複数の.xlsxファイルをCSVに書き出す手間なくそのまま1つのCSVに結合。
  • 条件付き書式が増えすぎて重い・消せないときの棚卸し削除ツール — 条件付き書式ルールを全シート横断で一覧化し、範囲の重複・行列全体・書式参照切れを自動で見分けて削除。
  • ハイパーリンクが開けない・大量にあって消せないときの一覧・削除ツール — 全シートのクリック可能なハイパーリンクを一覧化し、ローカルファイルへのリンクや存在しないシートを指す社内リンクを自動検出して解除。
  • シートの「再表示」に出てこないときの対策：非表示・完全非表示シートの一覧・一括変更 — 非表示・完全非表示（veryHidden）シートの表示状態を一覧化し、選んだシートをまとめて表示に戻す（または非表示にする）新しいファイルを書き出す。
  • 数式を値に変換：外部ファイルへのリンクが解除できないときに — Excelの数式を保存されている計算結果に変換。外部ファイルを参照している数式だけを選んで値にし、条件を満たせば外部リンクの記録も削除。
  • 社外に送る前に確認：Excelの「隠れた情報」一括チェック — 作成者名以外にも、非表示シート・コメント・外部リンク・名前定義などをまとめて診断（読み取り専用）。
  • 「数値が文字列として保存されています」(緑の三角)を列ごと一括で数値に変換 — テキストとして保存された数値らしいセルを列ごとに一覧化し、選んだ列だけ数値に変換。郵便番号等の0始まりコード列や8桁以上の長い数字コードの列は既定で対象外。
  • 入力規則（プルダウン）がどこにあるか分からない：全シート一覧化 — セル範囲・種類・リスト元（他シート参照・名前定義経由も含む）を全シート横断で一覧化し、参照が壊れているものを検出してCSV出力。
  • シートごとに印刷範囲・印刷タイトル・改ページがバラバラなときの一覧・一括解除 — 印刷範囲・印刷タイトル・手動の改ページの設定状況を全シート一覧化し、選んだシート・項目だけをまとめて解除した新しいファイルを書き出す。印刷の向き・用紙サイズ・余白は変更しない。
  • 図形が知らないうちに増えている・見えない図形が残っていないか一覧でチェック — 非表示設定の図形、サイズが実質ゼロの図形、同じ名前が繰り返し付いた図形（コピーで増えた可能性）を全シート横断で一覧表示。選んだ図形（グループは丸ごと単位）を削除した新しいファイルも書き出せる。
  • 非表示の行・列が全シートに散らばっている：まとめて「再表示」または内容だけ削除 — 非表示の行・列の数と、そこに値が入っているセル数を全シート一覧表示し、選んだシートをまとめて「再表示」、または内容（値・数式）だけ削除した新しいファイルを書き出す。
  • Hidden rows/columns scattered across every sheet: bulk "Unhide" or clear just their contents — List every sheet's hidden rows/columns and how many cells inside them hold a value, then build a copy with the ones you choose either unhidden or cleared of their contents.
  • 「無効なデータ」の丸印は1シートずつ：入力規則に違反した値を全シート一括で一覧化 — リスト（プルダウン）や数値・文字数の範囲に実際に違反している値が入ったセルだけを、全シート・複数ファイル横断で一覧化してCSV出力（読み取り専用）。カスタム数式や複雑な参照は安全のため対象外と表示。
