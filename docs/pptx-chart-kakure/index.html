「グラフのデータを編集」で元の表が丸ごと見える：PowerPointグラフの埋め込みExcel診断ツール

PowerPointのグラフ（Excelグラフオブジェクト）を右クリックして「データの編集」を開くと、グラフには表示されていない余分な行・列まで埋め込みExcelシートにそのまま残っていることがあります。社外にファイルを渡す前に、全スライドのグラフを一括で診断し、グラフが実際に使っている値の個数と、埋め込みシートの使用範囲を比較して、余分なデータが残っている可能性を知らせます。複数ファイルを一括処理でき、ファイルはサーバーに送らずこのブラウザの中だけで処理します（読み取り専用・ファイルは書き換えません）。

ここにPowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.pptx に対応（.pptは読み込めません）。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

読み込んだファイル

使い方とよくある質問

  1. 上の枠にPowerPoint(.pptx)ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. ファイル内の全スライドにあるグラフが一覧表示されます。「埋め込みExcelあり」のグラフについて、グラフが実際に使っている値の個数（キャッシュ）と、埋め込みシートの使用範囲（行数・列数）を比較し、「差異の可能性」「差異なし」「判定できません」のいずれかを表示します。
  3. 「差異の可能性」のグラフは、PowerPointでグラフを右クリック→「データの編集」を開き、キャッシュに使われていない余分な行・列が残っていないか確認してください。

Q. このツールは何をチェックしていますか？

A. グラフを「Excelグラフオブジェクト」として貼り付けた場合、グラフ自体の表示に使うキャッシュ値（numCache/strCache）とは別に、元になったExcelシートがファイルの中に丸ごと埋め込まれていることがあります。見た目には出ないこの埋め込みシートに、グラフが拾っている範囲より外側の行・列が残っていないかを、ファイルを開かずに（グラフのXMLとシートの使用範囲の記録だけを読んで）確認します。

Q. 「差異の可能性」と出たら、必ず余分なデータが含まれていますか？

A. 必ずではありません。使用範囲（Ctrl+Endで飛ぶ場所）は、実際のデータ量に関わらず広がっている場合もあります（xlsx-omoiやxlsx-haniで扱っているのと同じ現象です）。ただし、グラフが使っていない行・列がファイルの中に機械的に残っていることは確かなので、「データの編集」で内容を確認する価値があります。

Q. 「判定できません」と出るのはどんな場合ですか？

A. バブルチャート・株価チャート・等高線グラフ、項目軸が複数階層になっているグラフなど、キャッシュの数え方が単純でない場合、埋め込みが古い形式（OLEオブジェクト・.bin）で中身を読み取れない場合、または埋め込みシート自体が壊れている・読み取れない場合です。誤って「問題なし」と判定するより、分からないものは分からないと表示する方針にしています。

Q. 見つかったらどう対処すればいいですか？

A. このツールは診断のみで、ファイルの書き換えは行いません。対処法としては、①グラフを右クリック→「データの編集」でExcelを開き、キャッシュの範囲より外側にある余分な行・列を削除してから保存し直す、②どうしても心配な場合はグラフをコピーして「図として貼り付け」で画像化する（編集できなくなりますが元データは残りません）、のいずれかをおすすめします。

Q. 複数のファイルを一度に確認できますか？

A. はい。ファイルを追加するたびにカードが増え、それぞれ個別に結果を確認できます。

Q. 対応しているグラフの種類は？

A. 棒・線・円・面・散布図・ドーナツ・レーダー、およびこれらの組み合わせグラフに対応しています。バブルチャート・株価チャート・等高線グラフは対象外として「判定できません」と表示されます。

Q. 対応しているファイル形式は？

A. PowerPoint 2007以降の.pptx形式です。古い.ppt形式や、パスワードで保護されたファイルは読み込めません。グラフの埋め込みも、近年のPowerPointが使う.xlsx形式のみ対象です（古いOLE形式の埋め込みは「埋め込みあり（旧形式）」とだけ表示します）。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析が行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。ファイルの内容を書き換えたり保存したりすることもありません。

How to use & FAQ

  1. Drag and drop PowerPoint (.pptx) files into the box above, or click it to choose (multiple files are fine).
  2. Every chart across every slide is listed. For charts with an embedded Excel workbook, the tool compares the number of data points the chart actually uses (its cache) against the embedded sheet's used range (rows × columns), and shows one of: possible extra data, no difference, or unable to tell.
  3. For charts flagged as possibly having extra data, right-click the chart in PowerPoint and open "Edit Data" to check for rows/columns the chart isn't using.

Q. What does this tool check?

A. When a chart is pasted as a native "Excel Chart Object", the source workbook it was built from can remain fully embedded inside the file — separate from the small cache of values (numCache/strCache) the chart actually displays. This invisible embedded sheet can hold rows or columns the chart never plots. This tool checks for that, without opening the file, by reading only the chart's own XML and the embedded sheet's recorded used range.

Q. If it says "possible extra data," is there definitely something hidden?

A. Not necessarily. A sheet's recorded used range (where Ctrl+End jumps) can be larger than the actual data for unrelated reasons (the same phenomenon covered by xlsx-omoi and xlsx-hani). Still, it does mean the file mechanically retains rows/columns the chart doesn't use, so it's worth checking with "Edit Data".

Q. When does it say "unable to tell"?

A. For chart types whose cache isn't simple to count (bubble, stock, surface charts, or multi-level category axes), for embeddings in the older OLE/.bin format this tool can't parse, or when the embedded sheet itself can't be read. The tool prefers saying "unable to tell" over risking a false "no issue" result.

Q. What should I do if extra data is found?

A. This tool only diagnoses — it never rewrites your file. Either right-click the chart → "Edit Data" in Excel and delete the rows/columns beyond what's cached, then save, or — if you'd rather be safe — copy the chart and "Paste as Picture" to flatten it to an image (no longer editable, but no source data remains).

Q. Can I check multiple files at once?

A. Yes. Each file you add gets its own card with its own results.

Q. Which chart types are supported?

A. Bar, line, pie, area, scatter, doughnut, radar charts, and combinations of these. Bubble, stock and surface charts are out of scope and shown as "unable to tell".

Q. Which file formats are supported?

A. PowerPoint 2007+ (.pptx). The older .ppt format and password-protected files are not supported. Only charts with a modern .xlsx-format embedded workbook are inspected (older OLE-format embeddings are shown as "embedded (legacy format)" only).

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter). The file's contents are never modified or saved anywhere.
