Word・PowerPointのハイパーリンクが開けない・社内専用のリンクが残っているときの一覧・削除ツール

社外に送る前に、Word(.docx)・PowerPoint(.pptx)に貼られたハイパーリンクをまとめて確認したいときに。本文・ヘッダー・フッター・脚注・文末脚注（Word）、スライドのテキストや図形（PowerPoint）のリンクを全部一覧化し、社内の共有フォルダ・自分のPCを指す「ローカルファイル」へのリンクや、参照先が無くなって開けない「壊れているリンク」を自動で見分けます。選んだリンクだけを解除した新しいファイルをその場で書き出せます。ファイルはサーバーに送らず、すべてこのブラウザの中だけで処理します。

ここにWord・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.docx / .pptx に対応。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

読み込んだファイル

使い方とよくある質問

  1. 上の枠にWord(.docx)・PowerPoint(.pptx)ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. 各ファイルで見つかったハイパーリンクが一覧表示されます。「ローカルファイル」「壊れている」と判定されたリンクには既定でチェックが入っています。削除したい行にチェックを入れ（全選択・全解除ボタンもあります）、「選んだリンクを解除して書き出す」を押すとダウンロードされます。

Q. 何を一覧にしますか？

A. Wordは本文・ヘッダー・フッター・脚注・文末脚注、PowerPointは各スライドの本体（テキストの一部に設定されたリンクと、図形・アクションボタン全体に設定されたリンクの両方）に設定された、クリックできるハイパーリンクを一覧にします。

Q. 「ローカルファイル」とはどういうリンクですか？

A. 自分のPCやファイルサーバー上のパス（C:\...、\\サーバー名\...、file:///...）を指すリンクです。社外の相手や別のPCには同じ場所にファイルが無いため、クリックしても開けません。社内で使っている間は気づきにくいため、送信前のチェックの対象にしています。

Q. 「壊れているリンク」とは？

A. 2パターンあります。1つは、リンクの参照情報（relationship）自体が見つからない場合（コピー＆ペーストの際に参照が外れることがあります）。もう1つは、文書内の見出し・ブックマーク（Word）やスライド（PowerPoint）へのジャンプ先が、削除などで無くなっている場合です。

Q. 外部サイトへのリンクやメールへのリンク、文書内で別の場所へ飛ぶリンクも消せますか？

A. はい。一覧には全種類のリンクが表示され、どの行でもチェックを入れて削除できます。ただし「ローカルファイル」「壊れている」以外（外部サイト・メール・文書内ジャンプ等）は通常問題なく動作するリンクのため、既定ではチェックを外しています。

Q. リンクを削除すると、リンクが付いていた文字や図形自体も消えますか？

A. 消えません。リンクの機能（クリックで開く動作）だけを取り除き、文字・図形・書式はそのまま残ります。Wordの「ハイパーリンクの削除」機能と同じ動作です。

Q. すべてのリンクを100%検出できますか？

A. 本文・ヘッダー・フッター・脚注・文末脚注（Word）とスライド本体のテキスト・図形（PowerPoint）を対象にしています。スライドの発表者ノート、文書内に埋め込まれた別のOffice文書の中のリンク、SmartArtの内部データのように特殊な場所にあるリンクは対象外です（見逃しはあっても、安全なリンクを誤って「壊れている」と表示することはない設計です）。

Q. 対応しているファイル形式は？

A. Word(.docx)とPowerPoint(.pptx)です。古い.doc/.ppt形式や、パスワードで保護されたファイルは読み込めません。ExcelのハイパーリンクはExcel版の一覧・削除ツールをご利用ください。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_リンク整理済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop Word (.docx) / PowerPoint (.pptx) files into the box above, or click it to choose (multiple files are fine).
  2. Every hyperlink found in each file is listed. Rows flagged as "local file" or "broken" are checked by default. Check the rows you want removed (there are select-all / select-none buttons too), then click "Remove selected links & build" to download the result.

Q. What exactly does it list?

A. For Word: every clickable hyperlink in the document body, headers, footers, footnotes and endnotes. For PowerPoint: every clickable hyperlink on each slide — both links applied to a piece of text and links applied to a whole shape or action button.

Q. What counts as a "local file" link?

A. A link pointing to a path on your own PC or a file server (C:\..., \\servername\..., file:///...). Someone outside your organization — or even you on a different PC — won't have a file at that same path, so clicking it does nothing. This is easy to miss while you're still inside your own network, which is exactly why it's flagged here before you send the file out.

Q. What counts as a "broken" link?

A. Two cases: the link's underlying relationship record is missing entirely (this can happen after copy-pasting content between files), or the link points to a heading/bookmark (Word) or a slide (PowerPoint) that no longer exists.

Q. Can I also remove links to external websites, email addresses, or jumps to another part of the same file?

A. Yes — every link type appears in the list and any row can be checked for removal. Only "local file" and "broken" rows are checked by default, since the rest (web, email, in-document jumps) normally work fine.

Q. If I remove a link, does the linked text or shape disappear too?

A. No. Only the clickable link behavior is removed; the text, shape and formatting stay exactly as they were — the same result as Word's own "Remove Hyperlink" command.

Q. Does it catch every single link?

A. It covers the document body, headers, footers, footnotes and endnotes (Word) and each slide's text and shapes (PowerPoint). Speaker notes, links inside another Office file embedded within this one, and links buried inside SmartArt's internal data are out of scope — this can mean a rare miss, but it's designed to never mislabel a working link as broken.

Q. Which file formats are supported?

A. Word (.docx) and PowerPoint (.pptx). The older .doc/.ppt formats and password-protected files aren't supported. For Excel hyperlinks, use the Excel version of this tool.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_links-cleaned" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
