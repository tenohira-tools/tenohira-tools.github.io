使い方とよくある質問

  1. 上の枠にCSVファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 文字コードが自動判定されます。文字化けして見える場合は「文字コードを指定」で候補を試してください。
  3. プレビューの各列の見出しにあるチェックボックスで「文字列として保存」する列を選びます。郵便番号・社員番号・電話番号・JANコードなど0埋めや桁の多い番号の列は自動でチェックされています。手元のファイルに合わせてオン・オフを変更できます。
  4. 「Excel(.xlsx)に変換してダウンロード」を押すと、新しい.xlsxファイルがダウンロードされます（元のCSVは変更されません）。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで変換されます（サイト全体の閲覧数をCookieなし・個人を特定しない方法で数えるGoatCounterの通信のみ発生します）。

Q. なぜCSVをExcelで開くと先頭の0が消えたり日付になってしまうのですか？

A. CSVファイル自体には「この列は文字列」という情報が無いため、Excelが開くときにセルの内容から型を推測します。「0123456」のような0から始まる数字は数値と判断されて0が消え、「1-2」のような区切り文字入りの短い数字は日付と推測されて「1月2日」のような表示に変わってしまいます。このツールはExcel（.xlsx）ファイルとして直接書き出す際に、選んだ列を最初から「文字列」の型でセルに書き込むため、Excelで開いたときに再解釈されず、入力した通りの見た目で表示されます。

Q. どの列を「文字列として保存」すればいいですか？

A. 郵便番号・社員番号・電話番号・JANコードなど、0から始まる値や8桁以上の長い数字が入っている列、「1-2」や「2024/3/4」のような区切り文字入りの短い数字が入っている列は自動でチェックされます。計算に使いたい金額や数量の列はチェックを外したままにしてください（数値としてそのまま書き出され、Excelでの合計などの数式に使えます）。判断に迷う場合や、とにかく安全を優先したい場合は「すべての列を文字列として保存する」を選んでください。

Q. 「文字列として保存」しなかった列はどうなりますか？

A. チェックを外していても、見た目が数字そのもの（0から始まらない、区切り文字も無い）ではない値は、このツールが自動的に文字列として書き出すため0落ちや日付化けは起きません。チェックを外した列が数値として書き出されるのは、純粋な数字（0から始まらない整数・小数）だけです。

Q. 元のCSVファイルは変更されますか？

A. 変更されません。新しい.xlsxファイルを作成してダウンロードするだけで、選んだ元のCSVファイルはそのまま残ります。

Q. 大きなCSVファイルも変換できますか？

A. ブラウザのメモリ上で処理するため、数万行程度までを想定しています。非常に大きなファイルでは変換に時間がかかる場合があります。

How to use & FAQ

  1. Drag and drop a CSV file into the box above, or click it to choose a file.
  2. The character encoding is auto-detected. If it still looks garbled, try another option from the encoding selector.
  3. Use the checkbox in each column's header in the preview to choose which columns should be saved as text. Columns with zero-padded numbers, long digit codes, phone numbers or JAN/barcode-style codes are checked automatically — adjust them as needed.
  4. Click "Convert to Excel (.xlsx) and download" to get a new .xlsx file. The original CSV is left untouched.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is converted inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Why do leading zeros disappear or values turn into dates when I open a CSV in Excel?

A. A plain CSV file carries no information about a column's intended type, so Excel guesses from each cell's content when it opens the file. A number starting with 0, like "0123456", is read as a number and loses the leading zero; a short number with a separator, like "1-2", is guessed to be a date and displayed as "Jan 2". This tool writes the file directly as Excel's own .xlsx format and marks the columns you choose as text from the start, so Excel never re-guesses their type and shows them exactly as entered.

Q. Which columns should I mark as text?

A. Columns with values that start with 0, or long digit codes of 8+ digits (postal codes, employee IDs, phone numbers, JAN/barcodes), and short separator-based numbers like "1-2" or "2024/3/4" are checked automatically. Leave amount or quantity columns you want to total with formulas unchecked, so they're written as real numbers. If you're unsure, or want maximum safety, use "Save all columns as text".

Q. What happens to columns I leave unchecked?

A. Even unchecked, any value that isn't a plain number (no leading zero, no separators) is still written as text automatically, so no leading zeros or dates get mangled. Only genuinely plain numbers (integers or decimals that don't start with 0) are written as real numeric cells in unchecked columns.

Q. Does this change my original CSV file?

A. No. It only creates and downloads a new .xlsx file — the CSV file you chose is left exactly as it was.

Q. Can it handle large CSV files?

A. Everything runs in browser memory, so it's built for files up to tens of thousands of rows. Very large files may take longer to convert.
