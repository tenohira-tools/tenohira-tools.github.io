条件付き書式が増えすぎて重い・消せないときの棚卸し削除ツール

コピペのたびにルールが勝手に増える、「ルールの管理」を開いても範囲が重なって何が効いているか分からない——というExcel(.xlsx/.xlsm)ファイルの条件付き書式を、全シート横断で一覧表示します。範囲が重複しているルール、行全体・列全体を対象にした重くなりやすいルール、書式の参照先が壊れているルールを自動で見分け、選んだルールを削除した新しいファイルをその場で書き出せます。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。すべてのシートの条件付き書式ルールをまとめて抜き出します。ファイルは選択した端末の中だけで処理されます。

条件付き書式ルールの集計

「範囲が重複」は、同じシート内の別々のルール設定（別の範囲指定）同士がセル範囲で重なっている場合です。優先順位次第で片方が常に隠れたり、思った通りに表示されなかったりする原因になりやすいです。

ルールの一覧

選んだルールは書式（色・太字など）の設定だけが削除されます。セルの値・数式は変わりません。削除後はExcelで開いて見た目を確認してください。元のファイルは変更されず、新しいファイルとして書き出されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. ルールの一覧で、各ルールの対象シート・範囲・種類・条件・優先度と、「範囲が重複」「行全体・列全体」「書式参照なし」「StopIfTrueあり」の旗を確認します。
  3. 削除したいルールにチェックを入れます（クイック選択ボタンで一括選択も可能）。
  4. 「選んだルールを削除したファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. コピペのたびに条件付き書式が勝手に増えるのはなぜですか？

A. Excelはセルをコピーすると、そのセルに設定されていた条件付き書式も一緒にコピーします。参照をずらしながら何度も貼り付けを繰り返すと、本来1つで足りるはずのルールが少しずつ範囲の違う別ルールとして増殖し、「ルールの管理」ダイアログが数十〜数百行になることがあります。組み込みの管理画面は一覧性が低く、どの範囲が重なっているかも分かりにくいため、このツールでは全シートのルールをまとめて一覧化し、範囲が重なっているものを自動で見分けられるようにしています。

Q. 「範囲が重複」「行全体・列全体」「書式参照なし」「StopIfTrueあり」はそれぞれ何を意味しますか？

A. 「範囲が重複」は、同じシート内の別のルール設定同士が対象セル範囲で重なっている状態です。優先度の低い方が常に隠れていたり、意図しない見た目になっていたりする原因になります。「行全体・列全体」は対象範囲が「A:A」「1:1」のように行・列まるごと指定されているルールで、実際にデータがある範囲を大きく超えて評価され続けるため、ファイルが重くなる・再計算が遅くなる原因になりやすいです。「書式参照なし」は、ルールが参照している書式定義（dxf）がファイル内に見当たらない状態で、削除し忘れた古いルールの残骸である可能性があります。「StopIfTrueあり」は、そのルールの条件が成立した場合に同じ範囲の後続ルールの評価を打ち切る設定で、他のルールが効いていないように見える原因になることがあります。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。また、Excel 2010以降で追加された一部の拡張書式（新しい種類のアイコンセットなど、ファイル内の拡張領域(extLst)にのみ保存されるもの）は、現在のバージョンでは一覧に含まれません。

Q. ルールを削除すると、セルの値や数式は変わりますか？

A. 変わりません。削除されるのは条件付き書式のルール（表示上の色・太字などの切り替え設定）だけです。セルの値・数式・通常の書式（罫線やフォントなど）はそのまま残ります。

Q. 「種類」「条件」はどうやって判定していますか？

A. ルールに保存されているtype属性・operator属性・formula要素などを読み取って、日本語の短い説明に変換しています。カラースケール・データバー・アイコンセットは内部の詳細な設定までは表示せず、種類のみを表示します。断定的な判定ではないため、重要なファイルでは削除後にExcelの「ルールの管理」で最終確認してください。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_条件書式整理済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. シートの構成やセルの値、他の書式は変わりますか？

A. 変わりません。シート・セルの値・数式・通常の書式・グラフ・画像など、条件付き書式のルール以外のすべての部分はそのままコピーされます。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Check each rule's sheet, range, type, condition, priority, and the "overlapping range", "whole row/column", "missing style reference" and "stops further rules" flags.
  3. Tick the rules you want to remove (the quick-select buttons select several at once).
  4. Click "Build a file with the selected rules removed" to download the cleaned copy — your original file is untouched.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Why do conditional formatting rules keep multiplying when I copy and paste?

A. Excel copies a cell's conditional formatting along with its value. Paste the same style around the sheet enough times, with the reference shifting slightly each time, and one rule that should have covered the whole range turns into dozens of near-duplicate rules with slightly different ranges — Excel's own "Manage Rules" dialog can grow to hundreds of rows. That built-in dialog is hard to scan and doesn't show you which ranges overlap, so this tool lists every rule across every sheet at once and flags the overlapping ones automatically.

Q. What do "overlapping range", "whole row/column", "missing style reference" and "stops further rules" mean?

A. "Overlapping range" means two separate rule definitions on the same sheet cover intersecting cells — the lower-priority one may always be hidden or the result may look wrong. "Whole row/column" flags a rule whose range is an entire row or column (like A:A or 1:1), which gets evaluated far beyond where your data actually is and is a common cause of slowdowns and file bloat. "Missing style reference" means the rule points at a style definition (dxf) that no longer exists in the file — often a leftover from a rule that was half-deleted. "Stops further rules" means that when this rule's condition is true, Excel stops evaluating later rules on the same range, which can make other rules look like they're "not working".

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported. Some newer rule variants that Excel 2010+ stores only in the file's extension area (extLst) — such as certain icon-set options — are not currently listed.

Q. Does removing a rule change cell values or formulas?

A. No. Only the conditional formatting rule (the conditional color/bold/etc. switch) is removed. Cell values, formulas and regular formatting (borders, fonts) are untouched.

Q. How is the "type" / "condition" determined?

A. It reads the rule's stored type, operator and formula and converts them into a short description. Color scales, data bars and icon sets are shown by type only, without their detailed settings. These are text-pattern conversions, not certainties — double-check in Excel's "Manage Rules" after removing anything from an important file.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_cleaned" appended to the name). Your original file is never overwritten.

Q. Does this change the sheets, cell values, or other formatting?

A. No. Everything except the conditional formatting rules — sheets, cell values, formulas, regular formatting, charts, images — is carried over unchanged.
