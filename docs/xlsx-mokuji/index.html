シートが多すぎて目的のシートまで移動しづらいときの「目次」シート自動作成

シートが増えて、見出しのタブを何度も左右にスクロールしないと目的のシートに辿り着けなくなることがあります。このツールはExcel(.xlsx/.xlsm)の全シート名を解析し、クリックで各シートへ移動できるハイパーリンク付きの「目次」シートを先頭に追加した新しいファイルを書き出します。HYPERLINK関数を手で1つずつ打つ必要はありません。非表示・完全非表示のシートも一覧には含めますが、Excelの仕様上リンクはできないため文字のみで区別して表示します。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。全シートの名前と表示状態を解析します。ファイルは選択した端末の中だけで処理されます。

シート一覧

下のボタンで、クリックすると各シートへ移動できる「目次」シートを先頭に追加した新しいファイルを書き出せます。

注意：非表示・完全非表示のシートはExcelの仕様上ハイパーリンクでは移動できないため、一覧には載せますがリンクは付けません。

シート別の内訳

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 全シートの名前と表示状態（表示／非表示／完全非表示）が一覧表示されます。
  3. 「目次シートを追加したファイルを書き出す」でダウンロードします。元のファイルはそのまま残り、先頭に「目次」という名前の新しいシートが追加された別のファイルが保存されます。
  4. 目次シートのシート名をクリックすると、該当するシートへ直接移動できます。
  5. ファイルを作らず、シート名の一覧だけが欲しい場合は「シート名一覧をCSVで書き出す」または「シート名をコピー」を使います。

Q. 「目次」シートには何が書き込まれますか？

A. A列にシート名、B列に表示状態（表示／非表示／完全非表示）を、元のシートの並び順どおりに1行ずつ書き込みます。表示中のシートのA列は、クリックするとそのシートの先頭（A1）へ移動するハイパーリンクになります。

Q. 非表示・完全非表示のシートへはリンクできないのですか？

A. Excelの仕様上、非表示（あるいは完全非表示）になっているシートへハイパーリンクで移動することはできません（クリックしてもエラーになります）。そのため、このツールは非表示・完全非表示のシートも一覧には載せますが、リンクなしの文字だけで表示します。先にシートを再表示したい場合は、関連ツールの「非表示・完全非表示シートの一覧・一括変更」が使えます。

Q. 既存のシートの内容や並び順は変わりますか？

A. 変わりません。追加されるのは先頭の「目次」シートだけで、既存の全シートの名前・順序・セルの値や数式・書式は一切変更しません（ブックの表示時に最初に開くシートの指定は、追加した目次シートの分だけ番号をずらして元と同じシートが開くように調整します）。

Q. すでに「目次」という名前のシートがある場合はどうなりますか？

A. 自動的に「目次(1)」のように名前を変えて追加します。追加されるシート名は、既存のどのシート名とも重複しません。

Q. シート名が31文字を超えていたり、記号が入っていたりしても大丈夫ですか？

A. はい。目次シートへの書き込みやリンク先の指定では、既存のシート名をそのまま扱います（このツールが新しく作るのは「目次」という短い名前のシートだけです）。

Q. マクロ（.xlsm）のファイルでも使えますか？

A. はい。マクロ自体やその他のシートの内容は変更しないため、.xlsmファイルでもマクロを保持したまま目次シートだけを追加できます。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Every sheet's name and visibility (visible/hidden/very hidden) is listed.
  3. Click "Build a file with a contents sheet" to download a copy with a new "Contents" sheet added at the front. Your original file is untouched.
  4. In the new file, clicking a sheet name on the contents sheet jumps straight to it.
  5. If you just want the list of names without building a file, use "Export sheet names as CSV" or "Copy sheet names".

Q. What gets written on the "Contents" sheet?

A. Column A holds each sheet's name and column B its visibility, one row per sheet, in the workbook's original order. For visible sheets, column A is a clickable hyperlink that jumps to cell A1 of that sheet.

Q. Why can't hidden sheets be linked to?

A. Excel itself doesn't support jumping to a hidden (or very hidden) sheet via a hyperlink — clicking one would just produce an error. So hidden and very-hidden sheets are still listed, just as plain text with no link. If you want to unhide them first, the related "list and bulk-change hidden/very-hidden sheets" tool can do that.

Q. Does this change the existing sheets or their order?

A. No. Only the new "Contents" sheet is added at the front; every existing sheet's name, order, cell values/formulas and formatting are left untouched (the workbook's "sheet to open first" setting is shifted by one so the same sheet still opens first, accounting for the new sheet).

Q. What if a sheet named "Contents" (目次) already exists?

A. The new sheet is automatically renamed (e.g. "目次(1)") so it never collides with an existing sheet name.

Q. Does this handle long or special-character sheet names?

A. Yes — existing sheet names are used as-is when writing the list and the hyperlink targets (the only new sheet this tool creates uses a short fixed name).

Q. Does this work on macro-enabled (.xlsm) files?

A. Yes. Macros and every other sheet are left untouched, so a .xlsm file keeps its macros while gaining the contents sheet.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
