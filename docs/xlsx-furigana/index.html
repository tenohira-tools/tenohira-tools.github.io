セルのふりがな（読み）情報を一覧チェック・一括削除

Excelのセルには、見た目には出ない「ふりがな（読み）」情報が裏に保存されていることがあります。氏名・地名など、読み方そのものが個人情報になりうる文字列も対象です。どのシート・セルにふりがなが付いているかを一覧表示し、CSV書き出しや、ふりがな情報だけを取り除いた新しいファイルの書き出しに対応します。表示されている文字そのものは変更しません。ファイルはどこにも送信されません。

ここにExcel(.xlsx)ファイルをドラッグ＆ドロップ、またはクリックして選択（複数可）

全シート・共有文字列・セル個別の文字列からふりがな（rPh）が付いているものだけを抜き出します。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル・複数シートも自動でまとめて読み込みます）。
  2. ファイルごとに、ふりがなが付いているセルの件数が表示されます。件数が1件以上ある場合は「ふりがなを削除した新しいファイルをダウンロード」ボタンが出ます。
  3. 下の一覧で、どのシート・セルに、どの文字に対してどのふりがなが付いているかを確認します。絞り込みでファイル・シート・キーワードを指定できます。
  4. 必要であれば一覧を「CSVでダウンロード」するか「この一覧を印刷」します。ふりがな情報を取り除いた新しいファイルが必要な場合は、ファイルごとの削除ボタンを使います（文字そのものは変わりません。元のファイルも変更されません）。

Q. そもそも「ふりがな（読み）」情報とは何ですか？

A. Excelのセルに日本語の文字を入力すると、PHONETIC関数やセルの「ふりがなの表示」機能で使うための読み方（ひらがな・カタカナ）が、ファイルの中に文字とは別に保存されることがあります。見た目のセルの表示を変えても、この読み情報だけが古いまま残っていることもあります。

Q. なぜ社外に渡す前に確認した方がいいのですか？

A. セルの文字自体を通称名や略称に直しても、裏のふりがな情報には本来の読み方（本名の読みなど）が残っている場合があります。氏名・会社名・地名のふりがなは、文字だけでは分からない情報を含むことがあるため、渡す前に何が入っているか確認する価値があります。

Q. 「削除」すると、セルの文字や見た目は変わりますか？

A. 変わりません。削除するのはふりがな（読み）情報と、その書式設定（phoneticPr）だけです。セルに表示されている文字・数式・書式・列幅などはすべてそのまま残ります。PHONETIC関数やふりがなの表示機能は、削除後は空欄を返すようになります。

Q. 元のファイルは変更されますか？

A. いいえ。「ダウンロード」ボタンを押すと、ふりがな情報だけを取り除いた新しいファイルが別名でダウンロードされます。アップロードした元のファイルは変更されません。

Q. 一覧に出てこないのに、ふりがなが残っていることはありますか？

A. このツールは、実際に読み（rPh）が設定されているセルだけを一覧に出します。読みが未設定のまま「ふりがなの書式設定」だけが残っている場合（見た目には何も影響しません）は一覧に出ませんが、削除を実行すると、その空の設定もまとめて取り除かれます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more (every sheet in every file is scanned automatically).
  2. Each file shows how many cells carry phonetic (furigana) reading data. When there's at least one, a "Download a copy with furigana removed" button appears for that file.
  3. The list below shows exactly which sheet, cell, display text and reading each one has. Use the filters to narrow it down by file, sheet or keyword.
  4. Download the list as CSV or print it directly. To get a file with the reading data stripped, use the per-file download button (the visible text is untouched; your original file is never changed).

Q. What is this hidden "furigana" / phonetic reading data?

A. When you type Japanese text into an Excel cell, a phonetic reading (in hiragana or katakana) can be stored alongside it for the PHONETIC function or Excel's "Show Furigana" display. It's saved separately from the visible text, so it can go stale even after you edit the cell.

Q. Why check this before sending a file outside your company?

A. Even if you've replaced a cell's visible text with a nickname or abbreviation, the hidden reading can still carry the original reading (for example, the real reading of someone's name). Names, company names and place names can carry information in their reading that isn't obvious from the displayed text alone.

Q. Does removing it change the cell's text or appearance?

A. No. Only the phonetic reading data and its formatting settings (phoneticPr) are removed. The visible text, formulas, formatting and column widths are all left exactly as they are. The PHONETIC function and "Show Furigana" will return blank afterwards.

Q. Is my original file changed?

A. No. Clicking "Download" saves a new file with the phonetic data stripped, under a different name. The uploaded original is never modified.

Q. Could furigana remain even if a cell isn't listed?

A. This tool lists only cells where an actual reading (rPh) is set. A cell that has empty phonetic formatting but no reading text yet (invisible either way) won't appear in the list, but removal still clears that empty setting too.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.
