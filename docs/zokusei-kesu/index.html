社外に渡す前に、Excel・Word・PowerPointの「カスタムプロパティ」「テンプレート参照パス」を一覧化・削除

作成者名・最終更新者・会社名を消しても、ファイルの内部にはまだ「カスタムプロパティ」（会社の独自テンプレートが自動で書き込む、クライアント名・承認者・社内プロジェクトコードなどの独自項目）や、「テンプレートの参照パス」「ハイパーリンクの基準パス」（社内サーバーのフォルダ構成が分かってしまう場合があります）が残っていることがあります。Excel(.xlsx/.xlsm)・Word(.docx)・PowerPoint(.pptx)からこれらを一覧表示し、選んだものだけを削除した新しいファイルを書き出します。複数ファイルを一括処理できます。ファイルはサーバーに送らず、すべてこのブラウザの中だけで処理します。元のファイルは変更しません。

ここにExcel・Word・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.xlsx / .xlsm / .docx / .pptx に対応。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にExcel/Word/PowerPointファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. 見つかった「カスタムプロパティ」が表に一覧表示されます。消したい項目にチェックを入れたまま（既定でチェック済み）、テンプレート参照パス・ハイパーリンクの基準パスも消したい場合はチェックを入れ、「書き出す」を押すとダウンロードされます。元のファイルはそのまま残ります。

Q. 「カスタムプロパティ」とは何ですか？なぜ気づきにくいのですか？

A. Excel/Word/PowerPointのファイル内部（docProps/custom.xml）に保存される、ファイルの「情報」画面で「プロパティの詳細を表示」→「カスタム」タブを開かないと見えない独自項目です。会社や部署で用意された共通テンプレートから文書を作ると、クライアント名・承認者・プロジェクトコード・社内の文書管理システムが振った番号などが、作成者が気づかないまま自動的に書き込まれていることがあります。見た目には一切表示されないため、社外に送る前に見落としやすい情報です。

Q. 「テンプレートの参照パス」「ハイパーリンクの基準パス」とは？

A. ファイルの詳細プロパティ（docProps/app.xml）に保存される項目です。「テンプレート」は、その文書を作るときに使った雛形ファイル（.dotx/.potx/.xltx）の名前や場所で、社内サーバーの共有フォルダを指すパス（例：\\\\社内サーバー名\\テンプレート\\…）がそのまま残っていることがあります。「ハイパーリンクの基準パス」は、文書内の相対リンクの基準になるフォルダのパスで、同様に社内のフォルダ構成が分かってしまう場合があります。

Q. 作成者名を消すツール（sakusha-kesu）と何が違いますか？

A. sakusha-kesuは「作成者」「最終更新者」「会社名」「所属部門」「コメントの投稿者名」という、人物・組織名に関する項目を消します。このツールはそれとは別の保存場所にある「カスタムプロパティ」「テンプレート参照パス」「ハイパーリンクの基準パス」を対象にしており、互いに重複しません。両方を使うとより安心です。

Q. カスタムプロパティの値が消えても、文書の内容は変わりませんか？

A. 変わりません。消すのはdocProps/custom.xml・docProps/app.xmlに保存されたプロパティ情報だけで、本文・セルの値・数式・画像・書式など、文書そのものの内容は一切変更されません。

Q. 対応しているファイル形式は？

A. Excel(.xlsx/.xlsm)、Word(.docx)、PowerPoint(.pptx)です。古い.xls/.doc/.ppt形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_プロパティ削除済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・個人を特定しない形で数えるGoatCounterの通信のみ発生します。入力内容は端末の外に送られません）。

How to use & FAQ

  1. Drag and drop Excel/Word/PowerPoint files into the box above, or click it to choose (multiple files are fine).
  2. Every custom property found is listed in a table. Keep the boxes checked (checked by default) for the ones you want removed, optionally check the template-path / hyperlink-base boxes too, and click "Build" to download the result. Your original file is untouched.

Q. What are "custom properties", and why are they easy to miss?

A. They're arbitrary name/value fields stored inside the file (docProps/custom.xml), only visible from File > Info > "Show All Properties" > the "Custom" tab — nowhere near the document's visible content. A shared company template can silently write a client name, an approver, a project code or an internal document-management ID into these fields without the author ever noticing, which makes them easy to overlook before sending a file outside the company.

Q. What are the "template reference path" and "hyperlink base path"?

A. Both live in the file's extended properties (docProps/app.xml). "Template" records the name/location of the template (.dotx/.potx/.xltx) used to create the document, and can still contain a path to an internal file server (e.g. \\\\server-name\\templates\\...). "HyperlinkBase" is the base folder that relative links in the document resolve against, and can likewise reveal internal folder structure.

Q. How is this different from the author-name tool (sakusha-kesu)?

A. sakusha-kesu clears person/organization fields: creator, last-modified-by, Company, Manager and comment-author names. This tool targets a different storage location — custom properties, the template path and the hyperlink base path — so the two don't overlap. Using both together is the most thorough.

Q. Does removing a custom property change the document's content?

A. No. Only the property data in docProps/custom.xml and docProps/app.xml is removed; the document's actual content — text, cell values, formulas, images, formatting — is left completely untouched.

Q. Which file formats are supported?

A. Excel (.xlsx/.xlsm), Word (.docx) and PowerPoint (.pptx). The older .xls/.doc/.ppt formats and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_properties_removed" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter — nothing you type or upload ever leaves your device).
