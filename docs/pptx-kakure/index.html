社外に渡す前に：PowerPointのノート（発表者メモ）・非表示スライド・コメントを一覧化、ノートはまとめて削除

取引先や社外にPowerPoint(.pptx)ファイルを渡す前に、各スライドの「ノート（発表者メモ）」「非表示スライド」「コメント」が残っていないか一覧で確認したい、というときに。見つかったノートだけをまとめて削除した新しいファイルを書き出せます（非表示スライド・コメントは一覧表示のみ、削除はしません）。複数ファイルを一括処理でき、ファイルはサーバーに送らずこのブラウザの中だけで処理します。元のファイルは変更しません。

ここにPowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.pptx に対応（.pptは読み込めません）。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にPowerPoint(.pptx)ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. スライドごとに「非表示」「ノートの文字数・先頭部分」「コメント件数」が一覧表示されます。ノートが見つかった場合は既定でチェックが入り、「ノートを削除したファイルを書き出す」を押すとノートだけを消した新しいファイルがダウンロードされます。元のファイルはそのまま残ります。

Q. ノート以外（非表示スライド・コメント）も削除できますか？

A. このツールでは一覧表示のみです。非表示スライドは発表時にわざと飛ばしている場合があり、コメントは共同作業中のやり取りそのものであることが多いため、意図せず消えると困る可能性が高いと判断し、安全のため削除機能は付けていません。確認した上で、PowerPoint側の「スライドの非表示」解除や、コメントの削除を行ってください。

Q. 具体的に何を「ノート」の削除対象にしていますか？

A. 各スライドのノートページにある「本文（ノート）」のプレースホルダー内の文字だけです。スライド番号・日付など他のプレースホルダーや、ノートページ自体の存在（部品）はそのまま残り、本文の文字だけが空になります。スライドの画像・レイアウト・書式は変更しません。

Q. コメントは何件・誰が書いたかまで分かりますか？

A. 昔からある形式（レガシー形式）のコメントは件数と投稿者名が分かります。ただし、近年のPowerPoint（Microsoft 365）が使う「スレッド形式」の新しいコメント機能は保存場所の仕様が公開されておらず、このツールでは検出できません。コメント欄に0件と表示されても、実際にはスレッド形式のコメントが残っている可能性があります。最終確認はPowerPoint本体の「コメント」ペインも併用してください。

Q. 非表示スライドの判定はどこを見ていますか？

A. 各スライドのXMLに記録されている「非表示」フラグ（PowerPointの「スライドの非表示」機能でオン・オフされる設定）です。アニメーションでスキップされるだけのスライドなど、この設定を使わない形の「見せない」工夫までは検出できません。

Q. 対応しているファイル形式は？

A. PowerPoint 2007以降の.pptx形式です。古い.ppt形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、ノートを削除した内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_ノート削除済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop PowerPoint (.pptx) files into the box above, or click it to choose (multiple files are fine).
  2. Each slide's hidden status, speaker-notes length/preview and comment count are listed. Slides with notes are checked by default; click "Build the file with notes removed" to download a copy with just the notes cleared. Your original file is untouched.

Q. Can it also remove hidden slides or comments?

A. This tool only lists them. A hidden slide is often hidden on purpose for a specific presentation, and comments are usually an active discussion thread — both are too likely to be removed by accident, so deleting them is left out by design. Review the list, then use PowerPoint's own "Unhide" or comment-deletion features as needed.

Q. Exactly what counts as "notes" to remove?

A. Only the text inside each notes page's body placeholder (the speaker-notes text box). Other placeholders (slide number, date), the notes page itself, and the slide's image, layout and formatting are all left untouched — only the body text is cleared.

Q. Can I see how many comments and who wrote them?

A. Legacy-format comments show a count and the author names. However, the newer "threaded" comment feature in recent PowerPoint (Microsoft 365) stores data in an undocumented location this tool cannot detect — a count of 0 does not guarantee there are no threaded comments. Double-check with PowerPoint's own Comments pane before sending a file out.

Q. How is "hidden slide" detected?

A. The hidden flag recorded in each slide's XML (the same setting PowerPoint's own "Hide Slide" toggles). A slide that's merely skipped by a presenter without using that setting won't be flagged.

Q. Which file formats are supported?

A. PowerPoint 2007+ (.pptx). The older .ppt format and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_notes-removed" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
