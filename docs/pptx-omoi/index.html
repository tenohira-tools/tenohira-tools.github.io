「パワーポイントが重い」原因を診断：ファイル内訳チェッカー

PowerPoint(.pptx)ファイルの容量を、画像・動画・音声・埋め込みオブジェクトなどのパーツ別に内訳表示し、容量を押し上げている可能性が高い原因を順に挙げます。他のテンプレートから引き継いだまま使われていない「スライドレイアウト」や、複数残ったスライドマスターも検出します。ファイルを開かず、ブラウザの中だけで診断します。

ここにPowerPoint(.pptx)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。.pptxのみ対応（.ppt・パスワード保護は読み込めません）。ファイルは選択した端末の中だけで処理されます。

    使い方とよくある質問

    1. 上の枠にPowerPoint（.pptx）ファイルをドラッグ＆ドロップするか、クリックして選びます。
    2. 「全体の内訳」でファイル容量に占める大まかな構成と、スライド・レイアウト・マスターの数を確認します。
    3. 「容量を押し上げている可能性が高い原因」を確認します（スコアが高い順）。
    4. 「パーツ別の容量一覧」で、スライドごと・画像・動画・埋め込みオブジェクトなどの実際のサイズを細かく確認できます。必要ならCSVでダウンロードできます。

    Q. このツールにファイルをアップロードしても安全ですか？

    A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込みが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。ファイルの内容を書き換えたり保存したりすることもありません。

    Q. 「パワーポイントが重い」原因はどうやって調べていますか？

    A. .pptxファイルの実体はZIP形式で、内部にスライド・画像・動画・埋め込みオブジェクト・スライドレイアウト・スライドマスターなどの部品が別々のファイルとして入っています。このツールはZIPの目次（セントラルディレクトリ）から各部品の実際のサイズを読み取って内訳を作り、さらに各スライドが実際にどのスライドレイアウトを使っているかを調べて、容量や動作の重さに関わりやすい箇所を順に挙げます。

    Q. 「使われていないスライドレイアウト」とはどういう意味ですか？

    A. 社内の決まったテンプレートファイルをコピーして新しいプレゼンを作ったり、別の人が作ったスライドを貼り付けたりすると、そのテンプレートに元から用意されていた数十種類のスライドレイアウト（表紙用・見出し用・比較用など）が、実際には使っていないものも含めて全部ファイルの中に残ります。このツールは、ファイル内の全スライドレイアウトのうち、今あるどのスライドからも参照されていないものを検出し、その数と容量を表示します。PowerPointの「表示」→「スライドマスター」画面で、該当するレイアウトを右クリックして削除すると、使っていないレイアウトを減らせます（実際に使っているレイアウトを間違って消さないよう、このツールが挙げた名前で確認してから操作してください）。

    Q. スライドマスターが複数あると何が問題ですか？

    A. スライドマスター1つにつき、その下に数十種類のスライドレイアウトが紐づいています。複数のテンプレートから作ったスライドを1つのファイルにまとめると、スライドマスターごとまとめて増え、使っていないレイアウトも比例して増えやすくなります。

    Q. 画像・動画・音声・埋め込みオブジェクトの違いは何ですか？

    A. 画像はスライドに貼り付けた写真・図などです。動画・音声はそのまま埋め込んだメディアファイルで、1本あたりの容量が画像よりはるかに大きくなりやすいです。埋め込みオブジェクトは、グラフの元データ（Excelブック）や、Word・PDFなどのファイルをアイコンや画面表示のまま貼り付けたものです。

    Q. 対応しているファイル形式は？ファイルサイズの上限はありますか？

    A. PowerPoint 2007以降の.pptx形式に対応しています。古い.ppt形式や、パスワードで保護されたファイルは読み込めません。ファイルはブラウザのメモリ上で処理するため、非常に大きいファイル（数百MB以上）では、診断自体に時間がかかったりブラウザが重くなったりすることがあります。

    Q. 結果通りに直せば必ずファイルが軽くなりますか？

    A. このツールは原因の「可能性」を挙げるだけで、ファイルを書き換えることはしません。実際に軽くするには、使っていないスライドレイアウトの削除、画像の圧縮、動画・埋め込みオブジェクトの整理などをPowerPoint側で行う必要があります。原因が1つに絞れないファイルもあります。

    How to use & FAQ

    1. Drag and drop a PowerPoint (.pptx) file into the box above, or click it to choose one.
    2. Check the overall breakdown: the rough share of each part, plus counts like slides, layouts and masters.
    3. Review the ranked list of likely causes (highest score first).
    4. Use the detailed per-part table (slides, images, video, embedded objects, …) for the exact sizes, and download it as CSV if needed.

    Q. Is it safe to use this on my files?

    A. Yes. Files are never uploaded to a server — everything is read inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter). The file's contents are never modified or saved anywhere.

    Q. How does this figure out why a file feels heavy?

    A. A .pptx file is really a ZIP archive containing separate parts for slides, images, video, embedded objects, slide layouts, slide masters and more. This tool reads the ZIP's central directory to get each part's real size, then checks which slide layout each actual slide uses, and ranks the factors most likely to be adding to the size.

    Q. What does "unused slide layout" mean?

    A. Copying a company template or pasting in slides someone else made brings along every slide layout that template ever defined — title slides, section headers, comparison layouts, and so on — even the ones no slide in this file actually uses. This tool finds every slide layout in the file that no current slide references, and reports its count and size. In PowerPoint's View → Slide Master screen, right-click the layout (by the name this tool reports, to avoid removing one that's actually in use) and delete it to trim the unused ones.

    Q. Why would multiple slide masters be a problem?

    A. Each slide master carries dozens of its own slide layouts underneath it. Combining slides built from several different templates into one file multiplies both the masters and the layouts, including the unused ones.

    Q. What's the difference between images, video/audio and embedded objects?

    A. Images are pictures pasted onto slides. Video/audio are media files embedded as-is, and tend to be far larger than any single image. Embedded objects are things like a chart's source data (an Excel workbook) or a Word/PDF file pasted in and displayed as an icon or preview.

    Q. Which formats and sizes are supported?

    A. PowerPoint 2007+ .pptx files. The older .ppt format and password-protected files are not supported. Everything runs in your browser's memory, so very large files (several hundred MB) may take a while or make the browser sluggish during diagnosis.

    Q. If I act on the results, is the file guaranteed to get smaller?

    A. This tool only reports likely causes — it never modifies your file. Actually shrinking it requires deleting unused slide layouts, compressing images, or cleaning up video/embedded objects in PowerPoint itself. Some files don't have one single cause.
