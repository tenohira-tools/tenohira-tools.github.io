シートの「再表示」に出てこないときの対策：非表示・完全非表示シートの一覧・一括変更

シート見出しを右クリックして「再表示」を開いても、消えたはずのシートの名前が一覧に出てこないことがあります。それは普通の「非表示」ではなく、VBA(マクロ)でしか設定・解除できない「完全非表示（veryHidden）」の可能性があります。Excel(.xlsx/.xlsm)の全シートの表示状態を一覧化し、選んだシートをまとめて表示に戻す（または非表示にする）新しいファイルを書き出します。マクロは使いません。ファイルはサーバーに送信されません。

複数ファイルを一度に追加できます。どこにも送信されません。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. そのファイルに入っている全シートが、現在の表示状態（表示／非表示／完全非表示）のバッジ付きで一覧表示されます。
  3. 各シートの「変更後」欄で、そのシートをどうするか（表示にする／非表示にする／完全非表示にする）を選びます。非表示・完全非表示のシートは既定で「表示」が選ばれています（そのまま「ダウンロード」を押すだけで全部が戻ります）。
  4. 「ファイルをダウンロード」を押すと、選んだ変更を反映した新しいファイルが保存されます（元のファイルは変更されません）。変更したシートだけが一覧上で色の枠で強調表示されます。
  5. 一覧だけCSVで保存したい場合は「一覧をCSV出力」を押します。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 「非表示」と「完全非表示（veryHidden）」はどう違いますか？

A. シート見出しを右クリックして「非表示」にした通常のシートは、「再表示」ダイアログに名前が出て、クリックするだけで元に戻せます。一方、VBA（マクロ）でWorksheets("Sheet1").Visible = xlSheetVeryHiddenのように設定された「完全非表示」のシートは、Excelの「再表示」ダイアログの一覧に一切出てきません。VBAエディタ（開発タブ→Visual Basic）を開いて、該当シートのプロパティから直接「Visible」を変更するしか戻す方法がなく、VBAやマクロに不慣れな場合は事実上手を出せない状態になります。このツールはどちらの状態も検出し、クリックだけで元に戻せます。

Q. なぜ完全非表示のシートが存在するのですか？

A. 作業用の下書き・集計元データ・他のシートが参照している補助シートなどを、通常の「非表示」よりも誤って表示・削除されにくくする目的でVBAから完全非表示に設定することがあります。ファイルを作った人や前任者がこの機能を使っていた場合、引き継いだ側は存在自体に気づけないことがあります。

Q. シートを一覧から選んで「非表示」や「完全非表示」に変更することもできますか？

A. できます。表示中のシートを社外に渡す前に隠したい場合など、逆方向の変更にも対応しています。ただし、全シートの「変更後」が「表示」以外になる組み合わせは選べません（Excelのファイルとして開くには表示中のシートが最低1つ必要なため、ダウンロードボタンが無効になります）。

Q. シートの並び順やセルの内容は変わりますか？

A. 変わりません。変更するのは各シートの表示状態だけで、シートの並び順・名前・セルの値や数式・書式は一切変更しません。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one (several files at once are fine too).
  2. Every sheet in that file is listed with a badge showing its current visibility (visible / hidden / very hidden).
  3. For each sheet, pick what to do with it in the "New state" column (visible / hidden / very hidden). Hidden and very-hidden sheets default to "visible", so just clicking Download brings everything back.
  4. Click "Download file" to save a new file with your chosen changes (the original is untouched). Changed rows are outlined for clarity.
  5. Click "Export list as CSV" to save just the list.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and rewritten inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. What's the difference between "hidden" and "very hidden"?

A. A sheet hidden the normal way (right-click a tab → Hide) shows up by name in Excel's own Unhide dialog — one click brings it back. A sheet set to "very hidden" via VBA (Worksheets("Sheet1").Visible = xlSheetVeryHidden) never appears in that dialog at all. The only built-in way back is opening the VBA editor (Developer tab → Visual Basic) and changing that sheet's Visible property directly — out of reach if you're not comfortable with VBA or macros are disabled. This tool detects both states and lets you flip either one back with a click.

Q. Why would a very-hidden sheet exist in the first place?

A. People sometimes use VBA to mark scratch data, raw source data for other sheets, or helper sheets as very hidden specifically so they're harder to accidentally reveal or delete than an ordinarily hidden sheet. If whoever built the file (or a predecessor) used this, you may inherit the file with no idea such sheets even exist.

Q. Can I also hide or very-hide a currently visible sheet?

A. Yes — useful if you want to hide a sheet before sending the file elsewhere. The only restriction: you can't set every sheet to anything other than visible at once (an Excel file needs at least one visible sheet), so the download button is disabled if your choices would leave none.

Q. Does this change sheet order or cell contents?

A. No. Only each sheet's visibility state is changed — sheet order, names, cell values/formulas and formatting are all left exactly as they were.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported — if a file fails to load, an error is shown next to it.
