Excelの検索は開いているファイルだけ：複数のエクセルファイルから文字列を一括検索

Excelの検索（Ctrl+F）は今開いているブックの中だけが対象で、別々に保存した複数のファイルをまとめて検索することはできません。このツールはExcel（.xlsx/.xlsm）ファイルを複数追加するだけで、全シート・全ファイルを横断して検索し、どのファイルのどのシート・セルに見つかったかを一覧表示・CSV出力します。セルの値（共有文字列・インライン文字列・数値など）と、数式そのものの文字列（フィルハンドルでコピーされた共有数式も復元）の両方を検索対象にできます。読み取り専用で、ファイルはサーバーに送信されません。

Q. Excel自体の検索（Ctrl+F）と何が違いますか？

A. Excelの検索は、今アクティブなウィンドウで開いているブック（ファイル）の中だけが対象です。別々に保存した複数のファイルを一括で検索することはできず、1つずつ開いて検索し直す必要があります。このツールは複数のExcelファイルをまとめて追加するだけで、全ファイル・全シートを一度に検索し、どのファイルのどのシート・セルに見つかったかを一覧化・CSV出力します。

Q. どこを検索の対象にしていますか？

A. セルの値（共有文字列・インライン文字列・数値を文字列化したもの・TRUE/FALSE）と、数式そのものの文字列（例：="A"&A1 のような数式に含まれる関数名・引用符内の文字列・セル参照そのもの）の、どちらを対象にするかを個別に選べます。数式は再計算せず、ファイルに保存されている数式の文字列をそのまま検索します。エラー値（#REF!等）が入っているセルの値は検索対象外です。

Q. フィルハンドルでコピーされた数式（共有数式）も検索できますか？

A. はい。Excelがコピー時に使う「共有数式」は先頭のセルだけが数式の文字列を持ち、残りのセルは参照番号だけを持つ仕組みのため、このツールは先頭セルの数式からセル参照をずらして各セルの数式を復元したうえで検索します（復元が推定であることはご了承ください）。

Q. 大文字・小文字、全角・半角は区別されますか？

A. 既定では大文字・小文字を区別せずに検索します（チェックを外すと区別します）。半角・全角、ひらがな・カタカナの表記ゆれは自動的には統一されないため、見つからない場合は検索語の表記を変えて試してください。

Q. 「完全一致」は何が変わりますか？

A. オンにすると、セルの値全体が検索語とちょうど一致するものだけを対象にします（「1」のような短い値を探すとき、部分一致では無関係な値まで多数ヒットするのを防げます）。数式の検索は常に部分一致です。

Q. このツールはファイルを書き換えたり、削除したりできますか？

A. いいえ。読み取り専用の検索・一覧化・CSV出力だけを行い、ファイルは一切書き換えません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・検索されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more at once.
  2. Once loading finishes, type what you're looking for into the search box — results update as you type.
  3. Toggle "Search values", "Search formula text", "Ignore case" and "Exact match" as needed.
  4. If there are a lot of results, narrow them down by file, sheet, or type (value/formula).
  5. Click "Download as CSV" to save the list — exactly what the filters currently show.

Q. How is this different from Excel's own Find (Ctrl+F)?

A. Excel's own Find only searches the workbook you currently have open in the active window — it can't search several files you've saved separately in one pass; you'd have to open and search each one in turn. This tool lets you add multiple Excel files at once and searches every file and sheet in one pass, listing exactly which file, sheet and cell each match is in, exportable as CSV.

Q. What does it actually search?

A. You can independently choose whether to search cell values (shared strings, inline strings, numbers rendered as text, TRUE/FALSE) and/or the raw text of formulas themselves (e.g. function names, quoted string literals and cell references inside a formula like ="A"&A1). Nothing is recalculated — formulas are matched against the text actually stored in the file. Cells holding a cached error value (#REF! etc.) are excluded from the value search.

Q. Does it search formulas copied with the fill handle (shared formulas)?

A. Yes. Excel's "shared formula" optimization stores the full formula text only on the first cell in the group, with the rest holding just a reference index — so this tool reconstructs each cell's formula by shifting the first cell's formula text by the right number of rows/columns before searching (this reconstruction is a best-effort estimate).

Q. Is matching case-sensitive, and are full-width/half-width or kana forms normalized?

A. By default matching ignores case (uncheck the box to make it case-sensitive). Full-width/half-width characters and hiragana/katakana are not automatically normalized, so try a different form of your search term if nothing turns up.

Q. What does "Exact match" change?

A. With it on, only cells whose entire value exactly equals your search term are included — useful for short values like "1" that would otherwise match far too much with a plain substring search. Formula search is always a substring match.

Q. Can this tool rewrite or remove anything?

A. No. This is a read-only search/listing/CSV-export tool — it never rewrites your file.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and searched inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.
