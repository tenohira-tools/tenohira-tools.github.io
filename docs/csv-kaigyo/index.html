Q. なぜセル内改行で行がずれるのですか？

A. ExcelでセルにAlt+Enterで改行を入力してCSVとして保存すると、そのセルはダブルクォート（"）で囲まれ、改行は文字としてそのままセルの中に保存されます。これはCSVの正式な仕様ですが、1行＝1レコードだと単純に思い込んでいるテキストエディタや自作の行区切り処理で読み込むと、そのセルの中の改行が余分な行として数えられてしまい、行がずれて見えたり後続の列が崩れたりします。

Q. 本来の行の区切り（改行）も消えてしまいませんか？

A. いいえ。このツールはCSVの引用符のルールに従って正しく解析するため、ダブルクォートで囲まれたセルの中にある改行だけを検出・置き換えます。行と行を分ける本来の改行はそのまま残ります。

Q. 置き換える文字を空欄にするとどうなりますか？

A. 改行を完全に削除し、前後の文字をそのままつなげます。単語の間にスペースなどを挟みたい場合は、空欄のままにせず「置き換える文字」に入力してください。

Q. セルの中に改行が複数回（空行を含めて）入っている場合は？

A. 連続した改行はまとめて検出し、1回だけ置き換えます。空行が複数続いていても置き換える文字が何個も連続することはありません。

Q. アップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのブラウザの中だけで処理されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 大きなファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、数十MB程度までを想定しています。

How to use & FAQ

  1. Drag and drop a CSV file into the box above, or click it to choose a file.
  2. Every cell that contains a line break is listed. If none are found, you'll see "No line breaks were found".
  3. Type a replacement (a space, or leave it blank to delete entirely) — the "After" column updates live.
  4. Check the list, then click "Fix and download CSV".

Q. Why does a line break inside a cell make rows look shifted?

A. When you press Alt+Enter inside an Excel cell and save as CSV, that cell is wrapped in double quotes and the line break is kept literally inside it — this is valid CSV. But a text editor or a naive line-by-line reader that assumes "one line = one row" counts that embedded break as an extra row, so everything after it looks shifted or the columns break.

Q. Will it also remove the real line breaks that separate rows?

A. No. This tool parses the CSV's quoting rules correctly, so it only touches line breaks inside quoted cells. The real line breaks that separate one row from the next are left untouched.

Q. What happens if I leave the replacement blank?

A. The line break is removed entirely and the text before and after it is joined directly. If you want a space (or anything else) between them, type it into the replacement field instead of leaving it blank.

Q. What if a cell has several line breaks, or blank lines, in a row?

A. A run of consecutive line breaks is treated as one and replaced only once — you won't get several replacement characters in a row from a blank line inside a cell.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded — everything is processed inside this browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Can it handle large files?

A. Everything runs in browser memory, so it's built for files up to tens of megabytes.
