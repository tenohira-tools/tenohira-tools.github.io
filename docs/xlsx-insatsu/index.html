シートごとに印刷範囲・印刷タイトル・改ページがバラバラなときの一覧・一括解除

Excelでシートを増やしていくと、印刷範囲・印刷タイトル（繰り返す行/列）・手動の改ページ位置がシートごとに別々に設定され、どのシートに何が設定されているか分からなくなります。「ページレイアウト」タブの各機能はシートを選んでから1枚ずつ操作するしかなく、全シートを一度に確認・解除する手段はありません。このツールはExcel(.xlsx/.xlsm)の全シートを解析し、印刷範囲・印刷タイトル・改ページの設定状況を一覧表示したうえで、選んだシート・項目だけをまとめて解除した新しいファイルを書き出します。印刷の向き・用紙サイズ・拡大縮小・余白は変更しません。元のファイルも変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。全シートの印刷範囲・印刷タイトル・改ページを解析します。ファイルは選択した端末の中だけで処理されます。

シートごとの印刷設定

チェックした項目を解除した新しいファイルを書き出せます。

印刷範囲・印刷タイトル・改ページは、どのシートにも設定されていませんでした。

シート別の一覧

チェックを入れた項目だけが解除されます。設定が無い項目のチェックボックスは操作できません。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 自動で解析され、シートごとに印刷範囲・印刷タイトル・改ページ（行/列の件数）の有無が一覧表示されます。
  3. 解除したい項目にチェックを入れ（「設定がある項目を全て選択」で一括チェックも可能）、「選んだ項目を解除したファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. 「印刷範囲」「印刷タイトル」「改ページ」とは何ですか？

A. 「印刷範囲」は、ページレイアウトタブの「印刷範囲」で設定した「このセル範囲だけを印刷する」という指定です（xl/workbook.xmlの組み込みの名前定義 _xlnm.Print_Area として保存されます）。「印刷タイトル」は同タブの「印刷タイトル」で設定した「全ページに繰り返し印刷する行・列」の指定です（同じく _xlnm.Print_Titles）。「改ページ」は、セルを選んで手動で挿入した改ページ（表示タブの「改ページプレビュー」で実線として表示される区切り）です。これら3つはいずれもシートごとに個別に設定するしかなく、Excel自体に全シートをまとめて確認・解除する画面はありません。

Q. 「すべての改ページを解除」コマンドと何が違いますか？

A. Excelの「ページレイアウト」タブにある「改ページ」→「すべての改ページを解除」は、今選んでいる1枚のシートの手動改ページだけを解除するコマンドです。シートが多いブックでは、この操作をシートの数だけ繰り返す必要があります。このツールは、その操作を含む3項目（印刷範囲・印刷タイトル・改ページ）を全シート分まとめて一覧化し、選んだシートだけ一度に解除します。

Q. 印刷の向き・用紙サイズ・拡大縮小・余白・ヘッダーフッターは変わりますか？

A. 変わりません。このツールが変更するのは印刷範囲・印刷タイトル・手動の改ページ位置の3項目だけです。ページの向き・サイズ・拡大縮小・余白・ヘッダーフッターの設定（xl/worksheets内のpageSetup・pageMargins・headerFooter要素）はそのまま残ります。

Q. 印刷範囲を解除すると何が印刷されますか？

A. 印刷範囲を明示的に指定していない状態と同じになり、Excelは各シートの使用範囲（データが入っている範囲）をもとに自動で印刷対象を判定します。使用範囲自体が実データより広がっている場合は、白紙ページが出ることがあります（この症状には「使用範囲」リセットツールが対応します）。

Q. 一部のシートだけ解除することはできますか？

A. できます。一覧のチェックボックスはシート・項目ごとに独立しています。あるシートは印刷範囲だけ解除し、別のシートは改ページだけ解除する、といった選び方も可能です。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_印刷設定クリア」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・個人を特定しない方法で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. It's analyzed automatically: for every sheet, whether a print area, print titles, and manual page breaks (row/column counts) are set.
  3. Check the items you want cleared (or use "Select everything that's set" to check them all at once), then click "Build a file with the checked items cleared" to download it. Your original file is untouched.

Q. What are "print area", "print titles" and "page breaks"?

A. The print area (Page Layout tab → Print Area) restricts printing to a specific cell range, stored as the built-in defined name _xlnm.Print_Area in xl/workbook.xml. Print titles (Page Layout tab → Print Titles) repeat chosen rows/columns on every printed page, stored as _xlnm.Print_Titles. Manual page breaks are breaks you inserted yourself by selecting a cell (shown as solid lines in Page Break Preview). All three can only be set one sheet at a time in Excel — there's no built-in screen that reviews or clears them across every sheet at once.

Q. How is this different from Excel's own "Reset All Page Breaks"?

A. Excel's Page Layout → Breaks → Reset All Page Breaks only clears the manual breaks on the sheet you currently have open. In a workbook with many sheets you'd have to repeat it sheet by sheet. This tool lists all three settings (print area, print titles, page breaks) across every sheet at once and clears only the ones you select, in a single pass.

Q. Will this change the page orientation, paper size, scaling, margins or header/footer?

A. No. Only the print area, print titles and manual page breaks are touched. Orientation, paper size, scaling, margins and header/footer settings (the pageSetup, pageMargins and headerFooter elements) are left exactly as they were.

Q. What gets printed after clearing the print area?

A. Same as if no print area had ever been set: Excel falls back to each sheet's used range to decide what to print. If that used range itself extends past your real data, you may still see blank pages — our used-range reset tool handles that specific case.

Q. Can I clear just some sheets, or just one setting?

A. Yes. Every checkbox is independent per sheet and per item — you could clear only the print area on one sheet and only the page breaks on another.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result downloads as a new file (with "_print-settings-cleared" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
