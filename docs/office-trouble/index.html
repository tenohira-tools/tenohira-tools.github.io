Word・PowerPoint 社外に渡す前のチェックガイド

Word/PowerPoint Pre-Share Checklist

「隠れた情報が残っていないか」「ファイルが重い」「グラフのデータが丸ごと見える」など、取引先や社外に渡す前によくある困りごとから該当するツールを選べます。全てブラウザ内だけで動く無料ツールで、ファイルはどこにも送信されません。

Pick the tool that matches what's bothering you before you send a Word or PowerPoint file outside your company — hidden metadata, a file that's too heavy, or a chart that reveals more than you meant to show. All 9 tools run entirely in your browser; your file is never uploaded anywhere.

Wordに変更履歴・コメント・隠し文字など「隠れた情報」が残っていないか確認したい

Check Word for hidden tracked changes, comments, or hidden text

  • 社外に渡す前に確認：Wordの「隠れた情報」一括チェック

    変更履歴（校閲）の編集者名、コメントの投稿者名、隠し文字、作成者・最終更新者・会社名、ヘッダー・フッターの文字を1画面で診断。Windows版の「ドキュメント検査」の代わりに使える読み取り専用ツール。

    Diagnose tracked-change authors, comment authors, hidden text, document properties, and header/footer text in one screen — a read-only stand-in for Windows-only Document Inspector.

作成者・最終更新者・コメントの投稿者名を消したい

Remove the author / last-modified-by / comment-author names

  • 社外に渡す前に、Excel・Word・PowerPointの「作成者・最終更新者・コメントの投稿者名」を消す

    Excel・Word・PowerPointの3形式に対応し、複数ファイルを一括処理。Wordの変更履歴に残る編集者名の匿名化にも対応。

    Works on Excel, Word, and PowerPoint files at once, including anonymizing the editor names left in Word's tracked changes.

複数のWordファイルの変更履歴（校閲）をまとめて確定したい

Accept all tracked changes across several Word files at once

  • 複数のWordファイルの変更履歴（校閲）を一括で確定・反映

    1件ずつ開いて「すべての変更を反映」を押す手間をなくし、挿入・削除・移動をまとめて確定。コメント削除はオプション。

    Skip opening each file to click "Accept All" — insertions, deletions, and moves are all finalized at once, with optional comment removal.

Wordファイルが重い・容量が大きい

A Word file is too heavy / too large

  • 「Wordファイルが重い」原因を診断：ファイル内訳チェッカー

    画像・埋め込みオブジェクト・埋め込みフォントのパーツ別容量に加え、画像をトリミングしても削除されず残っている元データの推定容量を検出。

    Breaks down file size by part (images, embedded objects, embedded fonts) and detects leftover image data hidden behind a crop.

パワーポイントが重い・容量が大きい

A PowerPoint file is too heavy / too large

  • 「パワーポイントが重い」原因を診断：ファイル内訳チェッカー

    画像・動画・音声・埋め込みオブジェクトのパーツ別容量に加え、テンプレートのコピーなどで増えた「使われていないスライドレイアウト」「複数のスライドマスター」を検出。

    Breaks down file size by part and detects unused slide layouts and extra slide masters left over from copied templates.

グラフを「データの編集」で開くと元の表が丸ごと見える

Editing a chart's data reveals the whole original table

  • 「グラフのデータを編集」で元の表が丸ごと見える：PowerPointグラフの埋め込みExcel診断ツール

    グラフに表示していない余分な行・列が埋め込みExcelシートに残っていないか、ファイルを開かず全スライドのグラフを一括診断。

    Diagnoses every chart across all slides, without opening the file, for leftover rows or columns in the embedded Excel sheet that the chart itself doesn't display.

ノート（発表者メモ）・非表示スライド・コメントを確認したい

Check speaker notes, hidden slides, and comments

  • 社外に渡す前に：PowerPointのノート（発表者メモ）・非表示スライド・コメントを一覧化、ノートはまとめて削除

    スライドごとにノート・非表示フラグ・コメント（投稿者名含む）を一覧表示し、ノート本文だけをまとめて削除した新しいファイルを書き出す。

    Lists speaker notes, the hidden flag, and comments (with author names) per slide, and can clear just the notes into a new file.

埋め込まれた画像をまとめて取り出したい

Extract all embedded images at once

  • Excel・Word・PowerPointの画像をまとめて保存：zip変換せず一括抽出

    拡張子をzipに変えて展開する手作業の代わりに、埋め込まれた画像をまとめて抽出。どのシート・スライド・本文で使われているかの対応表CSV付きでZIPダウンロード。

    Extracts every embedded image at once — no renaming the file to .zip by hand — with a CSV mapping each image to the sheet, slide, or body text that uses it.

ハイパーリンクが開けない・社内専用のリンクが残っていないか確認したい

Check for hyperlinks that won't open or still point to an internal-only location

  • Word・PowerPointのハイパーリンクが開けない・社内専用のリンクが残っているときの一覧・削除ツール

    本文・ヘッダー・フッター・脚注（Word）、スライドのテキスト・図形（PowerPoint）のハイパーリンクを一覧化し、社内の共有フォルダを指す「ローカルファイル」へのリンクや、参照先が無くなった「壊れているリンク」を自動検出して解除。

    Lists every hyperlink in the document body, headers, footers and footnotes (Word) or on each slide's text and shapes (PowerPoint), and flags links to a local file/network share or ones that are broken, so you can remove just those.

このページについて

Q. このページは何をするところですか？

A. Word・PowerPointファイルを社外に渡す前によくある困りごとを症状別に分類し、このサイトで公開している9個の無料ツールへの案内をまとめたページです。このページ自体はファイルを処理しません。

Q. Excelファイル（.xlsx）のトラブルはありますか？

A. 「重い」「保存できない」「エラーが出る」などExcel特有のトラブルはエクセルのトラブル解決ガイドにまとめています。CSVファイルのトラブルはCSVのトラブル解決ガイドにまとめています。

Q. 料金や登録は必要ですか？

A. すべて無料・登録不要です。ファイルはアップロードされず、お使いのブラウザの中だけで処理されます（このページ・各ツールページの閲覧数だけ、Cookieなし・個人を特定しない方法で計測しています）。

About this page

Q. What does this page do?

A. It's a directory that sorts common pre-share Word/PowerPoint problems by symptom and points you to the matching free tool among the 9 listed above. This page itself does not process files.

Q. What about Excel (.xlsx) or CSV file problems?

A. Excel-specific issues are covered in the Excel Troubleshooting Guide, and CSV issues in the CSV Troubleshooting Guide.

Q. Is this free, and do I need to sign up?

A. Yes, free and no sign-up. Files are never uploaded — everything runs in your browser (only an anonymous, cookie-free page-view count is collected for this page and each tool page).
