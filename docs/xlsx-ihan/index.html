「無効なデータ」の丸印は1シートずつ：入力規則に違反した値を全シート一括で一覧化

Excelの「データの入力規則」→「無効なデータ」(丸で囲む)はシートごとに実行する必要があり、結果を一覧やCSVに書き出すこともできません。このツールはExcel（.xlsx/.xlsm）の全シート・複数ファイルを横断して、入力規則（リストのプルダウン・数値や文字数の範囲・日付など）に実際に違反している値が入ったセルだけを一覧表示し、CSVに出力します。カスタム数式や、セル参照・名前定義を使った複雑な条件は安全のため判定対象外とし、その旨を別途表示します。読み取り専用で、ファイルはサーバーに送信されません。

Q. Excel自体の「無効なデータを丸で囲む」機能と何が違いますか？

A. Excelのこの機能は、今アクティブなシートに対してボタンを押すたびに実行する必要があり、全シート・複数ファイルを一度に調べることはできません。結果を一覧やCSVに書き出すこともできません。このツールは複数ファイル・複数シートを横断して一度に全件を判定し、見つかった違反セルを一覧化・CSV出力できます。

Q. どの種類の入力規則を判定できますか？

A. 次の場合だけ、安全に判定できると判断して実際の値をチェックします。①リスト（プルダウン）型のうち、項目が直接入力（例：「はい,いいえ」）か、同一シート・他シートの具体的なセル範囲を参照している場合（その範囲の実際の値を読み取って比較します）。②整数・小数・日付・時刻・文字数の各型のうち、条件の上限・下限が数値としてそのまま設定されている場合（セル参照や数式で指定されている場合は対象外）。それ以外（カスタム数式、名前定義経由のリスト、OFFSET/INDIRECTなどの動的なリスト、条件がセル参照になっているもの等）は、誤った判定をしないよう「判定できないルール」として除外し、違反としても安全としても扱いません。

Q. 「違反している」とはどういう状態ですか？

A. そのセルに実際に入っている値（数式の場合はファイルに保存されている計算結果）が、設定されている入力規則の条件を満たしていない状態です。たとえばリストに無い値が入力されている、数値の範囲外の値が入っている、整数のはずが小数になっている、文字数が条件外、などです。空欄のセルは常に対象外（違反として数えません）。エラー値（#REF!等）が入っているセルも、このツールでは判定対象外です。

Q. 数式が入ったセルも判定されますか？

A. はい。ただし再計算は行わず、ファイルに保存されている計算結果（キャッシュされた値）だけを使って判定します。ファイルを最後に保存したときの状態を確認するものだと考えてください。

Q. このツールはファイルを書き換えたり、削除したりできますか？

A. いいえ。読み取り専用の一覧化・CSV出力だけを行い、ファイルは一切書き換えません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more.
  2. Check the summary panel for the total number of validation rules found, how many could actually be checked, and how many violating cells were found.
  3. Use the filters to narrow the violation list down by file, sheet or rule type.
  4. Click "Download as CSV" to save the list — exactly what the filters currently show.
  5. Rules that couldn't be checked are listed under "View rules that couldn't be checked" below the main list.

Q. How is this different from Excel's own "Circle Invalid Data"?

A. Excel's own command has to be run on the active sheet, one sheet at a time, with no way to scan every sheet and file at once or export the result as a list or CSV. This tool checks every file and sheet in one pass and lists the violating cells as a filterable table or CSV.

Q. Which rule types can actually be checked?

A. Only cases where a value comparison is safe to make: (1) List (dropdown) rules whose source is either a literal quoted list (e.g. "Yes,No") or a concrete cell range on the same or another sheet — the actual values in that range are read and compared against. (2) Whole number, decimal, date, time and text-length rules whose upper/lower bound is a plain literal number in the rule itself (not a cell reference or formula). Everything else — custom-formula rules, list sources that go through a defined name, dynamic sources built with OFFSET/INDIRECT, or bounds given as a cell reference — is excluded as "not checked" rather than guessed at, and is never counted as either a violation or as valid.

Q. What counts as "violating"?

A. The value actually stored in the cell (for a formula cell, its cached result) doesn't satisfy the rule that's set on it — e.g. a value not in the dropdown list, a number outside its allowed range, a decimal where a whole number is required, or text longer/shorter than the allowed length. Blank cells are always excluded (never counted as violating). Cells holding a cached error value (#REF! etc.) are also excluded from this check.

Q. Are formula cells checked too?

A. Yes, but nothing is recalculated — only the cached result already saved in the file is used. Think of it as a snapshot of the file as it was last saved.

Q. Can this tool rewrite or remove anything?

A. No. This is a read-only listing/CSV-export tool — it never rewrites your file.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.
