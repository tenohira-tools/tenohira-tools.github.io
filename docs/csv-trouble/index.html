CSV Troubleshooting Guide

「文字化けする」「結合できない」「表記がバラバラ」「Excelで開くと0が消える」など、症状から該当するツールを選べます。全てブラウザ内だけで動く無料ツールで、ファイルはどこにも送信されません。

Pick the tool that matches your symptom — mojibake, files that won't merge, inconsistent notation, or Excel mangling your CSV on open. All 7 tools run entirely in your browser; your file is never uploaded anywhere.

開くと文字化けする（□□□になる）

It turns into mojibake when opened

  • CSVやテキストを開くと文字化けする：文字コード変換ツール

    Shift_JIS・EUC-JPで文字化けしたファイルをUTF-8に変換。ExcelでCSVが文字化けする原因のBOM追加・削除にも対応。

    Convert Shift_JIS/EUC-JP CSV files to UTF-8, and add or remove a BOM to fix mojibake in Excel.

列の表記（全角半角・カナ・郵便番号・ハイフン）がバラバラ

A column's notation is inconsistent

  • 全角半角・カナ・郵便番号の表記ゆれをまとめて統一：CSV書式統一ツール

    列ごとに「全角英数字→半角」「半角カナ→全角カナ」「郵便番号を123-4567に統一」「ハイフン類の統一」を選んで適用。

    Normalize full/half-width characters, katakana, postal codes and hyphen styles, column by column.

複数のCSVを結合できない

Can't merge multiple CSV files

  • 文字コードがバラバラな複数のCSVを結合できない：複数CSV結合ツール

    ファイルごとに文字コード（Shift_JIS・EUC-JP・UTF-8）を自動判定し、見出し名で列をそろえて結合（無い列は空欄）。

    Auto-detect each file's encoding and merge them, aligning columns by header name — missing columns are left blank.

列の値ごとに複数ファイルへ分けたい

Want to split by a column's value

  • CSVを列の値ごとに自動分割

    都道府県・店舗・担当者などの値ごとに振り分けて複数ファイルに分割し、ZIPでまとめてダウンロード。行数での機械的な分割ではない。

    Split one CSV into files grouped by a column's value (store, prefecture, etc.), downloaded as a single ZIP.

コード列を名称などに一括変換したい

Want to convert codes to names in bulk

  • CSVのコード→名称 一括変換ツール

    データCSVのコード列を、対応表（マスタ）CSVと突き合わせて店舗名・氏名などの列を一括追加。一致しない行は空欄のまま、推測しない。

    Join a data CSV's code column against a lookup-table CSV to add name columns in bulk — unmatched rows stay blank, never guessed.

Excelで開くと0が消える・日付に化ける

Excel drops leading zeros or mangles dates on open

  • CSVの先頭の0が消える・日付に化けるときのExcel変換

    郵便番号・社員番号・JANコードの先頭の0が消える、「1-2」が日付になってしまう列を選んで文字列として保存し、CSVをExcel(.xlsx)に変換。

    Convert a CSV to Excel (.xlsx) without losing leading zeros or having values turn into dates — choose which columns stay text.

日付の書き方（和暦・西暦）が混在している

Dates mix Japanese-era and Western formats

  • 和暦・西暦 混在日付の一括統一

    「令和6年1月2日」「R6.1.2」「2024/1/2」など混在した日付をCSVや文章からまとめて検出し、指定の形式に統一。元号の境目を越えた存在しない日付は変換せずに知らせる。

    Find and unify mixed Japanese-era and Western date formats in a CSV or text — dates that fall outside a real era boundary are flagged, never silently guessed.

セルの中の改行で行がずれる・列が崩れる

A line break inside a cell shifts rows or breaks columns

  • CSVのセル内改行で行がずれる・列が崩れるときの削除・置換ツール

    CSVの引用符ルールを正しく解析し、セルの中にある改行だけを検出。削除または任意の文字（スペースなど）に置き換えた新しいCSVを書き出す。行の区切りとして使われる本来の改行はそのまま保持。

    Parses CSV quoting rules correctly to find only the line breaks inside cells, then deletes or replaces them — the real line breaks that separate rows are left untouched.

このページについて

Q. このページは何をするところですか？

A. CSVファイルのよくあるトラブルを症状別に分類し、このサイトで公開している8個の無料ツールへの案内をまとめたページです。このページ自体はファイルを処理しません。

Q. Excelファイル（.xlsx）のトラブルはありますか？

A. 「重い」「保存できない」「エラーが出る」などExcel特有のトラブルはエクセルのトラブル解決ガイドにまとめています。

Q. 料金や登録は必要ですか？

A. すべて無料・登録不要です。ファイルはアップロードされず、お使いのブラウザの中だけで処理されます（このページ・各ツールページの閲覧数だけ、Cookieなし・個人を特定しない方法で計測しています）。

About this page

Q. What does this page do?

A. It's a directory that sorts common CSV problems by symptom and points you to the matching free tool among the 8 listed above. This page itself does not process files.

Q. What about Excel (.xlsx) file problems?

A. Excel-specific issues like heavy files, save errors or stray error values are covered in the Excel Troubleshooting Guide.

Q. Is this free, and do I need to sign up?

A. Yes, free and no sign-up. Files are never uploaded — everything runs in your browser (only an anonymous, cookie-free page-view count is collected for this page and each tool page).
