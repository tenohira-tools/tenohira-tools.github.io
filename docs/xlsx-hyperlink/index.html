ハイパーリンクが開けない・大量にあって消せないときの一覧・削除ツール

クリックすると「指定されたファイルが見つかりません」「参照が正しくありません」と出る、コピペで増えすぎて1つずつ[ハイパーリンクの編集]で解除していくのが大変——というExcel(.xlsx/.xlsm)ファイルのハイパーリンク（セルに設定されたクリック可能なリンク）を、全シート横断で一覧表示します。ローカルファイルへのリンク（他のPCでは開けない可能性）、存在しないシート・セル範囲を指す社内リンク、参照そのものが壊れているリンクを自動で見分け、選んだリンクだけを解除した新しいファイルをその場で書き出せます。セルの文字や値は変わりません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。すべてのシートのハイパーリンクをまとめて抜き出します。ファイルは選択した端末の中だけで処理されます。

ハイパーリンクの集計

「ローカルファイル」はURLでも社内リンクでもなく、パソコンの中のファイルパスを指しているリンクです。ファイルを他の人に送ったり別のPCで開いたりすると、そのパスが存在せず開けなくなります。

ハイパーリンクの一覧

選んだリンクは「クリックすると開く」設定だけが解除されます。セルの文字（表示されている文字列）や値・数式は変わらず、クリックできないただの文字として残ります。削除後はExcelで開いて確認してください。元のファイルは変更されず、新しいファイルとして書き出されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 一覧で、各リンクの対象シート・セル・種類・リンク先と、「ローカルファイル」「存在しないシート参照」「参照が壊れている」の旗を確認します。
  3. 解除したいリンクにチェックを入れます（クイック選択ボタンで一括選択も可能）。
  4. 「選んだリンクを解除したファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. ここでいう「ハイパーリンク」とは何ですか？数式の外部参照とは違いますか？

A. 違います。このツールが対象にしているのは、セルに直接設定されている「クリックすると開く」リンク（Webページ・メールアドレス・パソコン内のファイル・同じブック内の別シートやセル範囲へのジャンプ）です。Excelでは[挿入]→[リンク]や[Ctrl]+[K]で設定するものがこれにあたります。一方、「=[参照先.xlsx]Sheet1!A1」のような数式の中に書かれた他のファイルへの参照（外部ソースへのリンク）は仕組みが別物で、そちらは当サイトの外部ソースへのリンク発生源を探すツールで扱っています。両方設定されているファイルでは、両方のツールを使うと網羅的に点検できます。

Q. 「ローカルファイル」「存在しないシート参照」「参照が壊れている」はそれぞれ何を意味しますか？

A. 「ローカルファイル」は、リンク先がWebのURL（http/https）やメールアドレス（mailto）ではなく、パソコンの中のファイルパス（例："C:\Users\…\見積書.xlsx" や「..\共有\資料.pdf」）になっているリンクです。自分のパソコンでは開けても、ファイルだけを人に送ったり別のPCで開いたりすると、同じ場所に同じファイルが無いため開けません。「存在しないシート参照」は、ブック内の別シートやセル範囲へジャンプするリンクが、現在のブックに存在しないシート名や名前付き範囲を指している状態です。シートの名前を変えたり削除したりした後に残ったリンクで起こります。「参照が壊れている」は、リンクの実体を指す内部の参照情報そのものが見つからない状態で、クリックすると「指定されたファイルが見つかりません」のようなエラーになったり、何も起きなかったりします。

Q. 大量のハイパーリンクが、コピペのたびに増えるのはなぜですか？

A. セルをコピーすると、そのセルに設定されたハイパーリンクも一緒にコピーされます。同じセルを何度も別の場所に貼り付けたり、行・列を挿入して既存の行をコピーして増やしたりする使い方を繰り返すと、同じリンク先を指すハイパーリンクがシート中に大量に残ることがあります。Excel標準の[ハイパーリンクの編集]ダイアログは1つずつしか開けず、全部を一度に見る手段が無いため、このツールでは全シートを横断して一覧化しています。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。図形・画像に設定されたハイパーリンク（セルではなく図形オブジェクト側の設定）は、現在のバージョンでは一覧に含まれません。

Q. リンクを解除すると、セルの文字や値は変わりますか？

A. 変わりません。解除されるのは「クリックすると開く」という設定だけです。セルに表示されている文字列・値・数式・書式（下線や青字などの見た目）はそのまま残ります。見た目まで変えたい場合は、解除後にExcel側で文字色や下線を手動で直してください。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_リンク解除済み」を付けます）。元のファイルを直接上書きすることはありません。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Check each link's sheet, cell, type, target, and the "local file", "broken in-sheet reference" and "missing relationship" flags.
  3. Tick the links you want to remove (the quick-select buttons select several at once).
  4. Click "Build a file with the selected links removed" to download the cleaned copy — your original file is untouched.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. What counts as a "hyperlink" here — is it the same as an external formula reference?

A. No. This tool handles clickable links attached directly to a cell (a web page, an email address, a file on your computer, or a jump to another sheet/range in the same workbook) — the kind you set with Insert > Link or Ctrl+K. A formula that references another file, like =[Source.xlsx]Sheet1!A1, is a different mechanism; that's covered by our external-workbook link finder. A file with both kinds benefits from running both tools.

Q. What do "local file", "broken in-sheet reference" and "missing relationship" mean?

A. "Local file" means the link points to a path on a computer's own disk (e.g. C:\Users\…\quote.xlsx) rather than a web URL or email address — it may work on your machine but breaks the moment the file is shared or opened elsewhere. "Broken in-sheet reference" means a jump-to-another-sheet link points at a sheet name or named range that no longer exists in the current workbook, usually left behind after a sheet was renamed or deleted. "Missing relationship" means the link's own internal pointer to its target is gone, which typically shows an error (or does nothing) when clicked.

Q. Why do hyperlinks keep piling up from copy-paste?

A. Copying a cell copies its hyperlink along with it. Repeatedly pasting the same cell elsewhere, or inserting rows by copying existing ones, can leave many cells pointing at the same target scattered across a sheet. Excel's own "Edit Hyperlink" dialog only shows one at a time with no way to see them all at once, which is why this tool lists every sheet together.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported. Hyperlinks attached to shapes or images (rather than cells) are not currently listed.

Q. Does removing a link change the cell's text or value?

A. No. Only the "clickable" setting is removed. The cell's displayed text, value, formula and formatting (underline, blue text, etc.) are untouched — if you also want the look changed, fix the font color/underline in Excel afterward.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_links-removed" appended to the name). Your original file is never overwritten.
