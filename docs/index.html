てのひらツール tenohira tools

ブラウザだけで動く無料ツール集。登録不要。Cookieなし・個人を特定しないアクセス数の計測のみ（GoatCounter）。入力内容は端末の外に送られません。
Free tools that run entirely in your browser. No sign-up. Only anonymous, cookie-free page-view counting (GoatCounter) — what you enter never leaves your device.

経理・事務書類 Paperwork & receipts

  • 証憑ファイル名整理ツール

    領収書・請求書に日付・取引先・金額を入力して一括リネーム。対応ブラウザはフォルダを選んで直接リネーム、それ以外はコピーを一括ダウンロード。 / Rename receipts and invoices in bulk with date/vendor/amount — direct in-folder rename on supported browsers.

  • 領収書まとめ台紙メーカー

    複数のレシート・領収書の写真を並べ方（2×2〜3×4）を選ぶだけでA4のPDFにまとめて整列。経費精算の添付や紙の台紙貼り付けに。 / Arrange multiple receipt photos into a printable A4 PDF sheet, entirely in your browser.

  • 書類写真のスキャン風補正

    斜めに撮った書類・領収書の写真の四隅をドラッグして台形補正し、白黒くっきり化。JPEG保存や複数枚のPDF出力にも対応。 / Straighten a photographed document by dragging its corners, then export as JPEG or a multi-page PDF.

  • 交通費精算書メーカー

    日付・区間・手段・金額を行ごとに入力すると自動集計し、A4で印刷できる精算書を作成。よく使う区間はプリセット保存で翌月も入力を省略。 / Build a printable A4 travel expense report with an automatic total — save frequent routes as presets for next month.

CSV・テキスト・データ整形 Data cleanup

  • CSV・テキストの文字化け直し

    Shift_JIS・EUC-JPで文字化けしたファイルをUTF-8に変換。ExcelのBOM追加・削除にも対応。 / Fix mojibake: convert Shift_JIS/EUC-JP files to UTF-8, add or remove a BOM.

  • CSVの列ごと書式統一

    CSVを読み込み、列ごとに全角半角・カナ・郵便番号・ハイフンの書式をそろえてダウンロード。 / Normalize full/half-width characters, katakana, postal codes and hyphen styles column by column in a CSV.

  • 和暦・西暦 混在日付の一括統一

    「令和6年1月2日」「R6.1.2」「2024/1/2」など混在した日付を文章・CSVからまとめて検出し形式を統一。元号の境目を越えた存在しない日付は変換せずに知らせる。 / Find and unify mixed Japanese-era and Western dates across text or a CSV — a date that crosses an era boundary is flagged, never silently guessed.

  • 表記ゆれ・全角半角チェッカー

    「サーバ／サーバー」などの表記ゆれ、全角英数字・半角カタカナ・全角スペースの混在を検出してワンクリックで統一。 / Detect and unify inconsistent Japanese word forms and full/half-width characters.

  • JSON・YAML・TOML 相互変換エディタ

    3つの枠のどれかを編集すると、残り2つの形式にその場で変換。行番号付きのエラー表示、コピー・ダウンロードに対応。 / Edit JSON, YAML or TOML and the other two formats update instantly, with line-numbered error messages.

  • 正規表現テスター（日本語で自動解説）

    正規表現とテスト文字列を入れるとマッチ箇所をハイライトし、パターンの意味を自然な日本語の文章で自動解説。郵便番号・電話番号などのサンプル付き。 / A regex tester that explains what your pattern means in a natural Japanese sentence.

  • 複数CSVの結合ツール

    文字コードがバラバラな複数のCSV（Shift_JIS・EUC-JP・UTF-8混在）をファイルごとに自動判定してから結合。見出し名で列をそろえ、列構成が違っても足りない列は空欄に。 / Merge multiple CSV files that use different character encodings — each file is auto-detected, with columns aligned by header name.

  • CSVを列の値ごとに自動分割

    1つのCSVを、選んだ列（都道府県・店舗・担当者など）の値ごとにグループ分けして複数ファイルに分け、ZIPでまとめてダウンロード。行数での機械的な分割ではなく値によるグループ分割。 / Split one CSV into files grouped by a column's value (e.g. by store or prefecture), downloaded as a single ZIP.

  • CSVのコード→名称 一括変換ツール

    データCSVのコード列を、コード・名称の対応表（マスタ）CSVと突き合わせて店舗名・氏名などの列を一括追加。一致しなかった行は空欄のまま一覧表示。 / Join a data CSV's code column against a lookup-table CSV to add name columns in bulk — unmatched rows are listed, never guessed.

  • 複数Excelファイルの結合ツール

    複数の.xlsxファイルを、1枚ずつCSVに書き出す手間なくそのまま読み込み1つのCSVに結合。日付・時刻のセルはシリアル値ではなく見たままの形式に変換。 / Merge multiple Excel (.xlsx) files directly into one CSV — no need to export each to CSV first, with dates converted from Excel's serial numbers automatically.

暦・時間 Calendar & time

  • 和暦・西暦・年齢 変換と早見表

    令和・平成・昭和と西暦の変換、満年齢・干支、履歴書用の入学・卒業年。 / Japanese era ⇄ Western year, age & school-year chart.

  • 海外との会議 時差計算プランナー

    複数のタイムゾーンを追加して24時間分の現地時間を一覧グリッドで比較。クリックした時間の各拠点の日時をまとめてコピーできる。 / Compare local times across multiple timezones on one grid and copy the result for a meeting invite.

その他 Other

  • 登山装備チェックリスト

    季節と日程（日帰り・山小屋泊・テント泊）を選ぶだけで持ち物リストを自動生成。チェックは端末に保存、印刷にも対応。 / Generate a hiking gear checklist by season and trip type, with checks saved on your device.
