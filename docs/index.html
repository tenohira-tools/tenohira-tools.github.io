経理・事務書類 Paperwork & receipts

  • 証憑ファイル名整理ツール

    領収書・請求書に日付・取引先・金額を入力して一括リネーム。対応ブラウザはフォルダを選んで直接リネーム、それ以外はコピーを一括ダウンロード。 / Rename receipts and invoices in bulk with date/vendor/amount — direct in-folder rename on supported browsers.

  • 領収書まとめ台紙メーカー

    複数のレシート・領収書の写真を並べ方（2×2〜3×4）を選ぶだけでA4のPDFにまとめて整列。経費精算の添付や紙の台紙貼り付けに。 / Arrange multiple receipt photos into a printable A4 PDF sheet, entirely in your browser.

  • 書類写真のスキャン風補正

    斜めに撮った書類・領収書の写真の四隅をドラッグして台形補正し、白黒くっきり化。JPEG保存や複数枚のPDF出力にも対応。 / Straighten a photographed document by dragging its corners, then export as JPEG or a multi-page PDF.

  • 交通費精算書メーカー

    日付・区間・手段・金額を行ごとに入力すると自動集計し、A4で印刷できる精算書を作成。よく使う区間はプリセット保存で翌月も入力を省略。 / Build a printable A4 travel expense report with an automatic total — save frequent routes as presets for next month.

CSV・Excelのファイル処理 CSV & Excel file processing

  • CSV・テキストの文字化け直し

    Excelで開くと文字化けする・□□□になるときに。Shift_JIS・EUC-JPで文字化けしたファイルをUTF-8に変換、ExcelのBOM追加・削除にも対応。 / When a CSV or text file turns into mojibake in Excel: convert Shift_JIS/EUC-JP to UTF-8, add or remove a BOM.

  • CSVの列ごと書式統一

    全角半角・カナ・郵便番号・ハイフンの書き方が列の中でバラバラなときに。列ごとに選んで書式をそろえてダウンロード。 / When a CSV column mixes full/half-width characters, katakana, postal codes or hyphen styles: normalize them column by column.

  • 複数CSVの結合ツール

    文字コードがバラバラな複数のCSV（Shift_JIS・EUC-JP・UTF-8混在）を1つに結合したいときに。ファイルごとに自動判定し、見出し名で列をそろえる（無い列は空欄）。 / Merge multiple CSV files that use different character encodings — each file is auto-detected, with columns aligned by header name.

  • CSVを列の値ごとに自動分割

    1つのCSVを都道府県・店舗・担当者などの値ごとに振り分けて複数ファイルに分けたいときに。行数での機械的な分割ではなく値によるグループ分割、ZIPでまとめてダウンロード。 / Split one CSV into files grouped by a column's value (e.g. by store or prefecture), downloaded as a single ZIP.

  • CSVのコード→名称 一括変換ツール

    データCSVのコード列を、対応表（マスタ）CSVを使って店舗名・氏名などに一括で変換したいときに。一致しない行は空欄のまま一覧表示、推測しない。 / Join a data CSV's code column against a lookup-table CSV to add name columns in bulk — unmatched rows are listed, never guessed.

  • Excelファイルを複数まとめて1つに

    複数のExcelファイルを、1枚ずつCSVに書き出す手間なくそのまま1つに結合したいときに。日付・時刻のセルはシリアル値ではなく見たままの形式に変換。 / Merge multiple Excel (.xlsx) files directly into one CSV — no need to export each to CSV first, with dates converted from Excel's serial numbers automatically.

  • 引き継いだExcelの数式を一覧に

    引き継いだExcelの数式がどこに入っているか分からないときに。ファイルを開かずシート・セルごとに一覧化し、エラー値や他シート参照・外部ファイル参照の可能性も自動検出してCSV出力。 / List every formula cell in an Excel workbook without opening it — flags cached errors, cross-sheet references and possible external-workbook links.

  • 「名前は既に存在します」対策：名前定義の点検・削除ツール

    シートをコピーすると「名前'○○'は既に存在します」と出て困るときに。原因になりやすい非表示・エラー(#REF!)の名前定義を見分けて削除した新しいファイルを作成（元ファイルは変更しない）。 / Find and remove the hidden/broken defined names that cause Excel's "A name already exists" dialog when copying sheets — builds a cleaned copy, original untouched.

  • Excelの「外部ソースへのリンク」発生源を探すツール

    「データ」タブの「リンクの編集」を見ても、外部参照がブック内のどこで使われているか分からないときに。数式・名前定義・データの入力規則・条件付き書式・グラフをシート・セル単位で一覧化。 / Find every external-workbook link in an Excel file and exactly where it's used — formulas, defined names, data validation, conditional formatting and charts.

  • Excelの結合セルを解除して値を埋める→CSV出力

    結合セルを解除すると空欄になり、並び替え・フィルター・ピボットができなくて困るときに。左上の値で自動的に埋めてからCSVに書き出す。縦方向だけ埋める／横方向も埋める（クロス集計見出し向け）を選択可能。 / Unmerge Excel merged cells and fill in the blanks with the top-left value, then export as CSV — for tables you need to sort, filter or pivot.

  • 「エクセルが重い」原因を診断：ファイル内訳チェッカー

    「エクセルが重い」原因が分からないときに。シート・画像・スタイル・共有文字列などパーツ別の内訳と、容量を押し上げている可能性が高い原因を表示。ファイルを開かずブラウザ内だけで診断。 / Diagnose why an Excel file feels heavy — breaks down file size by sheet, images, styles and shared strings, and ranks the likely causes, entirely in your browser.

  • 条件付き書式が増えすぎて重い・消せないときの棚卸し削除ツール

    コピペのたびに条件付き書式が勝手に増え、「ルールの管理」を見ても何が効いているか分からないときに。全シート横断で一覧化し、範囲の重複・行列全体を対象にした重くなりやすいルール・書式参照切れを自動検出して削除。 / For Excel files where conditional formatting rules keep multiplying from copy-paste: list every rule across every sheet, flag overlapping ranges, whole-row/column rules and broken style references, and remove the ones you choose.

テキスト整形 Text formatting

  • 和暦・西暦 混在日付の一括統一

    「令和6年1月2日」「R6.1.2」「2024/1/2」など日付の書き方が混在していて揃えたいときに。文章・CSVからまとめて検出し形式を統一。元号の境目を越えた存在しない日付は変換せずに知らせる。 / Find and unify mixed Japanese-era and Western dates across text or a CSV — a date that crosses an era boundary is flagged, never silently guessed.

  • 表記ゆれ・全角半角チェッカー

    「サーバ／サーバー」のような表記ゆれや、全角英数字・半角カタカナ・全角スペースの混在に気づかず放置しているときに。検出してワンクリックで統一。 / Detect and unify inconsistent Japanese word forms and full/half-width characters.

  • JSON・YAML・TOML 相互変換エディタ

    JSON・YAML・TOMLの間で書き写すのが面倒なときに。どれか1つの枠を編集すると残り2つがその場で変換される。行番号付きのエラー表示、コピー・ダウンロードに対応。 / Edit JSON, YAML or TOML and the other two formats update instantly, with line-numbered error messages.

  • 正規表現テスター（日本語で自動解説）

    正規表現を書いても何にマッチするのか読み返して分からなくなるときに。マッチ箇所をハイライトし、パターンの意味を自然な日本語の文章で自動解説。郵便番号・電話番号などのサンプル付き。 / A regex tester that explains what your pattern means in a natural Japanese sentence.
