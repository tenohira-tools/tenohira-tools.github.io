数字になった日付を一括で直す

    使い方とよくある質問

    1. 上で「変換後の形式」を選びます。
    2. 「CSVファイル」モードでは、CSVをドラッグ＆ドロップすると各列の値から形式（Excelのシリアル値／8桁の数字／米国式表記）を自動判定し、列ごとに選び直せます。プレビューで確認してからダウンロードします。「Excelファイル」モードでは、.xlsxファイルをドラッグ＆ドロップすると全シートのセル文字列を対象に8桁の数字・米国式表記を検出し、変換後のファイルをダウンロードできます。
    3. 対応する形式：Excelのシリアル値（1900年1月1日を1とする日数。例：45123→2023年7月16日）、8桁の数字（20240102のようなyyyymmdd）、米国式のスラッシュ区切り（01/02/2024＝1月2日ではなく2024年1月2日）。
    4. 実在しない日付（13月や、その月に無い日にちなど）は変換せず、その場に残したうえで「検出した日付」に理由つきで表示します。

    Q. 「45123」のような数字が、なぜ日付だと分かるのですか？

    A. Excelは日付を「1900年1月1日を1」とした連番（シリアル値）で内部的に保持しており、セルの表示形式が「日付」でなく「標準（数値）」になっていると、この連番がそのまま数字として見えてしまいます。CSVモードでは列の値のうち何割が実在する日付に変換できるかを見て自動的にこの列を候補にしますが、最終的な判定（本当に日付の列かどうか）は必ず列ごとの選択欄とプレビューで確認してください。偶然似た範囲の数字が並ぶ列（連番の社員番号など）を誤って変換しないための確認です。

    Q. Excelファイル（.xlsx）でもシリアル値を直せますか？

    A. 「Excelファイル」モードでは、セルに文字列として入っている8桁の数字・米国式表記だけを対象にしています。セルの値が実際の数値（シリアル値）として保存されている場合は、Excelで該当の列を選び「ホーム」→「書式」→「セルの書式設定」で一度「文字列」にしてから保存し直すか、Excelで一度CSVとして保存してからこのツールのCSVモードをお使いください。CSVモードであれば、数値としてのシリアル値をそのまま検出・変換できます。

    Q. 米国式の「01/02/2024」は、どうして「1月2日」ではなく「2024年1月2日の1月2日」になるのですか？

    A. 米国式の日付表記は「月/日/年」の順のため、01/02/2024は「1月2日」（2024年）という意味になります。最初の数字が13以上など月として成立しない場合は、米国式として扱えないため変換せず「検出した日付」に理由を添えて表示します。

    Q. 実在しない日付（13月など）はどうなりますか？

    A. カレンダー上に実在しない日付（13月や、その月に存在しない日にち）は変換せず、「検出した日付」に理由を添えて一覧表示します。うるう年の2月29日は、実際にうるう年である年だけ正しく変換されます。

    Q. CSVモードで、見出し行やIDの列まで変換されてしまいませんか？

    A. 見出し（1行目）は「1行目を見出しとして扱う」を付けたままにすると変換対象から外れます。データの列については、列ごとの選択欄を「変換しない」にすれば対象から外せます。自動判定は列全体のうち半分以上の値がその形式の実在する日付に変換できる場合だけ候補にしますが、完全ではないため、ダウンロード前にプレビューで意図しない列が変換されていないか確認してください。

    Q. 文章やファイルはサーバーに送信されますか？

    How to use & FAQ

    1. Choose an output format above.
    2. In "CSV file" mode, drop a CSV and each column's format (Excel serial number / 8-digit yyyymmdd / US-style slash date) is auto-detected from its values, with a dropdown to override per column. Review the preview, then download. In "Excel file" mode, drop an .xlsx file and the same detection runs on every sheet's cell text for 8-digit numbers and US-style dates, with a download of the updated file.
    3. Formats it recognizes: an Excel serial date number (days since 1900-01-01=1; e.g. 45123 → 2023-07-16), an 8-digit number like 20240102 (yyyymmdd), and a US-style slash date like 01/02/2024 (month/day/year, not day/month).
    4. A date that doesn't actually exist (month 13, a day that doesn't exist in that month) is left unchanged and listed, with a reason, under "Dates found".

    Q. How can a number like "45123" be a date?

    A. Excel stores dates internally as a running day count from 1900-01-01 (=1). If a cell's display format is "General" rather than "Date", that raw count is what you see. In CSV mode, a column becomes a candidate when enough of its values convert to a real calendar date, but the final call is yours — always check the per-column dropdown and the preview, so an unrelated column of sequential numbers (like employee IDs) isn't mistakenly converted.

    Q. Does Excel file mode fix serial numbers too?

    A. "Excel file" mode only targets 8-digit numbers and US-style dates stored as text in a cell. If a cell holds an actual numeric value (a serial date with General formatting), either format that column as Text in Excel before re-saving, or save the file as CSV first and use this tool's CSV mode, which can detect and convert a raw serial number directly.

    Q. Why does "01/02/2024" become January 2, not February 1?

    A. US-style dates are written month/day/year, so 01/02/2024 means January 2, 2024. If the first number can't be a month (13 or higher), it's left unchanged and flagged with a reason instead of being guessed.

    Q. What about a date that isn't real, like month 13?

    A. A date that isn't real on the calendar is left unchanged and listed with a reason. February 29 only converts correctly in an actual leap year.

    Q. Could it touch header rows or ID columns in CSV mode by mistake?

    A. Keep "Treat the first row as a header" checked to exclude row 1. For data columns, set the per-column dropdown to "Don't convert" to exclude any column. Auto-detection only proposes a column when at least half its values convert to a real date, but it isn't perfect — always check the preview before downloading.

    Q. Is my file uploaded anywhere?

    A. No. Everything is processed inside your browser on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
