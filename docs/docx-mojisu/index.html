  1. 上の枠にWord（.docx）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. 「数える範囲」で、本文のみ／脚注・文末脚注を含める／ヘッダー・フッターまで含める、のどれかを選びます（ファイルを選び直す必要はありません。切り替えるとその場で再集計します）。

Q. 「文字数（全体）」「空白を除く」「空白・改行を除く」はそれぞれ何を数えていますか？

A. 「全体」は半角・全角スペース、タブ、改行（段落の区切りや強制改行）もすべて1文字として数えた文字数です。「空白を除く」はそこから半角・全角スペースとタブを除いた数、「空白・改行を除く」はさらに改行（段落の区切り・強制改行）も除いた数です。見積もりの文字単価は「空白・改行を除く」文字数で計算することが多いため、この列を基準にしてください。絵文字など2文字分のコード単位を使う文字も、見た目どおり1文字として数えます。

Q. 「400字詰め原稿用紙換算」はどう計算していますか？

A. 「空白・改行を除く」文字数を400で割った枚数です（1行20字×20行の原稿用紙が基準）。小数点以下1桁で表示し、端数の扱いはファイルによって運用が異なるため四捨五入・切り上げは行わず、割った値そのものを表示します。

Q. 「数える範囲」で結果が変わるのはなぜですか？どれを選べばいいですか？

A. ヘッダー・フッターはページごとに同じ内容が繰り返されますが、ファイル内にはその内容が1回だけ保存されています。脚注・文末脚注は、本文に含めるかどうかで見積もりの考え方が分かれる部分です。原稿・翻訳の対象が本文だけなら「本文のみ」、脚注も翻訳対象なら「本文＋脚注・文末脚注」（既定）、ヘッダー・フッターの文言も対象にする場合だけ「全て」を選んでください。セクションごとに違うヘッダー・フッターが設定されているファイルでは、実際に使われているページ数ぶん重複して数えているわけではない点にご注意ください（ファイル内に保存されている内容を1回ずつ数えます）。

Q. Wordの「文字カウント」ダイアログの数字と違うのはなぜですか？

A. Wordは内部の計算方法を公開していないため、改行や特殊な要素の扱いが完全には一致しないことがあります。このツールは本ページに書いた数え方（スペース・タブ・改行の扱い）をそのまま適用するため、表示される数字の意味を確認できます。コメントの本文、変更履歴で「削除」として記録され未確定の文字は対象外です（確定済みとして表示される文字のみ数えます）。

Q. 複数ファイルの合計はどこで見られますか？

A. 「合計（選んだ全ファイル）」に、追加した全ファイルを合算した数字を表示します。ファイルごとの数字は下の一覧とCSVに含まれます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Word 2007以降の.docx形式に対応しています。古い.doc形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Word (.docx) file(s) into the box above, or click it to choose one or more at once.
  2. Pick a scope: body only, body + footnotes/endnotes, or also headers/footers. Switching re-counts instantly — no need to re-add files.
  3. Check the combined total and the per-file list.
  4. Click "Download as CSV" to save, or "Print this list" to print it directly. The CSV opens directly in Excel.

Q. What exactly do "all characters", "excl. spaces" and "excl. spaces/breaks" count?

A. "All characters" counts every half/full-width space, tab and line break (paragraph boundary or a manual line break) as one character each. "Excl. spaces" removes half/full-width spaces and tabs. "Excl. spaces/breaks" also removes line breaks. Quote rates are usually based on the "excl. spaces/breaks" figure, so use that column as your baseline. Characters using surrogate pairs (like many emoji) are still counted as one character each, matching how they look.

Q. How is the "400-char manuscript page" estimate calculated?

A. The "excl. spaces/breaks" count divided by 400 (a standard Japanese manuscript page: 20 characters × 20 lines). Shown to one decimal place with no rounding, since conventions for rounding up vary.

Q. Why does the result change with the scope setting — which should I pick?

A. Headers and footers repeat on every page visually, but the file stores that content only once. Footnotes/endnotes are the part where translation-quote practice tends to differ. Use "body only" if only the running text matters, "body + footnotes/endnotes" (the default) if footnotes are also being translated, and "all" only if header/footer text should count too. For files with different headers/footers per section, this counts each stored header/footer once — not once per page it's displayed on.

Q. Why doesn't this match Word's own Word Count dialog?

A. Word doesn't publish exactly how it counts, so edge cases around line breaks can differ slightly. This tool applies the rule described on this page consistently, so you know exactly what's being measured. Comment text, and text recorded as a tracked "deletion" that hasn't been accepted, is excluded (only the text that would currently display is counted).

Q. Where do I see the combined total across files?

A. The "Combined total" panel shows the sum across every added file. Per-file numbers are in the list below and in the CSV.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Word 2007+ .docx files. The older .doc format and password-protected files are not supported; a failed file shows an error next to it.
