図形が知らないうちに増えている・見えない図形が残っていないか：全シート一覧チェック

Excelでシェイプや画像を繰り返しコピーしているうちに、画面には映らない非表示・サイズ実質ゼロの図形や、同じ名前が何十個も付いた図形が残っていることがあります。「ホーム」→「検索と選択」→「オブジェクトの選択と表示」を開いても、名前が並ぶだけで、どれが非表示か、どれがコピーで増えたのかは分かりません。このツールはExcel(.xlsx/.xlsm)の全シートにある図形・画像・グラフ枠・グループを解析し、シートごとに一覧表示したうえで、非表示設定の図形、サイズが実質ゼロの図形、同じ名前が繰り返し付いた図形（コピーで増えた可能性）に印を付けます。読み取り専用で、ファイルは書き換えません。サーバーには送信されません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

複数ファイルを一度に追加できます。全シートの図形・画像・グラフ枠・グループを解析します。ファイルは選択した端末の中だけで処理され、どこにも送信されません。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. シートごとに図形・画像・グラフ枠・グループの件数が表示され、非表示設定・サイズ実質ゼロ・同じ名前の繰り返し（コピーの疑い）のいずれかに当てはまるものには印が付きます。
  3. 既定では「疑わしい図形だけ表示」にチェックが入った状態で一覧が出ます。チェックを外すと全ての図形が見られます。
  4. 一覧はCSVとしてダウンロードできます。

Q. 「非表示」「サイズ実質ゼロ」はどうやって判定していますか？

A. 「非表示」は図形のプロパティ（xdr:cNvPrのhidden属性）が明示的にオンになっている場合です。「サイズ実質ゼロ」は、図形自体の大きさ（a:ext要素のcx・cyのいずれか）が0に設定されている場合です。どちらも断定的な「不要」の判定ではなく、見落としやすい候補として示しています。大きさの情報自体が読み取れない図形は「不明」として扱い、誤って疑わしいと表示しないようにしています。

Q. 「同じ名前が繰り返されている」図形はなぜ疑わしいのですか？

A. Excelは図形をコピーすると「四角形 12」のように元の名前に連番を振って増やしていきます。同じシート内で同じ基本名（末尾の連番を除いた部分）の図形が4個以上あると、コピー＆ペーストを繰り返すうちに増えた図形である可能性が高いと判断し、印を付けています。意図して複数作った図形（凡例や装飾など）にも印が付くことがあるため、内容を確認してから判断してください。

Q. 見つけた図形を実際に削除するにはどうすればいいですか？

A. このツールは一覧表示のみで、ファイルの書き換えは行いません。該当シートを開き、「ホーム」タブ→「検索と選択」→「オブジェクトの選択と表示」を開くと、図形が名前の一覧で表示されます。一覧に出てきた名前をクリックすれば（Ctrlキーで複数選択も可能）、該当の図形だけを選択してDeleteキーで削除できます。どの名前が怪しいか分かっていれば、この操作がずっと速くなります。

Q. グラフやSmartArt、埋め込みのOLEオブジェクトも対象ですか？

A. シート上に描画オブジェクト（DrawingML、xl/drawings以下）として配置された図形・画像・グラフの枠・グループ・コネクタを対象にしています。グラフ自体はグラフ枠（graphicFrame）として検出されますが、グラフ内部の要素までは解析しません。また、フォームコントロール（チェックボックスやボタンなど）や、古い形式のコメント用VML図形など、別の仕組み（legacy VML drawing）で保存されているオブジェクトは対象外です。

Q. 透明な図形（塗りつぶしなし）も検出できますか？

A. いいえ。塗りつぶしの色や透明度まではファイルの構造だけでは安全に判定できないため、対象外としています（誤って普通の図形を「透明」と表示してしまうリスクを避けるためです）。検出できるのは、図形のプロパティで明示的に「非表示」と設定されている場合と、大きさが実質ゼロに設定されている場合の2つです。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。このツールは読み取り専用で、ファイルの内容を変更したり書き出したりする機能はありません。一覧をCSVとして保存できるだけです。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析が行われます（サイト全体の閲覧数をCookieなし・個人を特定しない方法で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop one or more Excel (.xlsx/.xlsm) files into the box above, or click it to choose them.
  2. For every sheet, the number of shapes, pictures, chart frames and groups is listed, and anything hidden, effectively zero-size, or sharing a repeated base name (suggesting copy-paste growth) is flagged.
  3. By default, "Show flagged shapes only" is checked. Uncheck it to see every shape.
  4. The list can be downloaded as CSV.

Q. How are "hidden" and "effectively zero-size" determined?

A. "Hidden" means the shape's own property (the hidden attribute on xdr:cNvPr) is explicitly turned on. "Effectively zero-size" means the shape's own extent (the cx or cy of its a:ext element) is set to 0. Neither is a definitive "this is junk" verdict — they're flagged as easy-to-miss candidates. Shapes whose size information can't be read are treated as "unknown" rather than being flagged.

Q. Why is a repeated shape name treated as suspicious?

A. When you copy a shape in Excel, it numbers the copy from the original name, e.g. "Rectangle 12". If four or more shapes on the same sheet share the same base name (with the trailing number stripped), it's flagged as likely having grown from repeated copy-paste. Shapes you deliberately created in a set (a legend, decorations) can also get flagged, so check the content before deciding.

Q. How do I actually delete the shapes this finds?

A. This tool only lists shapes — it never modifies or rewrites your file. Open the sheet, then Home → Find & Select → Selection Pane, which lists every shape by name. Click a name there (Ctrl-click for several) to select just that shape and press Delete. Knowing which names to look for in advance makes this much faster.

Q. Does this cover charts, SmartArt, or embedded OLE objects?

A. It covers drawing objects placed on a sheet as DrawingML (under xl/drawings): shapes, pictures, chart frames, groups and connectors. A chart itself is detected as a chart frame, but its internal elements aren't analyzed. Form controls (checkboxes, buttons) and legacy VML-based comment shapes, which use a different storage mechanism, are out of scope.

Q. Can this detect transparent (no-fill) shapes?

A. No. Fill color and opacity can't be resolved safely from the file structure alone (doing so risks misflagging an ordinary shape as "transparent"), so it's out of scope. Only two conditions are detected: a shape explicitly marked hidden, and a shape whose size is set to effectively zero.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. Is my original file modified?

A. No. This tool is read-only — it has no feature to change or rewrite your file's contents. You can only save the list itself as CSV.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
