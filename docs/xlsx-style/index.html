Q. 「異なるセルの書式の数が多すぎます」とは何ですか？

A. Excelのブックは、フォント・塗りつぶし・罫線・表示形式・配置・保護設定などの組み合わせ（セル書式）を内部に1つずつ記録しており、この組み合わせの総数には上限があります（Excel 2007以降は約64,000通り）。別のブックからのコピーや、書式のコピー＆貼り付けを繰り返すと、見た目が同じ、あるいはもう使われていない書式が気づかないうちに積み重なり、上限に達すると保存時にこのエラーが出て保存できなくなります。見た目を変えずに済むのは、重複している書式を1つにまとめ、使われていない書式を削除することです。このツールはその2つの処理だけを自動で行います。

Q. 本当に見た目は変わりませんか？

A. はい。まとめる対象は、フォント・塗りつぶし・罫線・表示形式・配置・保護設定などがすべて完全に一致する書式だけです。1文字でも設定が違う書式は別物として残すため、統合によって見た目が変わることはありません。削除する「未使用」の書式も、どのセル・行・列からも参照されていないものだけなので、削除してもどのセルの見た目にも影響しません。似ているけれど完全に同一ではない書式（例：色が1段階だけ違う）は、安全のためまとめません。

Q. 対象は「セルの書式」のどこまでですか？

A. セルに直接適用される書式の組み合わせ（ファイル内部ではcellXfsと呼ばれる部分）だけが対象です。「ホーム」タブの「セルのスタイル」ギャラリーに登録された名前付きスタイル（Normal・Percentなど）、テーブルのデザイン、条件付き書式用の書式（差分書式）は対象外で、変更しません。カスタムの表示形式（例："yyyy年m月d日"のような独自の書式コード）の定義自体も削除せず、セル側がその定義をもう使っていない場合だけ、セル書式の組み合わせの方を整理します。

Q. どんなファイルで効果がありますか？

A. 他のブックから何度もシートやセルをコピーした履歴があるファイル、条件付き書式や結合セルを使い回しながら作り込んだ長年運用中のファイル、「異なるセルの書式の数が多すぎます」のエラーが出て保存できないファイルなどで、重複・未使用の書式が多く見つかりやすい傾向があります。すでに整理されたシンプルなファイルでは「見つかりませんでした」と表示されることもあります。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、変更後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_書式整理済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. It's analyzed automatically: the original format count, how many are duplicates to merge, how many are unused and droppable, the resulting count, and the actual file-size change are shown.
  3. Review the breakdown of exactly which formats will be merged or dropped, then click "Build a cleaned file" to download it. Your original file is untouched.

Q. What does Excel's "too many different cell formats" error mean?

A. Every Excel workbook stores each unique combination of font, fill, border, number format, alignment and protection settings as one internal "cell format" record, and there's a cap on how many such combinations a workbook can hold (roughly 64,000 in Excel 2007 and later). Copying between workbooks, or copying and pasting formatting repeatedly, quietly piles up formats that look identical or are no longer used by any cell. Once the cap is hit, Excel refuses to save with this error. The safe fix, without changing how anything looks, is to merge the duplicate formats into one and drop the ones nothing uses — which is exactly what this tool does, automatically.

Q. Will this really leave the look of my file unchanged?

A. Yes. Formats are only merged when every setting — font, fill, border, number format, alignment, protection — matches exactly; a format that differs in even one setting is kept as its own entry, so merging never changes how anything looks. The "unused" formats it removes are, by definition, not referenced by any cell, row or column, so dropping them can't affect any cell's appearance either. Formats that are merely similar but not byte-identical (say, one shade of color apart) are deliberately left alone for safety.

Q. What part of "cell formatting" does this cover?

A. Only the pool of format combinations applied directly to cells (internally called cellXfs). Named cell styles from the "Cell Styles" gallery (Normal, Percent, etc.), table styles, and the differential formats used by conditional formatting are untouched. Custom number-format codes themselves (e.g. a custom date pattern) are not deleted either — only the cell-format combinations that no longer reference them are cleaned up.

Q. Which files benefit most?

A. Files with a long history of copying sheets or cells from other workbooks, long-lived files built up with repeated conditional formatting or merged cells, and files that already throw the "too many different cell formats" error tend to have the most duplicate or unused formats. A simple, already-tidy file may show nothing to clean up.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported.

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_cleaned" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
