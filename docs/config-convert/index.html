JSON・YAML・TOML 相互変換エディタ

3つの枠のどれかを編集すると、正しく書けた時点で残り2つの形式にその場で変換されます。設定ファイルの見比べや形式変換に。ブラウザ内だけで処理し、どこにも送信されません。

JSON

JavaScriptやAPIで一般的なデータ形式。

YAML

GitHub Actions・docker-compose・Kubernetesなどでよく使う形式。

TOML

Cargo.toml・pyproject.tomlなどでよく使う形式。

使い方とよくある質問

  1. JSON・YAML・TOMLのどれか1つの枠に、既存の設定ファイルの内容を貼り付ける（または直接書く）。
  2. 正しく書けている間は、残り2つの枠が自動的にその内容に変換されます。
  3. 構文にエラーがある間は、そのエラーが出た枠の下に行番号付きでエラーを表示します（他の2つの枠の内容はそのまま残ります）。
  4. できあがった内容は「コピー」または「ダウンロード」で取り出せます。

Q. 変換に失敗するときは？

A. エラーが出た枠の下に、原因と行番号が表示されます。その行を直すと、正しく書けた時点で自動的に変換が再開されます。

Q. コメント（#で始まる行など）は変換後も残りますか？

A. 残りません。YAMLやTOMLのコメントは、変換の際に失われます（JSONにはコメントを書く仕組みがないため）。コメントを残したい場合は、変換前のファイルを別途保管してください。

Q. 対応していない書き方はありますか？

A. あります。YAMLはアンカー・エイリアス（&・*）、タグ（!）、ブロックスカラー（|・>）、複数ドキュメント（---区切り）に対応していません。TOMLは配列テーブル（[[ ]]）、複数行・triple-quote文字列、日付型（貼り付けると文字列として扱われます）に対応していません。また、TOMLには「値なし（null）」という概念が無いため、null を含むデータはTOMLに変換できません（エラーで知らせます）。これらに該当する行は、エラーメッセージで具体的に指摘されます。

Q. 大きな設定ファイルでも使えますか？

A. ブラウザのメモリ上で処理するため、数千行程度までを想定しています。非常に大きなファイルでは表示や変換が遅くなる場合があります。

Q. 入力した内容はどこかに送信されますか？

A. いいえ。入力・変換はすべてこのブラウザの中だけで行われ、どこにも送信されません（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。設定ファイルにパスワードやAPIキーなどの秘密情報が含まれる場合でも、このページの外に出ることはありません。

How to use & FAQ

  1. Paste (or type) an existing config file into any one of the JSON, YAML or TOML boxes.
  2. While it parses successfully, the other two boxes are automatically regenerated from it.
  3. While there's a syntax error, that box shows the error with a line number, and the other two boxes are left untouched.
  4. Use "Copy" or "Download" to grab the result.

Q. Why did conversion stop working?

A. The box with the problem shows what's wrong and which line. Fix that line and conversion resumes automatically once it parses again.

Q. Are comments preserved?

A. No. Comments in YAML or TOML are dropped during conversion, since JSON has no way to represent them. Keep a copy of the original file if you need to preserve comments.

Q. What syntax isn't supported?

A. YAML: anchors/aliases (&, *), tags (!), block scalars (|, >), and multi-document streams (--- separators) are not supported. TOML: array-of-tables ([[ ]]), multi-line/triple-quoted strings, and date/time types (kept as plain strings if pasted) are not supported. Also, TOML has no concept of null, so data containing null cannot be converted to TOML (you'll get a clear error instead of silent data loss). Any of these will be pointed out in the error message.

Q. Can it handle large config files?

A. Everything runs in browser memory, so it's built for files up to a few thousand lines. Very large files may make the page slower.

Q. Is anything I type sent anywhere?

A. No. Everything happens inside this browser — nothing is uploaded (only an anonymous, cookie-free page-view count via GoatCounter for the site as a whole). Even config files containing secrets or API keys never leave this page.
