Excelの結合セルを解除して値を埋める

結合セルを解除するとできる空欄を、左上の値で自動的に埋めてからCSVに書き出します。並び替え・フィルター・ピボットができる表に整えたいときに。ファイルはどこにも送信されません。

ここにExcel(.xlsx)ファイルをドラッグ＆ドロップ、またはクリックして選択

複数ファイルを一度に追加できます。結合セルが無いファイルも、そのままCSV化だけ行えます。

埋め方の設定

オフ（既定）では、結合セルの一番左の列だけを下方向に埋めます（「部署名」を複数行にまたがって結合している、などのよくある使い方）。オンにすると、見出しが行と列の両方にまたがって結合されている表（クロス集計の見出し等）でも全マスを埋めます。

追加したファイル

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. 結合セルが見つかると「結合セルN個を検出」と表示され、左上の値で他のセルが自動的に埋まったプレビューが出ます（埋めたセルは色付きで表示）。
  3. 結合が行と列の両方にまたがっている表なら「横方向も埋める」をオンにします（通常の「1列を複数行にまたがる結合」だけならオフのままで大丈夫です）。
  4. ファイルごとに「CSVダウンロード」ボタンを押すと、そのファイル（選んだシート）を埋めた結果がCSVとして保存されます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・変換されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. なぜ結合セルを解除すると困るのですか？

A. Excelで「セルを結合して中央に配置」した見出し（部署名・担当者名など）は、ジャンプ機能や「セルの結合」解除ボタンで解除すると、元の見た目で1つだけ値が入っていたセルが、見た目通りの位置1か所にしか値を残さず、残りは空欄になります。並び替え・フィルター・ピボットテーブルでは各行に値が必要なため、空欄のままでは思った通りに動きません。

Q. 「縦方向だけ埋める」と「横方向も埋める」はどう違いますか？

A. 「部署名」のような1つの列が複数行にまたがって結合されている、最もよくあるケースは「縦方向だけ」（既定）で十分です。見出しが行・列の両方にまたがって結合されている表（例：2段のクロス集計見出し）では「横方向も埋める」をオンにすると、結合範囲の全マスが左上の値で埋まります。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

Q. 1つのファイルに複数のシートがある場合は？

A. ファイルの一覧に「シート」の選択欄が出るので、使いたいシートを1つ選べます（既定は先頭のシート）。

Q. 結合セル自体が入ったxlsxファイルとして保存し直すことはできますか？

A. このツールはCSV出力専用です。結合を解除した新しいxlsxファイルが必要な場合は、Excelの「セルの結合」解除後に手作業で値をコピーするか、別の方法をご検討ください。

Q. 日付や時刻、数式が入ったセルはどうなりますか？

A. セルの表示形式を見て、シリアル値ではなく「2026/04/01」のような見たままに近い文字列に変換します。数式セルは直近に保存されたときの計算結果をそのまま使い、再計算はしません。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one (several files at once are fine too).
  2. If merged cells are found, it shows "N merged cells detected" and a preview where the blanks have been filled with the top-left value (filled cells are highlighted).
  3. If a table's merges span both rows and columns, turn on "Also fill horizontally" (leave it off for the common case of one column merged down several rows).
  4. Click "Download CSV" on each file's card to save that file's (chosen sheet's) filled-in result as a CSV.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and converted inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Why is unmerging cells a problem in the first place?

A. A merged-and-centered heading in Excel (a department name, a person's name, etc.) only visually spans several cells — the value is really stored in just one of them. Unmerging with Excel's own "Unmerge Cells" button leaves every cell except that one blank, which breaks sorting, filtering and pivot tables that expect a value on every row.

Q. What's the difference between "vertical only" and "also horizontal"?

A. The common case — one column merged down several rows (like a department name) — only needs the default, vertical-only fill. Turn on "also fill horizontally" for tables whose merges span both rows and columns (e.g. a two-level cross-tab header), so every cell in the merged rectangle gets the top-left value.

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported — if a file fails to load, an error is shown next to it.

Q. What if a file has multiple sheets?

A. Each file's row in the list gets a sheet picker (defaulting to the first sheet).

Q. Can I save the result back as an .xlsx file with the merges actually removed?

A. This tool only exports CSV. If you need a new .xlsx file with the merges removed, use Excel's own "Unmerge Cells" and copy the values down by hand, or look for another tool for that specific need.

Q. What about date, time and formula cells?

A. Dates/times are converted from Excel's internal serial numbers to readable text like "2026/04/01" based on the cell's display format. Formula cells use the last calculated value saved in the file; nothing is recalculated.
