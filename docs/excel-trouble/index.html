動作が重い・保存に時間がかかる

It's heavy / slow to save

「エクセルが重い」「ファイルサイズが大きい」「保存が遅い」と感じたら、まず原因を診断してから対処するツールを選ぶのがおすすめです。

If a workbook feels heavy or takes a long time to save, start by diagnosing the cause, then pick the matching fix.

  • 「エクセルが重い」原因を診断：ファイル内訳チェッカー

    シート・画像・スタイル・共有文字列などパーツ別の内訳と、可能性が高い原因を表示。まずはここから。

    Breaks down file size by part (sheets, images, styles, shared strings) and ranks the likely causes. Start here.

  • 「異なるセルの書式の数が多すぎます」エラー対策

    重複・未使用のセル書式をまとめて削除。見た目は変わらない。

    Merge duplicate cell formats and drop unused ones, without changing how anything looks.

  • 条件付き書式が増えすぎて重い・消せないときの棚卸し削除

    コピペで増殖したルールを全シート横断で一覧化し、選んで削除。

    List every conditional-formatting rule across every sheet and remove the ones that multiplied from copy-paste.

  • Ctrl+Endで遠くへ飛ぶ・保存が遅いときの「使用範囲」リセット

    データの先に書式だけ残って広がった使用範囲を、実データの大きさに縮小。

    Shrink Excel's bloated "used range" back down to your actual data footprint.

保存しようとするとエラーが出る

An error appears when saving

  • 「異なるセルの書式の数が多すぎます」エラー対策

    保存時に出るこのエラーの直接対策。重複・未使用書式を削除。

    The direct fix for Excel's "too many different cell formats" save error.

  • 「名前は既に存在します」対策：名前定義の点検・削除

    シートをコピーすると出る「名前'○○'は既に存在します」の原因になりやすい、非表示・エラーの名前定義を削除。

    Removes the hidden/broken defined names that cause Excel's "A name already exists" dialog when copying sheets.

セルにエラー値や循環参照の警告が残っている

Error values or circular-reference warnings in cells

  • #REF!・#N/A・#DIV/0!が残っているセルを全部一覧に

    全シート・複数ファイルを横断してエラー値セルだけを一覧化。

    Find every cell with a cached error value across every sheet and file.

  • 循環参照の警告が消えない・どこにあるか分からないときの一覧化

    反復計算がONで警告が出ないときも、全シートを解析して循環参照グループを一覧化。

    Scan every sheet's formulas and list every circular-reference group at once — even when iterative calculation hides Excel's own warning.

セルの左上に緑の三角マークが出る・SUMで合計されない

Green triangle warning, or SUM doesn't add a cell up

  • 「数値が文字列として保存されています」(緑の三角)を列ごと一括で数値に変換

    テキストとして保存された数値らしいセルを全シート横断で列ごとに一覧化し、選んだ列だけ数値に変換。郵便番号など0始まりのコード列は既定で対象外。

    List cells whose text looks like a plain number by column across every sheet, and convert only the columns you choose — zero-padded code columns are excluded by default.

外部リンク・ハイパーリンクが消えない

External links or hyperlinks won't clear

  • Excelの「外部ソースへのリンク」発生源を探す

    「リンクの編集」では分からない、ブック内のどこで外部参照が使われているかを数式・名前定義・グラフ等で一覧化。

    Find every external-workbook link and exactly where it's used — formulas, defined names, validation, conditional formatting, charts.

  • 数式を値に変換：「リンクの解除」が失敗するときに

    外部ファイルを参照している数式だけを選んで値に変換し、条件を満たせば外部リンクの記録も削除。

    Convert formulas to their cached values, scoped to formulas referencing an external workbook, for when Excel's own Break Links fails.

  • ハイパーリンクが開けない・大量にあって消せないときの一覧・削除

    ローカルファイルへのリンクや存在しないシートを指す社内リンクを自動検出して解除。

    List every hyperlink across every sheet, flag broken ones, and remove the ones you choose.

印刷すると白紙ページが大量に出る

Printing produces dozens of blank pages

  • Ctrl+Endで遠くへ飛ぶ・印刷で白紙ページが大量に出るときの「使用範囲」リセット

    データの先に書式だけ残って広がった使用範囲が、この症状の典型的な原因です。

    A bloated "used range" from leftover formatting is the usual cause of this exact symptom.

更新前と更新後で何が変わったか分からない

Can't tell what changed between two versions

  • 2つのExcelファイルを比較：変更されたセルだけを全シート一括で色付け表示

    「変更前」「変更後」の2つのファイルを全シート一括で比較し、追加・削除・変更されたセルだけをシート形式の色付き表示と一覧で確認。

    Compare a before/after pair of files across every sheet at once, with added/removed/changed cells highlighted in a sheet grid or a list.

シート・セルの状態がおかしい／社外にファイルを渡す前に

Odd sheet/cell state, or before sending a file outside your company

  • 結合セルを解除して値を埋める→CSV出力

    結合セルを解除すると空欄になり並び替え・フィルター・ピボットができないときに。

    Unmerge cells and fill in the blanks with the top-left value, for tables you need to sort, filter or pivot.

  • シートの「再表示」に出てこないときの対策

    VBAでしか戻せない「完全非表示（veryHidden）」シートの一覧・一括変更。

    List and bulk-change every sheet's visibility, including "very hidden" sheets that only VBA can normally clear.

  • 複数のExcelファイルを1つに結合

    1枚ずつCSVに書き出す手間なく、そのまま結合。

    Merge multiple Excel files directly into one CSV, no manual export step.

  • 引き継いだExcelの数式を一覧に

    数式がどこに入っているか分からないときに、ファイルを開かず一覧化。

    List every formula cell in a workbook without opening it.

  • 社外に渡す前に、作成者・最終更新者・コメントの投稿者名を消す

    Excel・Word・PowerPointに残る作成者情報を複数ファイル一括で消去。

    Strip creator, last-modified-by and comment-author names from multiple Excel/Word/PowerPoint files at once.

  • シートのあちこちに散らばったコメント・メモを全部一覧に

    どのシート・セルにコメント・メモが付いているか分からないときに。返信・解決済みの状態も含めて一覧化しCSV出力・印刷。

    List every cell comment and note across every sheet, including thread replies and resolved status — exportable as CSV or printed directly.

  • 社外に送る前に確認：Excelの「隠れた情報」一括チェック

    非表示シート・非表示行列の値・コメント・作成者名・外部リンク・名前定義・白文字セルを1画面で診断し、該当する専用ツールへ案内（読み取り専用）。

    Check for hidden sheets, hidden-row/column values, comments, author metadata, external links, defined names and invisible text, all on one screen (read-only).

このページについて

Q. このページは何をするところですか？

A. Excelファイルのよくあるトラブルを症状別に分類し、このサイトで公開している19個の無料ツールへの案内をまとめたページです。このページ自体はファイルを処理しません。

Q. 複数の症状に当てはまる場合はどうすればいいですか？

A. まず「動作が重い・保存に時間がかかる」のxlsx-omoi（原因診断）から試すと、どのツールが合っているか絞り込みやすくなります。

Q. 料金や登録は必要ですか？

A. すべて無料・登録不要です。ファイルはアップロードされず、お使いのブラウザの中だけで処理されます（このページ・各ツールページの閲覧数だけ、Cookieなし・個人を特定しない方法で計測しています）。

About this page

Q. What does this page do?

A. It's a directory that sorts common Excel problems by symptom and points you to the matching free tool among the 19 listed above. This page itself does not process files.

Q. What if more than one symptom applies?

A. Start with xlsx-omoi (the heaviness diagnostic) under "It's heavy / slow to save" — it often narrows down which other tool you actually need.

Q. Is this free, and do I need to sign up?

A. Yes, free and no sign-up. Files are never uploaded — everything runs in your browser (only an anonymous, cookie-free page-view count is collected for this page and each tool page).
