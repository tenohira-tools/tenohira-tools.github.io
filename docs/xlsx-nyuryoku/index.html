入力規則（プルダウン）がどこにあるか分からない：全シート一覧化

Excel（.xlsx/.xlsm）のプルダウン（入力規則）がどのシート・どのセルに設定されているか、1枚ずつ開いて確認するのは大変です。全シート・複数ファイルを横断して、セル範囲・種類・リスト元（直接入力／セル参照／他シート参照／名前定義）を一覧表示し、参照先のシートや名前定義が見つからない「壊れた」リストも検出します。読み取り専用で、ファイルはサーバーに送信されません。

すべてのシートの入力規則（データの入力規則）だけをまとめて抜き出します。ファイルは選択した端末の中だけで処理されます。

Q. Excel自体の「データの入力規則」ダイアログと何が違いますか？

A. Excelは1つのセルを選んで「データ」タブから入力規則を確認する機能しかなく、シートをまたいで全部を一度に一覧化することはできません（標準機能だけでは1件ずつセルを選んで確認するしかありません）。このツールは複数ファイル・複数シートを横断して一度に全件を一覧化し、CSVに保存できます。

Q. 「リスト元」はどうやって判定していますか？

A. リスト（プルダウン）型の入力規則について、設定されている参照の書き方から判定して表示します。ダブルクォートで囲まれた直接入力のリスト（例：「はい,いいえ」）はそのまま項目を表示、同じシートまたは他シートのセル範囲への参照はその範囲を表示、名前定義（defined name）への参照はその名前を表示します。OFFSET関数やINDIRECT関数を使った動的なリスト、複数範囲を組み合わせたリストなどは元の文字列をそのまま「数式・複合参照」として表示するだけにしています。

Q. 「壊れている」とはどのような場合ですか？

A. 次の2つの場合だけを壊れていると判定します。①参照しているシートが見つからない場合（シートの削除・名前変更の後によく起きます）。②参照している名前定義（defined name）自体が存在しない、またはその名前定義の内容が#REF!エラーになっている場合です。セル範囲自体に実際にデータが入っているかどうかまでは確認していません。また、テーブルの構造化参照や255文字を超える数式など、Excelの拡張形式（x14）で保存されたリストはこのツールの検出対象外です（件数に含まれません）。

Q. 「矢印非表示」というバッジは何ですか？

A. 入力規則のファイル内部には「showDropDown」という設定項目がありますが、紛らわしいことに、これがオンになっているセルは実際にはプルダウンの矢印が表示されなくなります（名前とは逆の動作をする、Excelの昔からの仕様です）。このバッジが付いているセルは、リストとして値を選べる設定になっているのに矢印が出ないため、使う人がプルダウンの存在に気づきにくくなっている可能性があります。

Q. このツールはファイルを書き換えたり、削除したりできますか？

A. いいえ。読み取り専用の一覧化・CSV出力だけを行い、ファイルは一切書き換えません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more.
  2. Check the summary panel for the total number of validation rules, how many are list (dropdown) type, and how many have a broken reference.
  3. Use the filters to narrow the list down to one file, sheet, type, or status (e.g. broken only).
  4. Click "Download as CSV" to save the list — exactly what the filters currently show.

Q. How is this different from Excel's own Data Validation dialog?

A. Excel only lets you check one selected cell at a time from the Data tab, with no way to list every rule across every sheet at once. This tool scans multiple files and sheets in one pass and exports the full list as CSV.

Q. How is the "list source" determined?

A. For list (dropdown) type rules, the source formula's shape is used to classify it: a quoted literal list (e.g. "Yes,No") is shown as its items; a reference to a cell range (on the same sheet or another sheet) is shown as that range; a reference to a defined name is shown as that name. Dynamic sources built with OFFSET/INDIRECT, or multi-area ranges, are shown as-is under "formula / complex reference" without further analysis.

Q. What counts as "broken"?

A. Only two cases: (1) the referenced sheet can't be found (common after a sheet is deleted or renamed), or (2) the referenced defined name either doesn't exist or itself resolves to a #REF! error. Whether the range actually contains data isn't checked. Validation rules saved in Excel's newer extended format (x14 — used for table structured references or formulas over 255 characters) aren't detected and are not counted.

Q. What does the "arrow hidden" badge mean?

A. Data validation stores a confusingly-named "showDropDown" setting — when it's turned on, the in-cell dropdown arrow is actually hidden (the opposite of what the name suggests; this is long-standing Excel behavior). Cells with this badge can still be filled from the list, but the person using the file may never notice the dropdown is there.

Q. Can this tool rewrite or remove anything?

A. No. This is a read-only listing/CSV-export tool — it never rewrites your file.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and analyzed inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.
