使い方とよくある質問

  1. 上の枠にWord（.docx）ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイルも一度に追加できます）。
  2. 5つの項目（変更履歴の編集者名／コメントの投稿者／隠し文字／作成者・最終更新者・会社名・所属部門／ヘッダー・フッターの文字）ごとに、見つかった件数と内訳が表示されます。
  3. 該当がある項目には、実際に消去できる専用ツールへのリンクが付きます（専用ツールが無い項目はWord本体での確認方法を表示します）。

Q. このツールはファイルを書き換えたり、削除したりできますか？

A. いいえ。このツールは読み取り専用の一覧化・診断だけを行い、ファイルは一切書き換えません。変更履歴の編集者名・コメントの投稿者名・作成者などのプロパティを実際に消したい場合は、作成者・コメント投稿者名などを消すツールをご利用ください。

Q. 「隠し文字」とは何ですか？

A. Wordのフォント設定にある「隠し文字」チェックボックスを付けた文字のことです。通常の画面表示や印刷・PDF変換では見えませんが、ファイルの中にはそのまま文字が残っています。送った相手が「ホーム」タブの編集記号の表示（Ctrl+Shift+8）をONにすると見えてしまいます。このツールは本文・ヘッダー・フッター・脚注・文末脚注を対象に、隠し文字に設定された文字数をパーツごとに数えます（内容そのものは一覧に表示しません）。

Q. 「ヘッダー・フッターの文字」はなぜチェックしますか？

A. Wordの画面は本文の編集が中心で、ヘッダー・フッターは上下の余白部分をダブルクリックしないと編集モードに入らないため、古いテンプレートからコピーした社名や「社外秘」「ドラフト」といった文字が残っていることに気づきにくい場所です。このツールはファイル内部に保存されている全てのヘッダー・フッター部品（現在のセクションで使われていない部品も含みます）の文字をそのまま一覧表示します。

Q. 変更履歴やコメントの投稿者名は確実に検出できますか？

A. 本文・ヘッダー・フッター・脚注・文末脚注にあるw:author属性（挿入・削除・書式変更の記録や、従来形式のコメントに付く投稿者名）は確実に検出します。最近の「スレッド形式」コメントは投稿者名の保存場所がファイルの履歴によって異なることがあり、消去する側のツールでも100%の除去は保証していません。詳しくは作成者名などを消すツールのFAQをご覧ください。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込みが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Word 2007以降の.docx形式に対応しています。古い.doc形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop a Word (.docx) file into the box above, or click it to choose one (several files at once are fine too).
  2. Five checks are run (Track Changes editor names, comment authors, hidden text, creator/last-modified-by/company/manager, header/footer text), each showing a count and a breakdown.
  3. Any check with a hit shows a link to the dedicated tool that can remove it (checks with no dedicated tool show how to check it inside Word itself).

Q. Can this tool rewrite or remove anything?

A. No. This is a read-only inspection tool — it never rewrites your file. To actually clear Track Changes editor names, comment authors or author metadata, use the author/comment-author scrubber.

Q. What is "hidden text"?

A. Text with Word's "Hidden" font attribute checked. It doesn't show on screen, in print, or in a PDF export by default, but the characters stay inside the file. Anyone who turns on "Show/Hide ¶" (Ctrl+Shift+8) can see it. This tool counts how many characters are marked hidden in each part of the document — body, headers, footers, footnotes and endnotes — without showing the text itself.

Q. Why check header/footer text?

A. Word's editing view is centered on the body text; headers and footers only open for editing when you double-click the top/bottom margin, so it's easy to forget a leftover company name, "Confidential" or "Draft" label copied from an old template. This tool lists the text of every header/footer part actually stored inside the file, including ones not used by the current section.

Q. Are Track Changes editors and comment authors reliably detected?

A. The w:author attribute recorded in the document body, headers, footers, footnotes and endnotes (insertions, deletions, formatting changes, and classic-style comments) is reliably detected. Recent "threaded" comments can store the author's name in a location that varies by the file's history, and even the scrubbing tool can't guarantee 100% removal there — see the author scrubber's FAQ for details.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Word 2007+ .docx files. The older .doc format and password-protected files are not supported — if a file fails to load, an error is shown next to it.
