使い方とよくある質問

  1. 上の枠に結合したいExcel（.xlsx/.xlsm）ファイルを複数ドラッグ＆ドロップするか、クリックしてまとめて選びます（1つずつの追加も可）。
  2. 複数シートがあるファイルは、ファイルごとの一覧でどのシートを使うか選びます（既定は先頭のシート）。
  3. 各ファイルの1行目を見出し行として扱うか（既定でON）、先頭に元ファイル名の列を付けるかを選びます。
  4. 「そろえた列」で、どの列が全ファイルにあるか・一部のファイルだけかを確認し、プレビューで結合結果を確認してから「結合してCSVをダウンロード」を押します。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・結合されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示し、結合からは除外します。

Q. 1つのファイルに複数のシートがある場合は？

A. ファイルごとの一覧に「シート」の選択欄が出るので、使いたいシートを1つ選べます（既定は先頭のシート）。同じファイルの別のシートも結合に使いたいときは、同じファイルをもう一度ドラッグ＆ドロップして追加し、2つ目の方でシートだけ切り替えてください。

Q. 日付や時刻が入ったセルはどうなりますか？

A. Excelは日付を内部的に「シリアル値」という数値で保存していますが、このツールはセルの表示形式（日付・日時・時刻）を見て「2026/04/01」のような見たままに近い文字列に変換してからCSVに書き出します。非常に特殊な独自の表示形式の一部は判定できないことがあり、その場合は数値のまま出力されます。

Q. 数式が入ったセルはどうなりますか？

A. 直近にExcel等で保存されたときの計算結果（セルに保存されている値）をそのまま使い、再計算はしません。Excelで一度も開いて保存していない（他のプログラムが数式だけを書き込んだ直後の）ファイルでは、計算結果が空欄になることがあります。

Q. マクロやグラフ、セルの色・罫線などの書式は引き継がれますか？

A. いいえ。このツールはセルの値（文字列・数値・日付）だけを読み取ってCSVに変換するため、マクロ・グラフ・画像・セルの色や罫線、列幅などの見た目の情報は失われます。

Q. ファイルによって列の並び順や数が違っても結合できますか？

A. 「見出し名で列をそろえる」がONのときは、見出し名（前後の空白は無視）が一致する列を同じ列として扱い、全ファイルの見出し名を集めた列構成に結合します。あるファイルに無い見出しの列は、そのファイルの行では空欄になります。OFFにすると見出しは使わず、列の並び順のまま上から順につなげます。

Q. 大きなファイルや多数のファイルは扱えますか？

A. ブラウザのメモリ上で処理するため、合計で数万行程度までを想定しています。非常に大きい場合は読み込み・表示が遅くなることがあります。

How to use & FAQ

  1. Drag and drop several Excel (.xlsx/.xlsm) files into the box above, or click it to choose multiple files (you can also add them one at a time).
  2. For files with more than one sheet, pick which sheet to use from that file's row in the list (defaults to the first sheet).
  3. Choose whether to treat each sheet's first row as a header (on by default), and whether to prepend a "source file" column.
  4. Check "Aligned columns", review the merged preview, then click "Merge and download CSV".

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and merged inside your browser, on this device (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported — if a file fails to load, an error is shown next to it and it's excluded from the merge.

Q. What if a file has multiple sheets?

A. Each file's row in the list gets a sheet picker (defaulting to the first sheet) so you can choose which one to use. To merge two different sheets from the same file, add that file a second time and pick a different sheet for the second entry.

Q. How are date and time cells handled?

A. Excel stores dates internally as serial numbers. This tool looks at each cell's display format (date, date-time, or time) and converts it to a readable string like "2026/04/01" before writing the CSV. A few unusual custom formats may not be recognized, in which case the raw serial number is shown instead.

Q. What about cells containing formulas?

A. The last calculated value saved in the file is used as-is; nothing is recalculated. A file that was never opened and saved in Excel (e.g. generated by another program moments ago) may have blank cached values for its formulas.

Q. Are macros, charts, or cell formatting preserved?

A. No. Only cell values (text, numbers, dates) are read and converted to CSV — macros, charts, images, cell colors, borders and column widths are all dropped.

Q. Can I merge files whose columns are in a different order or count?

A. When "align columns by header name" is on, columns whose header text matches (ignoring leading/trailing spaces) are treated as the same column, using the union of all header names seen. A sheet missing a given column gets a blank cell for it. Turning this off appends every row, including the first, in column order as-is.

Q. Can it handle large or many files?

A. Everything runs in browser memory, so it's built for combined totals up to tens of thousands of rows. Very large inputs may make loading and rendering slower.
