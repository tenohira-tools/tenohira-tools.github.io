複数のWordファイルの変更履歴（校閲）を一括で確定

「変更履歴の記録」が付いたままのWordファイルを、1件ずつ開いて「すべての変更を反映」を押す手間をなくしたいときに。挿入は本文として確定、削除された文字は取り除き、移動は移動後の場所に確定、書式変更の記録は消去します。本文・ヘッダー・フッター・脚注・文末脚注すべてが対象です。コメントも一括で削除できます（オプション）。複数ファイルを同時に処理でき、ファイルはサーバーに送らずこのブラウザの中だけで書き換えます。元のファイルは変更しません。

.docx に対応。複数ファイルを同時に追加できます。ファイルは選択した端末の中だけで処理されます。

使い方とよくある質問

  1. 上の枠にWord(.docx)ファイルをドラッグ＆ドロップするか、クリックして選びます（複数ファイル可）。
  2. 各ファイルについて、見つかった変更履歴（挿入・削除・移動・書式変更の記録）とコメントの件数が表示されます。必要ならコメントも削除するにチェックを入れ、「確定して書き出す」を押すとダウンロードされます。元のファイルはそのまま残ります。

Q. 具体的に何をしますか？Wordの「すべての変更を反映」と同じですか？

A. Wordの校閲タブにある「すべての変更を反映（承諾）」をファイルを開かずにまとめて行うものです。挿入された文字・図は本文として確定し、削除された文字は実際に取り除き、移動（ドラッグ等で場所を変えた文章）は移動後の位置の内容として確定します。段落・表・文字単位の書式変更の記録（元の書式を記憶している部分）も、現在の書式を残したまま履歴だけ消します。対象は本文・ヘッダー・フッター・脚注・文末脚注です。

Q. 表の行・列の挿入・削除やセルの結合の履歴はどうなりますか？

A. 対象外です。表の行・列が「挿入・削除として記録されたまま」になっている場合や、セル結合の履歴は、このツールでは変更しません（安全のため、行・列ごと削除するような構造的な書き換えは行いません）。文章の挿入・削除・移動・書式変更の履歴だけを対象にしています。該当する表がある場合は、Word上で「すべての変更を反映」を実行してから使うか、このツール適用後にWordで確認してください。

Q. コメントは消えますか？

A. 既定では消えません。「コメントも削除する」にチェックを入れた場合のみ、コメント本文・コメントへの吹き出しの印（コメント範囲の開始・終了・参照マーク）をすべて削除します。チェックを入れなければ、変更履歴だけを確定し、コメントはそのまま残ります。

Q. 変更履歴が無いファイルを処理すると何が起きますか？

A. 何も変わりません。変更履歴・コメントの件数が0件と表示されたまま「確定して書き出す」を押すと、内容が同じファイルがそのままダウンロードされます（安全に使えることの確認用にお使いください）。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはブラウザのメモリ上でのみ扱われ、確定後の内容は別の新しいファイルとしてダウンロードされます（ファイル名の末尾に「_確定済み」を付けます）。元のファイルを直接上書きすることはありません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Word(.docx)です。古い.doc形式や、パスワードで保護されたファイルは読み込めません。

How to use & FAQ

  1. Drag and drop Word (.docx) files into the box above, or click it to choose (multiple files are fine).
  2. Each file shows how many tracked changes (insertions, deletions, moves, formatting-change records) and comments were found. Check "Also delete comments" if you want those removed too, then click "Accept & build" to download the result. Your original file is untouched.

Q. What exactly does this do — is it the same as Word's "Accept All Changes"?

A. Yes — it performs Word's Review-tab "Accept All Changes" across every file at once, without opening each one. Inserted text/objects become permanent body content, deleted text is actually removed, and moved text (dragged to a new location) is finalized at its new location. Formatting-change records on paragraphs, tables and runs (which store the previous formatting) are cleared while the current formatting stays. This covers the document body, headers, footers, footnotes and endnotes.

Q. What about tracked row/column insertions, deletions or cell merges in a table?

A. These are not handled. If a table has rows/columns recorded as tracked insertions or deletions, or a tracked cell merge, this tool leaves them as-is (it never deletes a whole row or column structurally, for safety). Only text-level insertions, deletions, moves and formatting-change records are accepted. If your file has this, run Word's own "Accept All Changes" first, or check the result in Word afterwards.

Q. Are comments removed?

A. Not by default. Only when you check "Also delete comments" are the comment bodies and their anchors (range start/end and reference marks) removed. Leave it unchecked to accept tracked changes while keeping comments intact.

Q. What happens if a file has no tracked changes?

A. Nothing changes. If the counts show 0 for both tracked changes and comments, clicking "Accept & build" downloads an unchanged copy (useful to confirm the tool is safe to use).

Q. Is my original file modified?

A. No. The file you load is only ever held in your browser's memory; the result is downloaded as a new file (with "_accepted" appended to the name). Your original file is never overwritten.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Word (.docx) only. The older .doc format and password-protected files are not supported.
