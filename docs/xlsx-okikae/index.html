Excelの置換（Ctrl+H）も開いているファイルだけ：複数のエクセルファイルの文字列を一括置換

Excelの検索・置換（Ctrl+H）は、今開いているブックの中だけが対象です。社名が変わった、決算年度が変わった、部署名を直したい——というときに、保存済みの複数のExcel（.xlsx/.xlsm）ファイルを1つずつ開いて置換し直すのは大変です。このツールはファイルを追加し、置き換えたい文字列と置き換え後の文字列を1回入力するだけで、全ファイル・全シートのセルの値（共有文字列・インライン文字列）を一括置換し、ファイルごとに新しいファイルとしてダウンロードします。元のファイルは変更しません。数式そのものの文字列は対象外です。読み取ったファイルはサーバーに送信されません。

Q. Excel自体の検索・置換（Ctrl+H）と何が違いますか？

A. Excelの置換は、今アクティブなウィンドウで開いているブック（ファイル）の中だけが対象です。別々に保存した複数のファイルを一括で置換することはできず、1つずつ開いて置換し直す必要があります。このツールは複数のExcelファイルをまとめて追加するだけで、同じ置き換えを全ファイル・全シートに一括適用し、ファイルごとに新しいファイルとしてダウンロードできます。

Q. どこが置換の対象ですか？

A. セルの値のうち、共有文字列とインライン文字列（どちらも文字列としてセルに保存されている内容）だけが対象です。数式そのものの文字列（例：="A"&A1 のような数式に含まれる引用符内の文字列）は対象外で、書き換えません。数式の計算結果として表示されている文字列（キャッシュされた計算結果）も対象外です。

Q. 「共有文字列」とはなんですか？なぜ1件の置換が複数のセルに影響することがありますか？

A. Excelのファイル形式は、同じ文字列が複数のセルに入っている場合、ファイル内部では1つの「共有文字列」として保持し、各セルはその番号を参照する仕組みになっています。同じ社名が50個のセルに入っていても、内部的には1つの文字列であることが多く、それを置換すると参照している全てのセルに一括で反映されます。社名変更や年度更新のような「同じ文字列をまとめて直したい」用途にはこの挙動が有利に働きますが、意図せず広い範囲が変わることもあるため、プレビューの「影響するセル数」で事前に確認してからダウンロードしてください。

Q. 一部だけ色や太字が違うなど、書式が途中で分かれている文字列はどうなりますか？

A. 1つのセルの文字列が、書式の都合で複数の「ラン」（文字の区切り）に分かれて保存されていることがあります。検索したい文字列がそのランの境界をまたいでいる場合、このツールでは検出・置換できません（例：「ABC」のうち「AB」だけ太字で別のランになっている場合、「ABC」を検索しても見つからないことがあります）。見つからない場合は、Excel側で一度書式を統一してから試すか、該当セルだけ手動で修正してください。誤って置換してしまうより、見逃す方を優先する設計です。

Q. 大文字・小文字は区別されますか？

A. 既定では区別します（チェックを入れると区別しなくなります）。置き換え後の文字列は、大文字・小文字の区別の設定に関わらず、常に入力したとおりの表記でそのまま挿入されます（元の文字の大小文字に合わせて自動調整されることはありません）。

Q. 「完全一致」は何が変わりますか？

A. オンにすると、セルの文字列のまとまり全体が検索語とちょうど一致する場合だけ置き換えます。オフ（既定）では、文字列の一部に含まれていれば置き換えます（「株式会社ABC 御中」の「ABC」だけを変える、といった使い方ができます）。

Q. ふりがな（フリガナ）は変わりますか？

A. いいえ。セルに保存されているふりがなの読み情報（rPh）は検索・置換の対象外で、変更されません。

Q. 元のファイルは変更されますか？

A. いいえ。読み込んだファイルはそのままで、置換後の内容は新しいファイルとしてダウンロードされます。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・置換されます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. 対応しているファイル形式は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。読み込みに失敗した場合は、そのファイルの横にエラーを表示します。

How to use & FAQ

  1. Drag and drop Excel (.xlsx/.xlsm) files into the box above, or click it to choose one or more at once.
  2. Once loading finishes, type the text to find and its replacement into the boxes — each file's preview updates as you type.
  3. Toggle "Ignore case" and "Exact match" as needed.
  4. Check the match count and before/after preview shown for each file, then click that file's "Replace & download" button.
  5. With several files, click the button for each one in turn — the same find/replace is applied to all of them.

Q. How is this different from Excel's own Find & Replace (Ctrl+H)?

A. Excel's own Replace only acts on the workbook you currently have open in the active window — it can't replace across several files you've saved separately in one pass; you'd have to open and redo it in each one. This tool lets you add multiple Excel files at once, applies the same find/replace to every file and sheet, and lets you download each updated file.

Q. What does it actually rewrite?

A. Only text stored as cell values — shared strings and inline strings. The raw text of formulas themselves (e.g. a quoted string literal inside ="A"&A1) is left untouched, as is a formula's cached calculated text result.

Q. What is a "shared string", and why can one replacement affect many cells?

A. Excel's file format stores a string that appears in more than one cell only once, as a "shared string", with each cell simply referencing its index. The same company name in 50 cells is often internally just one string, so replacing it updates every cell that references it in one go — exactly the behavior you want for a company-name or fiscal-year change, but it can also change more than you expect. Check the "cells affected" count shown in the preview before downloading.

Q. What about text whose formatting is split partway through (part bold, part not)?

A. A single cell's text can be stored as several formatted "runs". If your search text spans a boundary between two runs, this tool won't detect or replace it (e.g. if "AB" is bold and "C" isn't within "ABC", searching for "ABC" may not find it). If a match seems to be missing, try unifying the formatting in Excel first, or edit that cell by hand. This favors missing a match over replacing something incorrectly.

Q. Is matching case-sensitive?

A. By default, yes (check the box to ignore case). Whatever you type as the replacement is always inserted exactly as typed, regardless of the matched text's original case.

Q. What does "Exact match" change?

A. With it on, only cells whose entire text block exactly equals your search term are replaced. With it off (default), a match anywhere inside the text is replaced — useful for changing just "ABC" inside "ABC Corp., Attn:".

Q. Does it touch furigana (phonetic reading hints)?

A. No. The phonetic reading data stored for a cell (rPh) is excluded from search and replace.

Q. Can this tool change my original file?

A. No. The file you load is left as-is; the replaced result downloads as a new file.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and replaced inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Which file formats are supported?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files are not supported; a failed file shows an error next to it.
