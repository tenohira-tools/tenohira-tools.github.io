数式を値に変換：外部ファイルへのリンクが解除できないときに

「データ」タブの「リンクの編集」→「リンクの解除」を押しても外部ファイルへの参照が消えない・エラーになる、社外にファイルを渡す前に数式を外して値だけ残したい——というときに。Excel(.xlsx/.xlsm)の数式を、保存されている計算結果（値）に変換します。「すべての数式」と「外部ファイルを参照している数式だけ」のどちらを値にするか選べ、条件を満たす場合だけ外部リンクの記録そのものも一緒に削除できます。元のファイルは変更しません。

ここにExcel(.xlsx/.xlsm)ファイルをドラッグ＆ドロップ、またはクリックして選択

1回に1ファイル。すべてのシートの数式セルを解析します。ファイルは選択した端末の中だけで処理されます。

数式セルの集計

「外部参照の可能性」「他シート参照」は数式の文字列からの機械判定で、断定ではありません。「計算結果が未保存」は、数式はあるが直近の保存時に計算結果が記録されていないセルで、値に変換すると空欄になってしまうため、どちらのスコープでも常に数式のまま残します。

値に変換する範囲

数式セルの一覧

変換されたセルは、保存されている計算結果がそのまま固定された値になります。再計算はしません（元の数式内に再計算が必要な未保存の変更があった場合、その変更は反映されません）。元のファイルは変更されず、新しいファイルとして書き出されます。

使い方とよくある質問

  1. 上の枠にExcel（.xlsx/.xlsm）ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. 数式セルの集計と、どの範囲を値に変換するか（外部参照の数式だけ／すべての数式）を選びます。
  3. 条件を満たしていれば、外部リンクの記録そのものも一緒に削除するチェックが使えます。
  4. 「選んだ範囲で値に変換したファイルを書き出す」でダウンロードします。元のファイルはそのまま残ります。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・書き換えが行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

Q. Excel自身の「リンクの解除」（Break Links）ではダメなのですか？

A. Excelの「データ」タブ→「リンクの編集」→「リンクの解除」は、参照先が見つからない・壊れている・名前付き範囲やグラフなど一部の箇所からも参照されている、といった条件がそろうと失敗したり、解除したつもりでも再度開くと「更新」を聞かれたりすることがあります。このツールは数式セル1つ1つをブラウザの中で直接読み取り、保存されている計算結果に置き換えるため、Excel側の「リンクの解除」が効かない場合の代わりになります。

Q. 「外部ファイルを参照している数式だけ」を選ぶとどうなりますか？

A. 数式の文字列に「[1]」「[ファイル名.xlsx]」のような、他のExcelファイルを指す書き方が含まれているセルだけを値に変換します。文字列パターンによる機械判定のため、名前定義を経由して間接的に外部ファイルを参照している数式などは検出できないことがあります。フィルハンドルでコピーされた「共有数式」については、グループ内のどこか1つでも外部参照が見つかれば、参照のずれで見逃しが起きないよう、そのグループ全体を値に変換します。

Q. 「外部ファイルへのリンクの記録も一緒に削除する」はいつ使えますか？

A. このチェックは、変換後にファイル内のどこにも外部参照が残らないと確認できたときだけ有効になります。具体的には、(1) 外部参照を含む数式セルが1つ残らず値に変換され、かつ (2) 名前定義・データの入力規則・条件付き書式・グラフのいずれでも外部参照が使われていない、という2つの条件がそろった場合です。どちらか一方でも満たさない場合はチェックが無効化され、その理由を表示します（このツールは数式セル以外の書き換えをしないため、そちらで使われている外部参照は安全に消せないと判断しています）。有効な場合、workbook内の外部参照の記録（参照先ファイルの情報）そのものを削除し、Excelの「リンクの編集」ダイアログにも何も表示されなくなります。

Q. 「計算結果が未保存」のセルはどうなりますか？

A. 値に変換せず、数式のまま残します。数式セルに計算結果（キャッシュされた値）が保存されていない場合、空欄のセルに置き換えてしまうと内容が失われるため、安全のため常にスキップします。該当するセルがある場合は一覧に表示されるので、必要であれば一度Excelで開いて保存してから、このツールを使い直してください。

Q. 配列数式・データテーブルはどう扱われますか？

A. 配列数式（CSE数式・動的配列数式）やデータテーブルは、数式が保存されている先頭セルだけを数式セルとして検出し、値に変換すると保存されていた計算結果で固定されます。結果が広がっている他のセルは元々数式を持たないため、影響はありません。ただし、この操作を行うと配列・データテーブルとしての再計算は行われなくなります。

Q. 対応しているファイル形式・元のファイルへの影響は？

A. Excel 2007以降の.xlsx・.xlsm形式に対応しています。古い.xls形式や、パスワードで保護されたファイルは読み込めません。元のファイルはブラウザのメモリ上で読み込むだけで変更されず、結果は新しいファイルとしてダウンロードされます（ファイル名の末尾に「_値変換済み」を付けます）。数式セル以外のシート構成・値・通常の書式・グラフ・画像などはそのまま保持されます。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm) file into the box above, or click it to choose one.
  2. Check the formula summary and choose the scope to convert — external-reference formulas only, or every formula.
  3. When the conditions are met, you can also tick a box to remove the external-link records themselves.
  4. Click "Build a file converted to values" to download the result — your original file is untouched.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read and rewritten inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).

Q. Why not just use Excel's own "Break Links"?

A. Excel's Data → Edit Links → Break Links can fail, or silently leave you being prompted to "update" links again later, especially when the target file is missing, when a defined name or a chart still points at the external reference, or when the link is otherwise in an inconsistent state. This tool reads every formula cell directly in your browser and replaces it with its cached value, so it works even when Excel's own Break Links doesn't.

Q. What does "external-reference formulas only" do?

A. It converts only the cells whose formula text contains a pattern that points at another workbook, such as "[1]" or "[filename.xlsx]". This is a text-pattern check, so a formula that reaches an external workbook only indirectly through a defined name may not be detected. For "shared formulas" (created by filling/copying a formula down or across), if any one member of the group is flagged as external, the whole group is converted together, so a relative-reference offset can't cause a cell to be silently missed.

Q. When can I also remove the external-link records themselves?

A. That checkbox is only enabled when no external reference would remain anywhere in the file after conversion — specifically when (1) every formula cell referencing an external workbook has been converted to a value, and (2) no defined name, data validation rule, conditional formatting rule, or chart still uses an external reference. If either condition isn't met, the checkbox is disabled with an explanation (this tool only rewrites formula cells, so it won't guess at removing a reference that's still used elsewhere). When it's available, the workbook's external-reference records are removed entirely, so Excel's Edit Links dialog shows nothing afterward.

Q. What happens to cells with no cached result?

A. They're left as formulas, untouched. If a formula cell has no cached value saved (nothing stored alongside the formula), converting it would turn it into a blank cell and lose information, so this is always skipped for safety. Any such cells are listed — open the file in Excel, let it recalculate and save, then run this tool again if you need them converted too.

Q. How are array formulas and data tables handled?

A. Array formulas (legacy CSE or dynamic arrays) and what-if data tables only store their formula on the anchor cell; converting that cell freezes it at its last cached result. Other cells the result spills into never had a formula of their own, so they're unaffected — but the range no longer recalculates as an array or data table afterward.

Q. Which formats are supported, and is my original file changed?

A. Excel 2007+ .xlsx and .xlsm files. The older .xls format and password-protected files aren't supported. Your original file is only ever read into browser memory — the result downloads as a new file ("_values" appended to the name). Everything besides the converted formula cells — other cell values, regular formatting, charts, images — is carried over unchanged.
