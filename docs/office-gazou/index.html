Excel・Word・PowerPointの画像をまとめて保存する

ファイルの拡張子を.zipに変えて展開し、media フォルダから画像を1枚ずつ取り出す……という手作業の代わりに、Excel(.xlsx/.xlsm)・Word(.docx)・PowerPoint(.pptx)の中に埋め込まれている画像をまとめて抽出します。各画像がどのシート・スライド・本文（ヘッダー/フッター/脚注を含む）で使われているかを一覧表示し、対応表CSV付きのZIPでダウンロードできます。ファイルはサーバーに送らず、すべてこのブラウザの中だけで処理します。

ここにExcel・Word・PowerPointファイルをドラッグ＆ドロップ、またはクリックして選択

.xlsx / .xlsm / .docx / .pptx に対応。1回に1ファイル。ファイルは選択した端末の中だけで処理されます。

注意：一部の画像は、どのシート・スライド・本文で使われているか特定できませんでした（図形の背面に隠れている、特殊な埋め込み方法、または参照されず残っているだけの画像である可能性があります）。見つかった画像自体はすべて一覧とZIPに含まれます。

使い方とよくある質問

  1. 上の枠にExcel(.xlsx/.xlsm)・Word(.docx)・PowerPoint(.pptx)ファイルをドラッグ＆ドロップするか、クリックして選びます。
  2. ファイルの中に埋め込まれている画像が一覧表示されます（既定で全て選択済み）。サムネイルで中身を確認できます（.wmf/.emf/.tiffなどブラウザで表示できない形式はアイコン表示になりますが、抽出自体は可能です）。
  3. 不要な画像はチェックを外します。「選択した画像をZIPでダウンロード」で、画像ファイルと対応表CSVをまとめたZIPが保存されます。

Q. 「どこで使われているか」はどうやって調べていますか？

A. Excelはシートごとの描画情報（drawing）、PowerPointはスライド・スライドレイアウト・スライドマスターごとの参照情報、Wordは本文・ヘッダー・フッター・脚注・文末脚注それぞれの内部参照（リレーションシップ）を読み取り、各画像がどこから参照されているかを突き合わせています。参照が見つからなかった画像は「不明」として、画像自体は引き続き一覧・ZIPに含めます。

Q. どの画像形式に対応していますか？

A. ファイル内部のmediaフォルダに保存されている形式（png/jpeg/gif/bmp/tiff/wmf/emf/svgなど）をそのまま、変換・再圧縮せずに取り出します。png・jpeg・gif・bmp・webp・svgはこのページ上でサムネイル表示できますが、wmf・emf・tiffなど一部の形式はブラウザがプレビュー表示できないため、拡張子のアイコン表示になります（ファイル自体は正しく抽出されます）。

Q. 図形の塗りつぶしに使われている画像や、セル内画像（Excelの新しいIMAGE関数・画像の挿入機能）も取り出せますか？

A. 図形の塗りつぶし画像など、DrawingMLの標準的な埋め込み方法（Excelのdrawing、PowerPointのスライド本体）で参照されている画像は取り出せます。Excelの新しいセル内画像機能（リッチデータ形式）や、図形の背後に隠れた古い形式のVML描画など、特殊な保存方法を使っている画像は、ファイル自体は抽出されますが「どこで使われているか」が「不明」になる場合があります。

Q. 動画や音声、埋め込みExcel/Wordオブジェクトも取り出せますか？

A. このツールが取り出すのは画像だけです。動画・音声・埋め込みオブジェクトは対象外です（ファイル全体の内訳を見たい場合は、関連ツールの「重さの内訳」診断ツールをご利用ください）。

Q. 元のファイルは変更されますか？

A. 変更されません。元のファイルの画像データをそのまま複製して取り出すだけで、元のファイルには一切書き込みません。

Q. このツールにファイルをアップロードしても安全ですか？

A. はい。ファイルはサーバーに送信されず、すべてこのページを開いているブラウザの中だけで読み込み・解析・抽出が行われます（サイト全体の閲覧数をCookieなし・匿名で数えるGoatCounterの通信のみ発生します）。

How to use & FAQ

  1. Drag and drop an Excel (.xlsx/.xlsm), Word (.docx) or PowerPoint (.pptx) file into the box above, or click it to choose one.
  2. Every image embedded in the file is listed (all selected by default), with a thumbnail where the browser can render it (.wmf/.emf/.tiff and similarly unsupported formats show as an icon instead, but are still extracted correctly).
  3. Uncheck anything you don't need, then click "Download selected images as ZIP" to get a ZIP containing the image files plus a CSV mapping table.

Q. How does it figure out where each image is used?

A. For Excel, it reads each sheet's drawing part; for PowerPoint, each slide's, slide layout's and slide master's reference info; for Word, the internal relationships of the body, headers, footers, footnotes and endnotes. Each image is matched against these references. An image with no match found is labeled "unknown" but is still listed and included in the ZIP.

Q. Which image formats are supported?

A. Whatever format is already stored in the file's internal media folder (png/jpeg/gif/bmp/tiff/wmf/emf/svg, etc.) is extracted as-is, with no conversion or re-compression. PNG, JPEG, GIF, BMP, WebP and SVG get a thumbnail preview on this page; a few formats such as WMF, EMF and TIFF can't be previewed by the browser and show as a generic icon instead (the extracted file itself is still correct).

Q. Does it also extract images used as shape fills, or Excel's newer in-cell images (the IMAGE function / "Picture in cell")?

A. Images referenced through the standard DrawingML embedding used by Excel's drawing parts and PowerPoint's slide bodies — including shape-fill images — are extracted and matched. Excel's newer rich-data in-cell image feature, and older VML-based shapes hidden behind other shapes, use less common storage methods; the image file itself is still extracted, but its location may come back as "unknown".

Q. Can it also extract video, audio, or embedded Excel/Word objects?

A. No, this tool only extracts images. Video, audio and embedded objects are out of scope (see the related "where the size is going" diagnosis tools if you want a full breakdown of a file's contents).

Q. Does this change my original file?

A. No. It only copies out the image data that's already inside your file — nothing is written back to the original.

Q. Is it safe to use this on my files?

A. Yes. Files are never uploaded to a server — everything is read, analyzed and extracted inside your browser (only an anonymous, cookie-free page-view count for this site is sent, via GoatCounter).
