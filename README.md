# てのひらツール / tenohira tools

ブラウザだけで動く小さな無料ツール集。登録不要。Cookieなし・個人を特定しないアクセス数の計測のみ（GoatCounter）。入力内容は端末の外に送られません。

A collection of small, free tools that run entirely in your browser. No sign-up. Only anonymous, cookie-free page-view counting (GoatCounter) — what you enter never leaves your device.

- ツール一覧 / Tools: https://tenohira-tools.github.io/
- ご意見・不具合報告 / Feedback: [GitHub Issues](https://github.com/tenohira-tools/tenohira-tools.github.io/issues)
- 運用ルール / Operating rules: [RULES.md](RULES.md)
