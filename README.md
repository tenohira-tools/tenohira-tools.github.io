# てのひらツール / tenohira tools

ブラウザだけで動く小さな無料ツール集。登録不要・追跡なし。入力内容は端末の外に送られません。

A collection of small, free tools that run entirely in your browser. No sign-up, no tracking. What you enter never leaves your device.
